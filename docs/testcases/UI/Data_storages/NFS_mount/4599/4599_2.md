# Resume NFS storage file indexing after removing the exclusion attribute

Test verifies that removing the `Billing status` = `Exclude` attribute from an NFS storage resumes the indexing of its files.

**Prerequisites**:
- admin user
- Perform [4599_1](4599_1.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open `nfs_storage1` from [4599_1](4599_1.md) and click **Show attributes** button in the right upper corner | The `Billing status` = `Exclude` attribute added at [4599_1](4599_1.md) is shown |
| 2 | Remove the `Billing status` attribute (click the remove icon near the attribute and confirm) | The attribute is removed from `nfs_storage1` |
| 3 | Wait for the next NFS indexing cycle | |
| 4 | Click on **Search** icon at the left menu bar and search for `file2` uploaded at [4599_1](4599_1.md) | `file2` is now found among the search results |
