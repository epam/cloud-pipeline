# ROLE_STORAGE_READER: read-only access to existing storages

Test verifies that:
User with role STORAGE_READER
- has a read access to all storages registered in the system, even if the storage permissions deny it
- shall not be able to edit/delete storages and their data, unless a permission to do so is granted explicitly

**Prerequisites**:
- Admin user
- Non-admin user

**Preparations**
1. Login as admin user from the prerequisites
2. Create the object storages `storage1` and `storage2`. Open `storage1` and create file `testfile1.txt`.
3. Open the permissions of `storage1`, add the non-admin user from the prerequisites and deny **Read** to that user.
4. Open the permissions of `storage2`, add the non-admin user from the prerequisites and allow **Write** to that user.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as non-admin user from the prerequisites | |
| 2 | Open the **Library** page | `storage1` isn't visible |
| 3 | Logout and login as admin user from the prerequisites | |
| 4 | Open the **Settings** page >> Select the "**USER MANAGEMENT**" tab | |
| 5 | In the users list click the **Edit** button next to non-admin user from the prerequisites | |
| 6 | In the dropdown list next to the field "**Add role or group**" select `ROLE_STORAGE_READER` item. Click the "**+ Add**" button. Save changes. | |
| 7 | Logout and login as non-admin user from the prerequisites | |
| 8 | Open the **Library** page | `storage1` is visible for non-admin user |
| 9 | Open `storage1` | <li> `testfile1.txt` is visible <li> **+Create** and **Upload** buttons are not visible |
| 10 | Click the **Download** button near the `testfile1.txt` name | File `testfile1.txt` is downloaded |
| 11 | Click the **gear** icon in the right upper corner | Storage settings are opened in a read-only mode, **Delete** button is not visible |
| 12 | Open the **Permissions** tab | Storage permissions are shown, the non-admin user from the prerequisites is listed there |
| 13 | Open `storage2` | **+Create** and **Upload** buttons are visible |
