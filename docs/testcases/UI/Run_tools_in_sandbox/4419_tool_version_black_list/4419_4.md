# Admin removes a tool version from the black list

Test verifies that an admin user can remove a previously blacklisted tool version from the black list, restoring the ability to run it.

**Prerequisites**:
- Admin user
- Perform [4419_2](4419_2.md) and [4419_3](4419_3.md) cases

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Open the **Versions** tab | The blacklisted `latest` version is shown in the list with ***Black-listed*** button |
| 5 | Click ***Black-listed*** button opposite the `latest` version | A content menu opens that contains *Remove from black list* and *Add to white list* options |
| 6 | Click *Remove from black list* button | <li> *Remove from black list* button is replaced by *Add to black list* button <li> Exclamation mark disappears from the **Run** button |
