# ROLE_PIPELINE_ADMIN: clone existing pipeline

Test verifies that user with role `ROLE_PIPELINE_ADMIN` can clone existing pipeline to folder if has permissions on this folder.

**Prerequisites**:
- admin user
- non-admin user with `ROLE_PIPELINE_ADMIN` role
- perform [4146_1_3](4146_1_3.md) case

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create pipeline (`pipeline2`)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open **Library** | |
| 3 | Open `pipeline2` |  |
| 4 | Hover over *gear* icon in the right upper corner. In an appeared dropdown list click on *Clone* item | <li> *Select destination folder* pop-up appears <li> *Clone into Library* button is disabled |
| 5 | In an *Name* field specify a valid new pipeline name | |
| 6 | In the tree select `folder1` created at step 2 of the [4146_3](4146_1_3.md) case preparations | *Clone into <`folder1`>* button become active |
| 7 | Click on *Clone into <`folder1`>* button | Cloned pipeline opens |
