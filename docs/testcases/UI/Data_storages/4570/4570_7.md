# Downloads window: the Status filter's select-all box and "Reset to defaults"

Test verifies that:
- the **Status** column's filter lists a single select-all box above the per-status checkboxes, separated from them by a line
- that box's label names what the next click will do - **Select all** while any status is unticked, **Unselect all** only once every status is ticked
- clicking it ticks every status, and clicking it again unticks every status
- unticking any single status turns the label back to **Select all**
- **Reset to defaults** restores the default selection - every status except `CANCELLED` and `EXPIRED`
- the dropdown offers no **Clear** link

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose share is mounted as NFS), holding at least one file

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. Select a file via its checkbox, click the selection button (**"1 item selected"**), choose **Download archive**, then click **OK** without changing the offered name
4. Open the **Downloads** window: click the grid-icon button at the top right of the storage view and choose **Show downloads**

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click the filter icon on the **Status** column's header | <li> The filter dropdown opens <li> A single checkbox sits at the top, labelled **Select all**, shown in a half-ticked (indeterminate) state <li> A horizontal line separates it from the list of statuses below <li> Below the line there is one checkbox per status: `PENDING`, `RUNNING`, `CANCEL_REQUESTED`, `STOPPING`, `SUCCESS`, `FAILED`, `CANCELLED`, `EXPIRED` - all ticked except `CANCELLED` and `EXPIRED` <li> At the bottom there are two links, **OK** and **Reset to defaults**, and no **Clear** link |
| 2 | Click the **Select all** checkbox | <li> Every status checkbox below the line becomes ticked, `CANCELLED` and `EXPIRED` included <li> The top checkbox is now fully ticked and its label changes to **Unselect all** |
| 3 | Click the **Unselect all** checkbox | <li> Every status checkbox below the line becomes unticked <li> The top checkbox is unticked and not half-ticked, and its label changes back to **Select all** |
| 4 | Click the **Select all** checkbox again, then untick the `EXPIRED` checkbox alone | <li> Only `EXPIRED` is unticked; the other seven stay ticked <li> The top checkbox returns to the half-ticked state and its label reads **Select all** again |
| 5 | Click **Reset to defaults** | <li> The dropdown closes <li> The table reloads, showing the user's tasks of every status except `CANCELLED` and `EXPIRED` <li> The **Status** column's filter icon is not highlighted |
| 6 | Click the filter icon on the **Status** column's header again | <li> Every status is ticked except `CANCELLED` and `EXPIRED` - the default is back <li> The top checkbox is half-ticked and reads **Select all** |

**After**:
- Cancel the task queued in Preparations from the **Downloads** window, or let it finish and discard the downloaded archive
