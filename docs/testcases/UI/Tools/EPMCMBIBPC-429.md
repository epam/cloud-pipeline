# Validation of tool executions parameters

Test verifies that the **Disk (Gb)**, **Instance type** and **Cmd template** execution settings are saved and displayed after reopening the tool.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open **Tools** page |  |
| 2 | Select **Default** registry |  |
| 3 | Select a group |  |
| 4 | Click a tool |  |
| 5 | Click **SETTINGS** tab |  |
| 6 | Expand **EXECUTION ENVIRONMENT** section if it's minimized |  |
| 7 | Input a natural number into the **Disk (Gb)** field |  |
| 8 | Select an instance type in the **Instance type** combobox |  |
| 9 | Input a valid value into the **Cmd template** field |  |
| 10 | Click **SAVE** button |  |
| 11 | Repeat steps 1-5 for the just-edited tool | The values specified at steps 7-9 are displayed in the corresponding fields |
