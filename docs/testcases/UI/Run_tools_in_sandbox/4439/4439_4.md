# Custom endpoint with displayOnCompletion=true (or omitted) remains visible after run completion

Test verifies that a custom endpoint with `displayOnCompletion` set to `true` or omitted entirely remains visible in the **Endpoints** section regardless of the run status, including after the run has completed or been stopped.

**Prerequisites**:
- admin user
- test tool available in the registry

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Click the **Run** button | Run launch form opens |
| 5 | Expand the **Parameters** section. Click **Add system parameter** | |
| 6 | Enter key `EXTERNAL_URLS` and value `[{"url": "https://example.com/always", "name": "Persistent Link", "displayOnCompletion": true}, {"url": "https://example.org/no-flag", "name": "No Flag Link"}]` | |
| 7 | Click **Launch** | Run is launched |
| 8 | Wait until the run reaches `RUNNING` state (SSH link appears) | |
| 9 | Click on the run to open the run log page | |
| 10 | Locate the **Endpoints** section | Both **Persistent Link** and **No Flag Link** are displayed in the **Endpoints** section |
| 11 | Return to the **Runs** page. Stop the run | Run transitions to `STOPPED` state |
| 12 | Click on the stopped run to open the run log page | |
| 13 | Locate the **Endpoints** section | Both **Persistent Link** and **No Flag Link** are still displayed in the **Endpoints** section |
