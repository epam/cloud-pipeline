# ROLE_USER_ADMIN: create and delete user group

Test verifies that user with role `ROLE_USER_ADMIN` can create and delete user group.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Groups** tab |  |
| 5 | Click the **+ Create group** button | |
| 6 | In the appeared pop up specify the valid new user group name (`user_group2`). | |
| 7 | Click the **Create** button | |
| 8 | Enter into the search field the user group name specified at step 6. Press the **Enter** key | The record with the name  specified at step 6 appears in the Groups table |
| 9 | Click the **Remove** icon opposite the `user_group2` name. Click the **OK** button to confirm the deleting | |
| 10 | Enter into the search field the user group name specified at step 6. Press the **Enter** key | Search results are empty |
