# [MANUAL] Layout of the Node type field with a pool selected

Test verifies that in the ***Node type*** field:
- the pool name tag is always shown whole
- the CPU/RAM/GPU text is cut when it does not fit
- the field keeps its width when a long node type or a pool is selected

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Pools from the Preparations of [4960_1](4960_1.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | At the tool page, hover over the **Run v** button | |
| 4 | Click the **Custom settings** button in the list | |
| 5 | Expand the **Exec environment** section | |
| 6 | Make the browser window narrow, so that the ***Node type*** field is about as wide as the ***Docker image*** field | |
| 7 | In the ***Node type*** field, select a plain instance type with a short description | The field shows the instance type and its CPU/RAM text |
| 8 | Select a plain instance type with a long description (for example, a GPU instance type) | <li> The CPU/RAM/GPU text is cut at the field edge <li> The field and the ***Docker image*** field have the same width as at step 7 |
| 9 | Select the `pool-shareable-future` entry of the **Pools** group | <li> The pool name tag is shown whole <li> The CPU/RAM/GPU text is cut before the tag <li> The field width is the same as at step 7 |
| 10 | Click the ***Node type*** field | In the open list, every pool entry shows its tag whole |
