# Controls row and column header stay visible while scrolling the storage content

Test verifies that:
- the controls row and the column header of a storage stay at the top of the list while the list is scrolled
- the controls of both rows work at any scroll position

**Prerequisites**:
- Admin user

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create the object storage
3. Upload into the storage 40 files named `file_01` ... `file_40`

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Open the storage created at step 2 of the Preparations | The controls row (**Select page**, **Create**, **Upload**) is shown at the top of the list, the column header (**Name**, **Size**, **Date changed**) is shown under it |
| 4 | Scroll the list down to its middle | <li> The controls row stays at the top of the list <li> The column header stays right under the controls row <li> The rows scroll under them and are not seen through them |
| 5 | Scroll the list down to its end | The controls row and the column header stay at the same place as at step 4 |
| 6 | Click **Select page** | <li> All items of the page are selected <li> The controls row and the column header stay at the same place |
| 7 | Click the sort control of the **Name** column twice | <li> The items are sorted by name in descending order: `file_40` is the first one <li> The controls row and the column header stay at the top of the list |
| 8 | Scroll the list down to its middle | |
| 9 | Click the filter control of the **Name** column | The filter popup opens under the filter control |
| 10 | Enter `file_07` and click **OK** | Only the `file_07` file is shown |
| 11 | Open the filter popup of the **Name** column again and click **Clear** | All files are shown |
| 12 | Scroll the list up to its start | The controls row and the column header are shown at the top of the list, the first row under them is `file_40` |

**After**:
- Delete the storage created at step 2 of the Preparations
