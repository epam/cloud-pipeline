# [Negative] Validation of the disabled "Select page" button

Test verifies that:

- the **Select page** button is disabled when no item on the current page can be selected
- it becomes enabled again on a page that holds a selectable item

**Prerequisites**:

- Admin user
- An object storage with versioning enabled exists

**Preparations**:

1. Login as the admin user from the prerequisites
2. Open the library and click the storage from the prerequisites
3. Create the folders `empty_folder` and `deleted_only` at the storage root
4. Open the `deleted_only` folder, create the file `file1.txt` in it, then click the **..** row to return to the storage root
5. Click the **Grid menu** in the right upper corner and unset the **Show file versions** item

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the `deleted_only` folder of the storage from the prerequisites | <li> the `file1.txt` file is displayed <li> a checkbox is displayed in front of it <li> the **Select page** button is enabled |
| 2 | Click the **Select page** button | <li> the checkbox in front of `file1.txt` becomes checked <li> the **Select page** button becomes disabled |
| 3 | Click the appeared selection-actions button (**N item(s) selected**) and select the **Remove** item |  |
| 4 | Click the **OK** button in the appeared pop-up window | <li> no item is displayed except the **..** row <li> the **Select page** button is disabled |
| 5 | Click the **Grid menu** in the right upper corner and set the **Show file versions** item | <li> the deleted `file1.txt` file is displayed <li> no checkbox is displayed in front of it <li> the **Select page** button is disabled |
| 6 | Click the **Grid menu** in the right upper corner and unset the **Show file versions** item | <li> no item is displayed except the **..** row <li> the **Select page** button is disabled |
| 7 | Click the **..** row | <li> the `empty_folder` folder is displayed <li> a checkbox is displayed in front of it <li> the **Select page** button is enabled |
| 8 | Open the `empty_folder` folder | <li> no item is displayed except the **..** row <li> the **Select page** button is disabled |

**After**:

- Click the **..** row and remove the `empty_folder` folder, and the `deleted_only` folder if it is displayed, from the storage
