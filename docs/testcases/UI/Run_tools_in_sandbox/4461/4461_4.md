# Credit balance is displayed and reflects configured default for new users

Test verifies that a user's Platform Usage Credits balance is visible in the UI and that a newly configured default credit allowance is applied correctly.

**Prerequisites**:
- admin user
- non-admin user (user1)
- Platform Usage Credits feature enabled

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page, navigate to **Platform Usage Credits**
3. Set the default credit allowance to `2000`

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **User Management** page. Find user1 from the prerequisites | |
| 3 | Open user1's profile | The user's current **Platform Usage Credits** balance is displayed |
| 4 | Verify the displayed balance equals the configured default `2000` | The balance shows `2000` credits |
| 5 | Logout and login as user1 | |
| 6 | Navigate to the user profile or credits balance page | The current credit balance `2000` is visible to user1 |

**After**:
- Restore admin and user settings to their original values if changed.
