# Validation of remove several files and folders from NFS mount

Test verifies removing several selected files and folders from an NFS mount.

**Prerequisites**:
- Perform [EPMCMBIBPC-2274](EPMCMBIBPC-2274.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Navigate to the storage created in [EPMCMBIBPC-2274](EPMCMBIBPC-2274.md) |  |
| 2 | Click **+ Create v** button |  |
| 3 | Click on the **Folder** item |  |
| 4 | Specify a valid folder name in the appeared pop-up window |  |
| 5 | Click **OK** button |  |
| 6 | Repeat steps 2-5 |  |
| 7 | Click **Upload** button |  |
| 8 | Select a file and confirm the upload in the appeared window |  |
| 9 | Repeat steps 7-8 for another file |  |
| 10 | Set the checkboxes opposite the created files and folders |  |
| 11 | Click **Remove all selected** button |  |
| 12 | Click **OK** button in the appeared window | All selected files and folders successfully deleted |
