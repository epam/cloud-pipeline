# IDLE tag disappears when at least one of the activity type appears

Test verifies that IDLE tag disappears when at least one of the activity type appears.

**Prerequisites**:
- Admin user
- Perform [4512_2](4512_2.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Runs** page | |
| 3 | At the **Runs** page, click the run launched at step 3 of [4512_2](4512_2.md) case | ***IDLE_GPU***, ***IDLE_CPU*** and ***IDLE*** tags are shown in the **Instance** section | |
| 4 | Click the **SSH** hyperlink | |
| 5 | In the opened tab, enter and perform following commands to load CPU: <br> `sudo dnf config-manager --set-enabled powertools` <br> `sudo dnf install epel-release -y` <br> `sudo dnf install stress -y` <br> `sudo stress --cpu 4 --io 2 --vm 2 --vm-bytes 256M --timeout 1200s` |
| 6 | Close the tab | |
| 7 | Wait until ***IDLE_CPU*** tag disappears from the **Instance** section |  ***IDLE*** tag disappears from the **Instance** section simultaneously with ***IDLE_CPU*** tag |

**After**:
- Stop the run launched at step 3 of [4512_2](4512_2.md) case
- Restore the original values of `system.idle.monitoring.config`.
