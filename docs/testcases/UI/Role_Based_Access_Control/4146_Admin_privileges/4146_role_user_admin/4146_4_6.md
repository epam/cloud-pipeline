# ROLE_USER_ADMIN: give grant permissions to user account

Test verifies that user with role `ROLE_USER_ADMIN` can block user.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- non-admin user (`user2`)
- non-admin user (`user3`)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Find the non-admin `user2` from the prerequisites. Click *Edit* icon opposite the  `user2` name. |  |
| 6 | In an appeared pop-up select **Permissions** tab | |
| 7 | Add non-admin `user3` from the prerequisites and give him allow `READ`, `WRITE`, `EXECUTE` permissions | |
| 8 | Click **Apply** button | <li> Permissions are applyed without error <li> **APPLY** button becomes disabled |
