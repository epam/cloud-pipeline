# Remove one key validation for files in bucket

Test verifies deleting a single file attribute, with a cancel-then-confirm flow.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1174](EPMCMBIBPC-1174.md) case |  |
| 2 | Click the **Delete** icon opposite the **Key** added at step 1 of the [EPMCMBIBPC-1174](EPMCMBIBPC-1174.md) case |  |
| 3 | Click **Cancel** | Nothing changed, the record added at step 1 of the [EPMCMBIBPC-1174](EPMCMBIBPC-1174.md) case is displayed |
| 4 | Repeat step 2 |  |
| 5 | Click **OK** | The record added at step 1 of the [EPMCMBIBPC-1174](EPMCMBIBPC-1174.md) case is removed |
