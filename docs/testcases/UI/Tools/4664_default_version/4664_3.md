# Remove the default version

Test verifies that once the default version is removed, the **latest** version is the default one again.

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least two other versions
- `<version>` is one of the test tool versions, which is not the **latest** one

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **VERSIONS** tab | The `<version>` version has the **default** label |
| 4 | Click the "filled star" button opposite the `<version>` version | <li> The **latest** version has the **default** label <li> The `<version>` version has no **default** label and has a "star" button <li> There is no "star" button opposite the **latest** version |
| 5 | Click the **SETTINGS** tab | No alert about the default version is shown |
| 6 | Click the **Run** button at the top of the tool page | |
| 7 | In an appeared pop-up window click **Launch** button | |
| 8 | At the **Runs** page, click the just-launched run | |
| 9 | Click the **Instance** item | ***Docker image*** field is shown with the test tool's docker image and the `latest` tag |

**After**:
- Stop the run launched at step 7
