# [Negative] CP_CAP_POOL_ID is not offered as a parameter on the launch form

Test verifies that `CP_CAP_POOL_ID`:
- is not shown in the **Parameters** section of a launch form opened for a rerun of a pool run
- can't be used as a name for a manually-added parameter

**Prerequisites**:
- Admin user
- Test tool available in the registry
- The run launched at step 10 of [4960_2](4960_2.md) case, stopped

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Runs** page, the **COMPLETED RUNS** tab | |
| 2 | Open the run from the prerequisites | The **Parameters** section shows `CP_CAP_POOL_ID` |
| 3 | Click the **RERUN** button | The launch form opens |
| 4 | Expand the **Parameters** section | `CP_CAP_POOL_ID` is not shown |
| 5 | Click ***Add parameter*** button in the ***Parameters*** section | |
| 6 | Input `CP_CAP_POOL_ID` into the parameter name field | An error message starting with `Name is reserved` is shown under the field |
| 7 | Clear the parameter name field and input `cp_cap_pool_id` | An error message starting with `Name is reserved` is shown under the field |
