# Check username on tool page

Test verifies that the run log page's Owner name matches the user who launched the tool.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-495](EPMCMBIBPC-495.md) case |  |
| 2 | Open the **Runs** page |  |
| 3 | Click on the tool launched at the [EPMCMBIBPC-495](EPMCMBIBPC-495.md) case |  |
| 4 | Check the name opposite the **Owner** label | The name of the user who ran the tool must equal the **Owner** name on the tool's run log page |
