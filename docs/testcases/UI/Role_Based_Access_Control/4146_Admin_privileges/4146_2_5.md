# ROLE_RUN_ADMIN: ssh run of another user

Test verifies that user with role `ROLE_RUN_ADMIN` has ssh access to run of another user.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_RUN_ADMIN` role
- perform [4146_2_4](4146_2_4.md) case 

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open **Runs** page | |
| 3 | Click on the run launched at step 2 of the Preparations of the [4146_2_4](4146_2_4.md) case (`run4`) | Run log page opens |
| 4 | Wait until **SSH** hyperlink in the right upper corner will appear |  |
| 5 | Click on **SSH** hyperlink | <li> A new tab opens with terminal <li> that terminal contains a line with text `pipeline-{run4_id}` | |
