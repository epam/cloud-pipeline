# Notice with the available node pools on the launch form

Test verifies that:
- the notice under the CPU/RAM/GPU figures lists every active pool of the current region
- a future-dated pool shows its reserved node count and the date it is available until; a default pool shows its node count
- **use this type** selects the pool's entry of the **Pools** group

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Pools from the Preparations of [4960_1](4960_1.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | At the tool page, hover over the **Run v** button | |
| 4 | Click the **Custom settings** button in the list | |
| 5 | Expand the **Exec environment** section | |
| 6 | Set the default region in the ***Cloud Region*** field | The notice under the CPU/RAM/GPU figures is shown: <li> its header is `You have 4 node pools available. Please consider one of the node types below to re-use existing capacity:` <li> 3 pools are listed and the **Show 1 more** link is shown |
| 7 | Click the **Show 1 more** link | The fourth pool is listed |
| 8 | Check the entries of `pool-standard-future` and `pool-shareable-future` | Each one shows the instance type, the region, `N nodes reserved`, `available until <date>` and the pool name |
| 9 | Check the entries of `pool-standard-default` and `pool-shareable-default` | Each one shows the instance type, the region, `N nodes` (without `reserved`) and the pool name |
| 10 | Click **use this type** for `pool-standard-default` | <li> The ***Node type*** field shows the instance type with the `pool-standard-default` tag <li> The entry in the notice shows **selected** |
| 11 | Set the region of `pool-other-region` in the ***Cloud Region*** field | The notice lists `pool-other-region` only, and its header says `1 node pool` |
