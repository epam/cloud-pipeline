# Disabling the digest pinning does not affect the runs that are already pinned

Test verifies that, after the `launch.docker.image.pin.digest` system preference is disabled again
- a run launched while the preference was enabled keeps its ***Docker image digest***
- such a run can be committed, paused and resumed, and keeps its changes after the resume
- a new run is launched without a digest, with the tag, as before

**Prerequisites**:
- Admin user
- Test tool available in the registry

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Launch** tab
5. Find the `launch.docker.image.pin.digest` preference
6. Save the preference value, then set *Enabled* checkbox for `launch.docker.image.pin.digest` preference if needed
7. Click **Save** button if needed
