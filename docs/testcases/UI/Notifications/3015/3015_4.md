# [Manual] Multiple push notifications collapse into a tile with Hide and Read all controls

Test verifies that when several push notifications arrive simultaneously, a subset is shown individually while the rest are collapsed into a single tile that provides **hide** and **read all** controls.

**Prerequisites**:
- Admin user
- Non-admin user (user1) configured as a recipient for multiple enabled email notification templates
- At least 3 system events triggered for user1 in a short time span (so notifications arrive simultaneously)

| Steps | Actions | Expected results |
|:---:|------|---|
| 1 | Login as user1 from the prerequisites | |
| 2 | Trigger multiple system events in quick succession so that 3 or more push notifications are received at once | |
| 3 | Observe the top-right corner of the GUI | A few individual notification tiles are shown; remaining notifications are collapsed into a single tile displaying a count label |
| 4 | Inspect the collapsed tile | The collapsed tile shows: a **label** with the count of collapsed notifications, a **hide** button, and a **read all** button |
| 5 | Click the **hide** button on the collapsed tile | All push notification tiles disappear from the top-right corner. The unread counter near the **Notifications** icon is **not** decreased (notifications remain unread) |
| 6 | Trigger another batch of push notifications. When the collapsed tile appears, click **read all** | All push notification tiles disappear from the top-right corner. The unread counter near the **Notifications** icon decreases by the total number of notifications that were shown |

**After**:
- No cleanup required.
