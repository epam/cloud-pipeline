# ROLE_USER_ADMIN: add admin roles to user

Test verifies that user with role `ROLE_USER_ADMIN` can't add user admin's privilegy.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- non-admin user (`user2`)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Find the non-admin `user2` from the prerequisites. Click *Edit* icon opposite the  `user2` name. |  |
| 6 | Click the *Add role or group* dropdown list. Find in the list the `ROLE_ADMIN` item, select it. Click the *+ Add* button next to the dropdown list | `ROLE_ADMIN` item appears in the roles and groups list |
| 8 | Click **OK** button | <li> Error message `Access denied` appears <li> User edit pop-up remains open |
| 9 | Click **Cancel** button | |
| 10 | Click the **Roles** tab |  |
| 11 | Find the `ROLE_ADMIN`. Click *Edit* icon opposite the `ROLE_ADMIN` name. |  |
| 12 | Input `user2` name into the *Search user* field. Find in the drop-down list the `user2` item, select it. Click the *+ Add user* button next to the dropdown list | `user2` item appears in the users list |
| 13 | Click **OK** button | <li> Error message `Access denied` appears <li> User edit pop-up remains open |
| 14 | Click **Cancel** button | |
| 15 | Repeat steps 4-14 for `ROLE_TOOL_ADMIN`, `ROLE_USER_ADMIN`, `ROLE_PIPELINE_ADMIN`, `ROLE_RUN_ADMIN` | |
