# Remove one key validation

Test verifies deleting a single attribute, with a cancel-then-confirm flow.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-860](EPMCMBIBPC-860.md) case |  |
| 2 | Click the **Delete** icon opposite the **Key** added at step 1 of the EPMCMBIBPC-860 case |  |
| 3 | Click **Cancel** | Nothing changed, the record added at step 1 of the EPMCMBIBPC-860 case is displayed |
| 4 | Repeat step 2 |  |
| 5 | Click **OK** | The record added at step 1 of the EPMCMBIBPC-860 case is removed |
