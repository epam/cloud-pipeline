# "Capacity retries" limits the number of node-up attempts after `Insufficient instance capacity`

Test verifies that when a run's node can't be started due to insufficient capacity, the number of `Insufficient instance capacity.` records in the ***InitializeNode*** task log matches the ***Capacity retries*** value, after which the run fails.

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Node type `type1` of rare compute instance type for the current Cloud Provider which launch attempt can lead to the exception of insufficient capacity of such node types for the Cloud Region
- Perform [4608_2](4608_2.md) case

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab, then the **Launch** tab
4. Save the `launch.run.reschedule.enabled` preference value, then uncheck *Enabled* checkbox for `launch.run.reschedule.enabled` preference if needed. Click **Save** button if needed
5. Open the **Tools** page, select the test tool from the prerequisites
6. Click the **SETTINGS** tab
7. Expand the **EXECUTION ENVIRONMENT** section
8. Save the ***Allow reschedule to different region in case of insufficient capacity*** value, then select ***Not Configured*** option if needed. Click **SAVE** button if needed

**After**:
- Restore the `launch.run.reschedule.enabled` preference value saved at step 4 of the preparations
- Restore the ***Allow reschedule to different region in case of insufficient capacity*** value saved at step 8 of the preparations
