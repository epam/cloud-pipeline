# Validation of description for detached configuration

Test verifies that a description entered when creating a detached configuration is preserved.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Hover over **+ Create v**, click **Configuration** item |  |
| 3 | Specify a valid configuration name in the appeared pop-up window |  |
| 4 | Enter a configuration description |  |
| 5 | Click **CREATE** button |  |
| 6 | Click on the edit icon opposite the just-created configuration | The value entered at step 4 is displayed in the **Configuration description** field |
