# A user with read-only access can select a folder and download it as an archive

Test verifies that:
- a user with only **Read** permission on an AWS S3 storage sees a checkbox next to every folder, and can download a selected folder as an archive
- the **Select page** button picks up those folders as well as the files
- a user holding the **ROLE_STORAGE_READER** role sees the same on a storage they have no explicit permission on
- such a user still cannot change anything in the storage - the selection dropdown offers no **Remove** item for the selected folder
- a folder has no checkbox for such a user on a storage where **Download archive** is not offered at all

**Prerequisites**:
- Admin user
- Non-admin user, without the **ROLE_STORAGE_READER** role
- An AWS S3 object storage `storage1` exists
- An NFS storage `storage2`, on a file share mounted as **SMB** or **Lustre**, exists

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open `storage1`, create a folder `folder1` in it, open `folder1` and create a file `testfile1.txt` in it. Return to the root of `storage1` and create a file `testfile2.txt` there.
3. Open the permissions of `storage1`, add the non-admin user from the prerequisites and allow **Read** to that user only (leave **Write** and **Execute** unchecked)
4. Open `storage2`, create a folder `folder2` in it
5. Open the permissions of `storage2`, add the non-admin user from the prerequisites and allow **Read** to that user only
6. Logout

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open the **Library** page and click `storage1` in the library-tree | <li> `folder1` and `testfile2.txt` are listed <li> there is a checkbox next to the `folder1` name <li> **+Create** and **Upload** buttons are not visible |
| 3 | Click the **Select page** button | The **2 items selected** button appears - the folder is selected alongside the file |
| 4 | Click the **2 items selected** button, then click the **Clear selection** item | The selection is cleared |
| 5 | Click the checkbox next to the `folder1` name | The **1 item selected** button appears |
| 6 | Click the **1 item selected** button | <li> the dropdown contains a **Download archive** item <li> the dropdown contains no **Remove** item |
| 7 | Click the **Download archive** item | The **Download archive** pop-up appears, with the **Archive name** field pre-filled with `folder1.zip` |
| 8 | Click the **OK** button | A notification appears, saying that the archive download has been queued |
| 9 | Click the button with the **grid** icon among the buttons at the top right of the storage view, and choose the **Show downloads** item | The **Downloads** window is opened and lists a task for `folder1.zip (1 item)` |
| 10 | Wait until that task reaches a finished, successful state, then click the **Download** button on its row | The `folder1.zip` archive is downloaded and contains `testfile1.txt` |
| 11 | Close the **Downloads** window. Open `storage2` from the library-tree | <li> `folder2` is listed <li> there is **no** checkbox next to the `folder2` name |
| 12 | Logout and login as the admin user from the prerequisites | |
| 13 | Open the **Settings** page >> select the "**USER MANAGEMENT**" tab | |
| 14 | In the users list click the **Edit** button next to the non-admin user from the prerequisites | |
| 15 | In the dropdown list next to the "**Add role or group**" field select the `ROLE_STORAGE_READER` item. Click the "**+ Add**" button. Save the changes. | |
| 16 | Open the permissions of `storage1` and delete the non-admin user from the prerequisites from the permissions list | The user now has no explicit permission on `storage1` |
| 17 | Logout and login as the non-admin user from the prerequisites | |
| 18 | Open `storage1` from the library-tree | <li> `folder1` is listed <li> there is a checkbox next to the `folder1` name |
| 19 | Click the checkbox next to the `folder1` name, then click the **1 item selected** button | <li> the dropdown contains a **Download archive** item <li> the dropdown contains no **Remove** item |
| 20 | Click the **Download archive** item, then the **OK** button in the appeared pop-up | A notification appears, saying that the archive download has been queued |

**After**: as the admin user, delete `folder1` and `testfile2.txt` from `storage1` and `folder2` from `storage2`, remove the non-admin user from the prerequisites from the permissions of `storage2`, and remove the `ROLE_STORAGE_READER` role from that user.
