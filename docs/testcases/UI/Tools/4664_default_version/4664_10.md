# Deleting a version of the same image removes the default version

Test verifies that a Docker registry deletes all the versions of the same image together, so that deleting another version, which has the same digest as the default one, removes the default version as well, the deletion confirmation warns about it, and the **latest** version is the default one again.

**Prerequisites**:
- Admin user
- Test tool with the **latest** version
- `<version>` and `<alias>` are two versions of the test tool pushed from the same image (e.g. `docker tag <image> <registry>/<group>/<tool>:<version>` and `...:<alias>`, then `docker push` of both), which are not the **latest** one, and which the platform has registered with their digests. No other version of the test tool, the **latest** one included, is pushed from `<image>`: the registry deletes every version of an image together

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page and select the test tool from the prerequisites | |
| 2 | Click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | <li> The `<version>` version has the **default** label <li> The `<version>` and `<alias>` versions show the same ***Digest*** |
| 3 | Click the **Delete** button opposite the `<alias>` version | The confirmation contains the `You are going to delete the default version of the tool.` warning and the `The default version <version> refers to the same image, so the registry deletes it as well.` message |
| 4 | Click **Delete** | <li> Both the `<alias>` and the `<version>` versions disappear from the list <li> The **latest** version has the **default** label |
| 5 | Reload the page. Click the **VERSIONS** tab, and if the **VIEW UNSCANNED VERSIONS** button is shown, click it | <li> The **latest** version has the **default** label <li> There is no "star" button opposite the **latest** version |
