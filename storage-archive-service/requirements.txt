# Runtime dependencies, pinned. Keep in step with `install_requires` in setup.py - that file is what

# `workflows/pipe-common` and is not published to an index: a container installs it from the API
# distribution, exactly as `deploy/docker/cp-storage-lifecycle-service/Dockerfile` does, and a
# developer installs it from the checkout - see the README. It brings its own pinned `requests`,
# which is why this file no longer pins one.
