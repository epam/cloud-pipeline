# [MANUAL] Upload files on shared bucket

Test verifies that an unauthenticated visitor of a shared-bucket link can create a folder and upload a file into it.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform [EPMCMBIBPC-2402](EPMCMBIBPC-2402.md) case |  |
| 2 | Click the **+ Create** button -> select **Folder** item in the list |  |
| 3 | Enter a valid folder name in the appeared pop-up |  |
| 4 | Click the **OK** button | The folder with the name specified at step 3 is displayed in the list |
| 5 | Click the **Upload** button |  |
| 6 | Select the file and confirm the upload in the appeared pop-up | The file selected at step 6 is displayed in the list |
