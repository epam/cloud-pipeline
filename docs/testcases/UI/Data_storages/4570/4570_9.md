# Remove deletes only the selected items the user may write to

Test verifies that:
- when a user may write to only some of the selected items, the **Remove** item is still offered and shows an info icon
- the icon's tooltip and the confirm dialog say how many items will be removed
- **Remove** deletes only the items the user may write to, and leaves the rest

**Prerequisites**:
- Admin user
- Non-admin user, without the **ROLE_STORAGE_ADMIN** role

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create an AWS S3 object storage `storage1` with the "**Fine-grained permissions**" checkbox set
3. Open `storage1` and create two folders `folder1` and `folder2` in it
4. Open the permissions of `storage1`, add the non-admin user from the prerequisites and allow **Read** to that user only
5. Click the checkbox next to the `folder1` name, click the **1 item selected** button and choose the **Manage permissions** item
6. In the appeared pop-up, click the button with the **user-add** icon, select the non-admin user from the prerequisites and click **Select**. Set the **Write access** checkbox for that user and click **Save**
7. Clear the selection. Click the checkbox next to the `folder2` name, click the **1 item selected** button and choose the **Manage permissions** item
8. In the appeared pop-up, click the button with the **user-add** icon, select the non-admin user from the prerequisites and click **Select**. Leave the **Write access** checkbox unset and click **Save**
9. Logout

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open `storage1` from the library-tree | `folder1` and `folder2` are listed, each with a checkbox |
| 3 | Click the checkbox next to the `folder2` name, then click the **1 item selected** button | The dropdown contains no **Remove** item |
| 4 | Close the dropdown. Click the checkbox next to the `folder1` name | The **2 items selected** button appears |
| 5 | Click the **2 items selected** button | The dropdown contains a **Remove** item with an info icon next to it |
| 6 | Hover over the info icon | A tooltip appears: `Only items you have write access to will be removed (1 of 2).` |
| 7 | Click the **Remove** item | A confirm pop-up appears with the title `Remove 1 of 2 selected items?` |
| 8 | Click the **OK** button | <li> `folder1` is no longer listed <li> `folder2` is still listed <li> the selection is cleared |

**After**: as the admin user, delete `storage1`
