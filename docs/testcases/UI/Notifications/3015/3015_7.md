# [Manual] Muting notifications prevents push pop-ups but notifications still appear in the Notifications section

Test verifies that when a user enables the **Mute email notifications** setting in their profile, new push notifications no longer appear as pop-up tiles in the GUI, but are still recorded and visible in the **Notifications** section.

**Prerequisites**:
- Admin user
- Non-admin user (user1) configured as a recipient for at least one enabled email notification template

| Steps | Actions | Expected results |
|:---:|------|---|
| 1 | Login as user1 from the prerequisites | |
| 2 | Open **System settings**. Select the **My profile** tab | |
| 3 | In the **Profile** sub-tab, tick the checkbox **Mute email notifications** | The checkbox is checked |
| 4 | Trigger a system event that normally fires a push notification for user1 | |
| 5 | Observe the top-right corner of the GUI for the duration that a push tile would normally be shown | No push notification tile appears in the top-right corner of the GUI |
| 6 | Click the **Notifications** icon in the main menu | The **Notifications** section opens |
| 7 | Inspect the unread notifications list | The notification triggered in step 4 is present in the unread list with correct **Title**, **Text**, and **Created date** |

**After**:
- Untick the **Mute email notifications** checkbox in user1's profile to restore the original setting.
