# Delete the default version

Test verifies that
- the deletion confirmation warns that the default version of a tool is going to be deleted
- once the default version is deleted, the **latest** version is the default one again

**Prerequisites**:
- Admin user
- Test tool with the **latest** version

**Preparations**:
1. Login as the admin user from the prerequisites
2. Launch the test tool, and once the run is **Running**, commit it into the test tool with a new `<version>` version name (see [10.4. Edit a Tool](../../../../md/manual/10_Manage_Tools/10.4._Edit_a_Tool.md#commit-a-tool)). Stop the run
3. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **VERSIONS** tab | The `<version>` version has the **default** label |
| 4 | Click the **Delete** button opposite the **latest** version | The confirmation doesn't contain the `You are going to delete the default version of the tool.` warning |
| 5 | Click **Cancel** | |
| 6 | Click the **Delete** button opposite the `<version>` version | The confirmation contains the `You are going to delete the default version of the tool.` warning |
| 7 | Click **Delete** | <li> The `<version>` version disappears from the list <li> The **latest** version has the **default** label |
| 8 | Reload the page and click the **VERSIONS** tab | The **latest** version has the **default** label |
