# Set a version as the default one

Test verifies that
- a user with the **WRITE** permission sets a version as the default one at the **Versions** tab
- the default version is marked with the **default** label and is launched by the **Run** button at the top of the tool page
- the **Settings** tab shows and saves the settings of the default version

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least two other versions, without a default version set
- `<version>` is one of the test tool versions, which is not the **latest** one

**Preparations**:
1. Login as the admin user from the prerequisites

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **VERSIONS** tab | |
| 4 | Click the "star" button opposite the `<version>` version | <li> The `<version>` version has the **default** label <li> The **latest** version has no **default** label <li> A "star" button is shown opposite the **latest** version |
| 5 | Hover over the **default** label | Tooltip `This version is launched, if a version is not specified` appears |
| 6 | Hover over the "filled star" button opposite the `<version>` version | Tooltip `Remove default` appears |
| 7 | Reload the page and click the **VERSIONS** tab | The `<version>` version still has the **default** label |
| 8 | Click the **SETTINGS** tab | Alert `Execution environment settings will be applied to the default version <version>.` is shown |
| 9 | Change the **Instance type** in the **Execution environment** section and click **SAVE** | |
| 10 | Open the `<version>` version and click its **SETTINGS** tab | The **Instance type** set at step 9 is shown |
| 11 | Return to the test tool page and click the **Run** button at the top of the page | |
| 12 | In an appeared pop-up window click **Launch** button | |
| 13 | At the **Runs** page, click the just-launched run | |
| 14 | Click the **Instance** item | <li> ***Docker image*** field is shown with the test tool's docker image and the `<version>` tag <li> The instance type is the one set at step 9 |

**After**:
- Stop the run launched at step 12
- Restore the `<version>` version settings changed at step 9
- Remove the default version of the test tool: click the "filled star" button opposite the `<version>` version at the **VERSIONS** tab
