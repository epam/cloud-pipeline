# Groups with the same priority keep the preference order

Test verifies that if several groups in the `misc.groups.ui.preferences` preference have the same `priority`, the settings of the group listed first in the preference are applied.

**Prerequisites**:
- Admin user
- Non-admin user `<user>` that is a member of 2 groups: `<group_1>` and `<group_2>`
- `<user>`, `<group_1>` and `<group_2>` have no `ui-home-page` attribute

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Misc** tab and find the `misc.groups.ui.preferences` preference
5. Save the current value of the preference
6. Set the preference value to:
```
{
  "<group_1>": {"priority": 5, "ui-home-page": "library"},
  "<group_2>": {"priority": 5, "ui-home-page": "runs"}
}
```
7. Click **Save** button
8. Logout

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin user `<user>` from the prerequisites | The **Library** page opens |
| 2 | Open the platform root address `<platform_url>` | The **Library** page opens |

**After**:
- Restore the saved value of the `misc.groups.ui.preferences` preference
