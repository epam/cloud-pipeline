# Validation of select entity

Test verifies that the Root entity type combobox offers Sample and SampleSet.

**Prerequisites**:
- Perform the [EPMCMBIBPC-1588](EPMCMBIBPC-1588.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Library** page, navigate to the detached configuration created at step 5 of the [EPMCMBIBPC-1588](EPMCMBIBPC-1588.md) case |  |
| 2 | Click the **Root entity type** combobox | The list that appears for the **Root entity type** combobox contains the **Sample** and **SampleSet** items |
| 3 | Select **Sample** in the list that appears |  |
