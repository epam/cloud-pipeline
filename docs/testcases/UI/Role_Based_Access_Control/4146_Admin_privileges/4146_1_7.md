# ROLE_PIPELINE_ADMIN: delete existing pipeline

Test verifies that user with role `ROLE_PIPELINE_ADMIN` can clone existing pipeline to folder if has permissions on this folder.

**Prerequisites**:
- admin user
- non-admin user with `ROLE_PIPELINE_ADMIN` role

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create pipeline (`pipeline3`)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open **Library** | |
| 3 | Open `pipeline3` | |
| 4 | Hover over *Gear-icon* in the upper right corner of the page. Select *Edit* item | *Edit pipeline info* pop-up opens |
| 5 | Click **DELETE** button in an appeared pop-up window | |
| 6 | Click **Delete** button in an appeared pop-up window | Pipeline `pipeline3` doesn't display in the library-tree and objects list |

**After:**
- Delete pipelines and folder created at [4146_1_1](4146_1_1.md) - [4146_1_6](4146_1_6.md) cases
