# File download validation

Test verifies downloading a file keeps its name and size.

**Prerequisites**:
- A storage with files exists

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Open the folder that contains at least one file |  |
| 4 | Click on the download icon opposite the file name | A file with the same name is downloaded. Its size is the same as displayed opposite the file name on the storage's page |
