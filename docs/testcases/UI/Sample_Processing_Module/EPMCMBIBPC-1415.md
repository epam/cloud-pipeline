# Sort, search by metadata and metadata tables customization

Test verifies sorting the Sample metadata table by the ID column in both directions and clearing the sort.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1412](EPMCMBIBPC-1412.md) case |  |
| 2 | Click on the **Metadata** object in the library tree |  |
| 3 | Click on the **Sample** object |  |
| 4 | Click the **ID** column header | A decreasing-order icon appears, and the **ID** column is sorted in decreasing order |
| 5 | Click the **ID** column header | An increasing-order icon appears, and the **ID** column is sorted in increasing order |
| 6 | Click the **ID** column header | The sorting icon disappears, and the list of entities is unsorted |
