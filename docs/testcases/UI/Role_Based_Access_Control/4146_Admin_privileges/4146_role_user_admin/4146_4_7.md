# ROLE_USER_ADMIN: edit parameters for existing user group

Test verifies that user with role `ROLE_USER_ADMIN` can 
- see all existing user groups in the Groups list
- edit all parameters for user group.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- non-admin user (`user2`)
- user group (`user_group1`)

**Preparations**:
1. Login as admin user from the prerequisites
2. Create object storage `storage2`
3. Give all permissions on `storage2` to the `user1` 

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Groups** tab | <li> **+ Create group** button is shown at the top of the Groups table <li> All user groups are shown in the Groups table <li> *Edit* and *Remove* icons are shown for the each group in the table |
| 5 | Find the `user_group1` from the prerequisites. Click *Edit* icon opposite the `user_group1` name. | ***Edit Group*** pop-up opens that contains: <li> **Block** button is active <li> *Default data storage*, *User's Roles and groups* , *Launch option* fields and *Attributes* are editable |
| 6 | Click the *Default data storage* dropdown list. Find in the list `storage2`, select it. | `storage2` is shown in the *Default data storage* field |
| 7 | Input `user2` name into *Search user* field. Find in the dropdown list the `user2` item, select it. Click the *+ Add user* button next to the dropdown list | `user2` item appears in the users list |
| 8 | In the **Attributes** section click ***+ Add*** button. Add attribute `key1` with `value1`. Click **Add** button. | |
| 9 | In the ***Launch options** section fill all fields with correct values. | |
| 10 | Click **OK** button | |
| 11 | In the Groups list click *Edit* icon opposite the `user_group1`. | ***Edit Group*** pop-up opens. All parameters specified at steps 6-9 are shown in the corresponding fields |

**After:**
- Restore all `user_group1` parameters to initial stage.
