# ROLE_STORAGE_ADMIN: operations with existing storage

Test verifies that:
User with role STORAGE_ADMIN 
- has a full access to all storages registered in the system
- shall be able view/edit/delete any storage

**Prerequisites**:
- Admin user
- Non-admin user

**Preparations**
1. Login as admin user from the prerequisites
2. Create the object storage `storage1`. Open `storage1` and create file `testfile1.txt`.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as non-admin user from the prerequisites | |
| 2 | Open the **Library** page | `storage1` isn't visible |
| 3 | Logout and login as admin user from the prerequisites | |
| 4 | Open the **Settings** page >> Select the "**USER MANAGEMENT**" tab | |
| 5 | In the users list click the **Edit** button next to non-admin user from the prerequisites | |
| 6 | In the dropdown list next to the field "**Add role or group**" select `ROLE_STORAGE_ADMIN` item. Click the "**+ Add**" button. Save changes. | |
| 7 | Logout and login as non-admin user from the prerequisites | |
| 8 | Open the **Library** page | `storage1` is visible for non-admin user |
| 9 | Click **Rename** button opposite `storage1` storage | |
| 10 | Specify a new value in the _Alias_ field. Click **SAVE** button | `storage1` name has changed |
| 11 | Open `storage1` | <li> **+Create** and **Upload** buttons are visible <li> `testfile1.txt` is visible |
| 12 | Click **Remove** button near the `testfile1.txt` name and confirm removing | File `testfile1.txt` is removed |
| 13 | Hover over **+Create** button and select *File* option | |
| 14 | Specify `testfile3.txt` **Name** value and click **OK** button | File `testfile3.txt` is shown in storage |
| 15 | Click the **gear** icon in the right upper corner | |
| 16 | Click the **Edit** button in the aappeared list | |
| 17 | Click **Delete** button. Confirm deletion | `storage1` disappears |
