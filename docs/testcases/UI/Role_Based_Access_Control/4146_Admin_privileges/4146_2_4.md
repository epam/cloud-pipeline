# ROLE_RUN_ADMIN: sharing run of another user

Test verifies that user with role `ROLE_RUN_ADMIN` can sharing run of another user.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_RUN_ADMIN` role
- non-admin user (`user2`)

**Preparations**:
1. Login as the admin user from the prerequisites.
2. Select the test tool and launch a tool with default settings and `On-demand` price type (`run4`).

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open **Runs** page | |
| 3 | Click on the run launched at step 2 of the Preparations (`run4`) | Run log page opens |
| 4 | Click on *Not shared (click to configure)* link | |
| 5 | In appeared pop-up click on ***Add user*** icon | |
| 6 | In appeared pop-up specify the name of non-admin user `user2`, click **OK** button | |
| 7 | Click **OK** button | Next to *Share with* label, link with user name specified at step 6 is displaying |
