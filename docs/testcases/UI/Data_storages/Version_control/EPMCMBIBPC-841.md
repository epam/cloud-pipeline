# Delete file that has delete marker

Test verifies permanently deleting a file that already carries a delete marker.

**Prerequisites**:
- Perform [EPMCMBIBPC-815](EPMCMBIBPC-815.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on the `-` button in front of the file name that was deleted in the [EPMCMBIBPC-815](EPMCMBIBPC-815.md) case |  |
| 2 | Click on the delete icon opposite the file name |  |
| 3 | Click **Cancel** button in the appeared pop-up window |  |
| 4 | Repeat step 2 |  |
| 5 | Click **OK** button in the appeared pop-up window | The file is permanently deleted |
