# Folder navigation in the address row

Test verifies navigating to a folder by typing its path into the storage address row.

**Prerequisites**:
- The storage created in [EPMCMBIBPC-448](EPMCMBIBPC-448.md) is selected

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on the storage path |  |
| 2 | Input a valid path to a folder from this storage into the appeared field |  |
| 3 | Press **Enter** | The content of the entered folder is displayed |
