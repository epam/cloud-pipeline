# ROLE_USER_ADMIN: create and delete user

Test verifies that user with role `ROLE_USER_ADMIN` can create and delete user.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Click the **+ Create user** button | |
| 6 | In the appeared pop up specify the valid new user name into the *Name* field (e.g. `TEST_USER1_4146`). | |
| 7 | Click the **Create** button | |
| 8 | Enter into the search field the user name specified at step 6. Press the **Enter** key | The record with the name specified at step 6 appears in the Users table |
| 9 | Click *Edit* icon opposite the  `user2` name. | |
| 10 | click the **DELETE** button. Click the **OK** button to confirm the deleting | |
| 11 | Click the **OK** button | |
| 12 | Enter into the search field the user name specified at step 6. Press the **Enter** key | Search results are empty |
