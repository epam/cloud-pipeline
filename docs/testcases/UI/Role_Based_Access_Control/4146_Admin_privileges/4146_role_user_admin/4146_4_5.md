# ROLE_USER_ADMIN: block/unblock user

Test verifies that user with role `ROLE_USER_ADMIN` can block/unblock user.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- non-admin user (`user2`)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Find the non-admin `user2` from the prerequisites. Click *Edit* icon opposite the  `user2` name. |  |
| 6 | Click the **BLOCK** button in the left-bottom corner. Click the **OK** button to confirm the blocking | |
| 7 | Click the **OK** button | |
| 8 | Logout. Try to login to the platform as the non-admin `user2` from the Prerequisites | The page with the authorization error appears |
| 9 | Repeat steps 1-5 | |
| 10 | Click the **UNBLOCK** button in the left-bottom corner, in the appeared popup click the **OK** button to confirm the blocking | |
| 11 | Click the **OK** button | |
| 12 | Logout. Try to login to the platform as the non-admin `user2` from the Prerequisites | The main Dashboard appears |
