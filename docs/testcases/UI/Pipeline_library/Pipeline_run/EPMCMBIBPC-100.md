# Launch pipeline

Test verifies creating a pipeline from the PYTHON template and launching it, checking the run appears on the **ACTIVE RUNS** tab.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click **Create** button in the right upper corner |  |
| 3 | Hover over **Pipeline** item, select the PYTHON pipeline template |  |
| 4 | Enter the pipeline name in the pop-up window, click **CREATE** button |  |
| 5 | Click **Run** button opposite the name of the created pipeline |  |
| 6 | Set launch options |  |
| 7 | Click **Launch** button |  |
| 8 | Click **Launch** button in the pop-up window | <li> the **RUNS** page opens, the **ACTIVE RUNS** tab is active <li> there is at least one pipeline with a **waiting** indicator; the **Run** field shows the pipeline's name with ID, the **Pipeline** field shows the created pipeline's name and version name, the **Started** field shows the time and date |
