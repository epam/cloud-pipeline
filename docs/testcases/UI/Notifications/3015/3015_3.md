# [Manual] Closing a push notification via the cross button marks it as read

Test verifies that dismissing a push notification tile using the cross (×) button marks it as read and decrements the unread counter, without requiring the user to open the full pop-up.

**Prerequisites**:
- Admin user
- Non-admin user (user1) with at least one unread push notification already received

| Steps | Actions | Expected results |
|:---:|------|---|
| 1 | Login as user1 from the prerequisites | |
| 2 | Wait for or trigger a push notification tile to appear in the top-right corner | A push notification tile is visible in the top-right corner |
| 3 | Note the current unread counter value near the **Notifications** icon | |
| 4 | Click the **cross (×)** button on the push notification tile (do not click the tile body) | The notification tile disappears |
| 5 | Inspect the **Notifications** icon in the main menu | The unread counter decreases by 1 |
| 6 | Open the **Notifications** section from the main menu. Switch to the **Read** notifications list | The notification dismissed in step 4 is present in the **Read** notifications list |

**After**:
- No cleanup required.
