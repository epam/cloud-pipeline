Test verifies that canceling the multi-folder deletion pop-up leaves the storage content unchanged.

| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Hover the mouse pointer over the **+ Create v** button, select **Folder** item |  |
| 4 | Input a valid value into the **Name** field in the pop-up window |  |
| 5 | Click **OK** button |  |
| 6 | Repeat steps 3-5 |  |
| 7 | Check the checkbox near the folder created after step 5 |  |
| 8 | Check the checkbox near the folder created after step 6 |  |
| 9 | Click the appeared **Remove all selected** button |  |
| 10 | Click **Cancel** button in the appeared pop-up window | The list of files and folders in the storage doesn't change |
| 11 | Repeat step 9 |  |
| 12 | Click **OK** button in the appeared pop-up window |  |
