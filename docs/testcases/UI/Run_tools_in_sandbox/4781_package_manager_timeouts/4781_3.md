# The package manager time limits do not affect a usual run start

Test verifies that a run launched with the default settings starts as before: no package manager call reaches its time limit, and the run log has no warnings about the time limits.

**Prerequisites**:
- Admin user
- Two test tools available in the registry: one based on Ubuntu, as in [4781_1](4781_1.md), and one based on CentOS
- The `launch.pre.common.commands` preference has no `test_apt_hang_once` and `test_yum_hang_once` entries: the cases [4781_1](4781_1.md) and [4781_2](4781_2.md) restored it

**Preparations**:
1. Login as the admin user from the prerequisites

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the Ubuntu test tool from the prerequisites | |
| 3 | Click the **Run** button | |
| 4 | In an appeared pop-up window click **Launch** button | |
| 5 | At the **Runs** page, click the just-launched run | |
| 6 | Wait until the **SSH** hyperlink appears. Click the *Console* task | Log doesn't contain: <li> `did not finish in` <li> `is not a number of seconds` <li> `No usable timeout command` |
| 7 | Repeat steps 1-6 for the CentOS test tool from the prerequisites | |

**After**:
- Stop the runs launched at step 4
