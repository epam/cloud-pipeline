# ROLE_USER_ADMIN: edit parameters for existing user

Test verifies that user with role `ROLE_USER_ADMIN` can 
- see all existing users in the Users list
- edit all parameters for user.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- non-admin user (`user2`)

**Preparations**:
1. Login as admin user from the prerequisites
2. Create object storage `storage1`
3. Give all permissions on `storage1` to the `user1` 

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab | **USER MANAGEMENT** page opens that contains ***Users***, ***Groups***, ***Roles***, ***Usage report*** tabs |
| 4 | Click the **Users** tab | <li> **+ Create user**, **Import users**, **Export users** buttons are shown at the top of the Users table <li> All users are shown in the Users table <li> Statuse cyrcle and *Edit* icon are shown for the each user in the table |
| 5 | Find the non-admin `user2` from the prerequisites. Click *Edit* icon opposite the  `user2` name. | ***Edit User*** pop-up opens that contains: <li> **Impersonate**, **Delete** and **Block** buttons are active <li> *Default data storage*, *User's Roles and groups* , *Launch option* fields and *Attributes* are editable |
| 6 | Click the *Default data storage* dropdown list. Find in the list `storage1`, select it. | `storage1` is shown in the *Default data storage* field |
| 7 | Click the *Add role or group* dropdown list. Find in the list the `ROLE_PIPELINE_MANAGER` item, select it. Click the *+ Add* button next to the dropdown list | `ROLE_PIPELINE_MANAGER` item appears in the roles and groups list |
| 8 | In the **Attributes** section click ***+ Add*** button. Add attribute `key1` with `value1`. Click **Add** button. | |
| 9 | Click the *configure* button next to the *Can run as this user:*. Click the *Add user* button on the *Share with users and groups* pop up. Specify the admin name from prerequisites. Click the **OK** button. | |
| 10 | In the ***Launch options** section fill all fields with correct values. | |
| 11 | Click **OK** button | |
| 12 | In the users list click *Edit* icon opposite the `user2`. | ***Edit User*** pop-up opens. All parameters specified at steps 6-10 are shown in the corresponding fields |

**After:**
- Restore all `user2` parameters to initial stage.
