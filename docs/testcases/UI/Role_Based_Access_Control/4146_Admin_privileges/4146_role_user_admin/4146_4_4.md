# ROLE_USER_ADMIN: impersonate user

Test verifies that user with role `ROLE_USER_ADMIN` can impersonate user.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- non-admin user (`user2`)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Find the non-admin `user2` from the prerequisites. Click *Edit* icon opposite the  `user2` name. |  |
| 6 | In an appeared pop-up click on the **Impersonate** button | <li> Page reloads and the **Dashboard** page opens |
| 7 | Open the **Settings** page | |
| 8 | Open the **My Profile** tab | Profile of non-admin `user2` is shown on the page |
| 9 | Click **Stop Impersonation** button | <li> Page reloads and the **Dashboard** page opens <li> **Stop Impersonation** button disappears from the left navigation panel |
| 10 | Repeat steps 7 - 8 | Profile of non-admin `user1` is shown on the page |
