# ROLE_RUN_ADMIN: pausing, resuming and terminating paused run of another user

Test verifies that user with role `ROLE_RUN_ADMIN` can pausing, resuming and terminating paused run of another user.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_RUN_ADMIN` role

**Preparations**:
1. Login as the admin user from the prerequisites.
2. Select the test tool and launch a tool with default settings and `On-demand` price type (`run3`).

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open **Runs** page | |
| 3 | Wait until ***PAUSE*** button appears opposite the run launched at step 2 of the Preparations (`run3`) | |
| 4 | Click ***PAUSE*** button opposite the `run3`. In an appeared pop-up click ***PAUSE*** button | `run3` status is being changed to ***PAUSING*** |
| 5 | Wait until ***RESUME*** button appears opposite the `run3` | |
| 6 | Click ***RESUME*** button opposite `run3`. In an appeared pop-up click ***RESUME*** button | `run3` status is being changed to ***RESUMING*** |
| 7 | Click on `run3` name | Run log page opens |
| 8 | Wait until ***PAUSE*** button appears | |
| 9 | Click ***PAUSE*** button opposite the `run3`. In an appeared pop-up click ***PAUSE*** button |
| 10 | Wait until ***TERMINATE*** button appears | |
| 11 | Click ***TERMINATE*** button. In an appeared pop-up click ***TERMINATE*** button | `run3` is complited with *Stopped* status |
