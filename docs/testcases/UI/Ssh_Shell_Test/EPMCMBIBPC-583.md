# Validate of SSH access link is available

Test verifies that the SSH link appears on a launched tool's run log page.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open **Tools** page |  |
| 2 | Select tool |  |
| 3 | Click **Run** button |  |
| 4 | Click **Launch** in the appeared pop-up |  |
| 5 | Click on the just-launched pipeline on the **ACTIVE RUNS** tab of the **Runs** page to open the **RUN LOGS** page | After ~5 minutes, the SSH link appears in the right upper corner |
