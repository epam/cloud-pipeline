# A rerun of a pinned run is pinned to the digest its tag points to at the rerun

Test verifies that, with the `launch.docker.image.pin.digest` system preference enabled
- a run keeps its ***Docker image digest*** after its version (tag) is moved to another image
- a **RERUN** of that run resolves the digest again: the new run is pinned to the image the tag points to now, and runs that image

**Prerequisites**:
- Admin user
- Test tool available in the registry
- If the tool scanning is enabled, the `security.tools.policy.deny.not.scanned` system preference is disabled, so that a version which is not scanned yet can be launched

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Launch** tab
5. Find the `launch.docker.image.pin.digest` preference
6. Save the preference value, then set *Enabled* checkbox for `launch.docker.image.pin.digest` preference if needed
7. Click **Save** button if needed
8. Launch the test tool. Click the **COMMIT** hyperlink of the run, select the test tool's registry and tools group in the **Docker image** field, make sure the tool name is the test tool's name, and replace the value of the **Version** field with `digest-test`. Click **COMMIT** button, wait until the label `COMMIT SUCCEEDED` appears, then stop the run
