# A default version removed outside the platform

Test verifies that, when the default version is removed from the Docker registry outside of Cloud Pipeline,
- the **default** label moves to the **latest** version, and its tooltip tells that the default version does not exist
- `pipe run` of the tool image without a tag stops, since the missing default version is checked
- the **Remove default** button opposite the **latest** version removes the missing default version

**Prerequisites**:
- Admin user
- Test tool with the **latest** version
- `<version>` is a version of the test tool, pushed for this test from an image of its own, which no other version of the test tool is pushed from (e.g. committed from a run of the test tool, as in [4664_4](4664_4.md) (preparation 2)): the registry deletes every version of an image together
- `<version>` can be deleted directly in the Docker registry (e.g. with the registry API: `DELETE /v2/<group>/<tool>/manifests/<digest>`)
- `pipe` CLI is installed and configured for the admin user

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Delete the `<version>` version directly in the Docker registry, outside of Cloud Pipeline | |
| 2 | Open the **Tools** page, select the test tool from the prerequisites, click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | <li> The `<version>` version isn't shown <li> The **latest** version has the **default** label |
| 3 | Hover over the **default** label | Tooltip `The default version <version> does not exist, so the latest version is used` appears |
| 4 | Hover over the "filled star" button opposite the **latest** version | Tooltip `Remove default: version <version> does not exist` appears |
| 5 | Run `pipe run -di <registry>/<group>/<tool> -it <instance type> -id 30 -cmd "sleep infinity" -y`, where `<registry>/<group>/<tool>` is the test tool image without a tag | `pipe` prints `Docker image <registry>/<group>/<tool> has no tag "<version>"` with the list of the available tags, and exits without launching a run |
| 6 | Click the "filled star" button opposite the **latest** version | There is no "star" button opposite the **latest** version anymore |
| 7 | Hover over the **default** label | Tooltip `A default version is not set, so the latest version is used` appears |
