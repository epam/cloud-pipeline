# Validation of inactive notifications

Test verifies that unsetting Active on all notifications stops them from being displayed.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click the system-settings button (gear icon in the left panel) |  |
| 2 | Click the **System events** tab |  |
| 3 | Unset the **Active** checkbox opposite all notifications in the list |  |
| 4 | Click **Refresh** |  |
| 5 | Wait 1 minute | Notifications are not displayed |
