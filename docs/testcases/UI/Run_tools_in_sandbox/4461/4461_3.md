# Run launch is blocked when user has insufficient credits

Test verifies that the platform prevents a user from launching a run when their Platform Usage Credits balance is below the minimum required to start a run.

**Prerequisites**:
- admin user
- non-admin user (user1)
- test tool available in the registry
- Platform Usage Credits feature enabled

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page, navigate to **Platform Usage Credits**
3. Set user1's credit balance to `0` (or below the minimum launch threshold)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Logout and login as user1 from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Click the **Run** button | |
| 5 | Click **Launch** on the run configuration form | Run launch is **blocked**. An error or warning message is displayed indicating that the user has insufficient credits to launch the run |
| 6 | Navigate to the **Runs** page | No new run was created for user1 |

**After**:
- Restore user1's credit balance to the default value.
