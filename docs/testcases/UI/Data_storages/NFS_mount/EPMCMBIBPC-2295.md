# Remove not empty folder on NFS mount

Test verifies that deleting a non-empty folder on an NFS mount removes it together with its content.

**Prerequisites**:
- Perform [EPMCMBIBPC-2294](EPMCMBIBPC-2294.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on `..` |  |
| 2 | Click on the delete icon opposite the folder name from step 1 of the [EPMCMBIBPC-2294](EPMCMBIBPC-2294.md) case |  |
| 3 | Click **OK** button in the appeared pop-up window | The folder with its content is permanently deleted |
