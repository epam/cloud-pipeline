# Storage permissions restrictions

Test verifies that restrictions on permissions for storages for roles can be specified using preference.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with role `ROLE_STORAGE_MANAGER`
- test user group (`test_group`)

**Preparations**:
1. Login as the admin user `user1` from the prerequisites.
2. Create folder (`folder1`) and give all permissions on that folder to the non-admin user from Prerequisites.
3. Logout and login as the non-admin `user1` from the prerequisites
4. Open `folder1` created at step 2. Create object storage (`storage1`). 

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Click the **PREFERENCES** tab | |
| 3 | Click the **User Interface** tab and find the `ui.storages.permissions.restrictions` preference | |
| 4 | Add to the `ui.storages.permissions.restrictions` preference json <br> `{` <br> `"role": "<test_group>",` <br> `"disable": "WRITE,EXECUTE"` <br> `}`, <br> where `<test_group>` - test user group from the prerequisites | |
| 5 | Set *eye-icon* near the preference if they are disabled | |
| 6 | Click **Save** button. | | 
| 7 | Logout and login as the non-admin `user1` from the prerequisites | |
| 8 | Open `folder1` created at step 2 from the Preparations. | |
| 9 | Open the `storage1` created at step 3 from the Preparations. |  |
| 10 | Click gear-icon. In an appeared *Edit object storage* popup select *Permissions* tab | |
| 11 | Click the **Add group** button. Input the test user group name from the prerequisites. Click the **OK** button | |
| 12 | Click the appeared group at the *Groups and users* section | In the Permissions tab <li> *WRITE, EXECUTE* checkboxes are ticked as **DENY** and disabled. <li> *READ* permission empty in the both columns and active|
| 13 | Close *Edit group* popup | |
