# Add support for autoscaling filesystem for AWS

Test verifies that for all runs with the file system autoscaling capability being enabled the daemon checks current filesystem usage and attach additional disks in case there is no enough space in the filesystem.

**Prerequisites**:
- Admin user

| Steps | Actions | Expected results |
|:-----:|--------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool | |
| 4 | At the tool page, hover over the **Run v** button | |
| 5 | Click the **Custom settings** button in the list | |
| 6 | Expand the **Advanced** section | |
| 7 | Select `On-demand` value for **Price type**. Tick _Do not mount storages_ option | |
| 8 | Expand **Exec environment** section | |
| 9 | Input `25` into the **_Disk (Gb)_** field | |
| 10 | Click **Launch** button | |
| 11 | At the Runs page, click the just-launched run | |
| 12 | Wait until the SSH hyperlink appears | |
| 13 | Click the SSH hyperlink | |
| 14 | In the opened tab, enter and perform the command `df -hT` | File system space usage table is shown in the response |
| 15 | Store ***Avail*** value for filesystem with type `btrfs` | |
| 16 | Enter and perform the command <br> `fallocate -l <file_size>G test.big`, <br> where `<file_size>` is a value equals to the value kept at the step 15 minus 1 | 
| 17 | Return to the run log page | |
| 18 | Wait until the ***FilesystemAutoscaling*** task appears | |
| 19 | Click ***FilesystemAutoscaling*** task | Log contains record <br> `Filesystem /ebs was autoscaled <value1>G + <value2>G = <value3>G.`, <br> where <br> `<value1>` is value kept in the step 15, <br> `<value2>` is `<value1> * 0.5`, <br> `<value3> = <value1> + <value2>` |
| 20 | Click the SSH hyperlink. In the opened tab, enter and perform the command `df -hT` | File system space usage table is shown in the response that contains ***Size*** value for filesystem with type `btrfs` equal to the `<value3>` from the step 19 |
| 21 | Return to the run log page | |
| 22 | Click **Commit** link. Enter new version. Click **Commit** button | |
| 23 | Wait until **COMMIT SUCCEEDED** message appears on the run log page | |
| 24 | Click ***FilesystemAutoscaling*** task | Log contains 2 records similar to the record from step 19 with a corresponding the previous disk size increasing by 1.5 times |
| 25 | Click the SSH hyperlink. In the opened tab, enter and perform the command `df -hT` | File system space usage table is shown in the response that contains ***Size*** value for filesystem with type `btrfs` equal to the value from the last log record from the step 24 |
| 26 | Return to the run log page | |
| 27 | Click **PAUSE** button and wait until **PAUSE** button is changed to the **RESUME** button | | | |
| 28 | Click **RESUME** button and wait until **RESUME** button is changed to the **PAUSE** button | |
| 29 | Click ***FilesystemAutoscaling*** task | Log contains record similar to the record from step 19 with a corresponding the previous disk size increasing by 1.5 times |
| 30 | Click the SSH hyperlink. In the opened tab, enter and perform the command `df -hT` | File system space usage table is shown in the response that contains ***Size*** value for filesystem with type `btrfs` equal to the value from the last log record from the step 29 |

**After:**
- Stop the run launched at step 10
- Delete test tool version created at step 22
