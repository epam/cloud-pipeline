# A run launched with the digest pinning enabled shows the docker image digest

Test verifies that, with the `launch.docker.image.pin.digest` system preference enabled, a launched run
- keeps the docker image name with the tag in its ***Docker image*** field
- shows the ***Docker image digest*** field, with the digest the tag points to at the launch: the same digest, as the tool's **VERSIONS** tab shows for the launched version

**Prerequisites**:
- Admin user
- Test tool available in the registry

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Launch** tab
5. Find the `launch.docker.image.pin.digest` preference
6. Save the preference value, then set *Enabled* checkbox for `launch.docker.image.pin.digest` preference if needed
7. Click **Save** button if needed

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | |
| 4 | Choose any version of the tool (`version1`) in the list, without clicking its row, and save its ***Digest*** value | The ***Digest*** value has the form `sha256:<64 hexadecimal characters>` |
| 5 | Hover over the **Run v** button of the `version1` version, click **Default settings** | |
| 6 | In an appeared pop-up window click **Launch** button | |
| 7 | At the **Runs** page, click the just-launched run | |
| 8 | Wait until the run's state turns to **Running** | |
| 9 | Click the **Instance** item | <li> ***Docker image*** field is shown with the test tool's docker image name, ending with `:version1` <li> ***Docker image digest*** field is shown with the value saved at step 4 |
| 10 | Reload the page. Click the **Instance** item | ***Docker image digest*** field is shown with the value saved at step 4 |

**After**:
- Stop the run launched at step 6
- Restore the `launch.docker.image.pin.digest` preference value saved at step 6 of the preparations
