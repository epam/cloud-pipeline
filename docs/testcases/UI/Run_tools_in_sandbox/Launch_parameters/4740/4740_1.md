# "Add system parameter" dialog keeps the selection while the launch form loads

Test verifies that
- the parameters selected in the ***Add system parameter*** dialog stay selected while the dialog is open, even when the launch form behind it is redrawn while it loads
- all the selected parameters are added after **OK**

The result depends on timing: the dialog shall be opened while the launch form is still loading. So the network is throttled during the test.

**Prerequisites**:
- Admin user
- Test tool
- The `CP_FSBROWSER_ENABLED` and `CP_CAP_KUBE_VERSION` parameters are defined in the **`launch.system.parameters`** preference
- The test tool's settings do not define the `CP_FSBROWSER_ENABLED` and `CP_CAP_KUBE_VERSION` parameters
- A browser with developer tools that can throttle the network, e.g. Chrome

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Open the browser's developer tools. On the **Network** tab, select a slow network throttling preset, e.g. `3G` | |
| 5 | At the tool page, hover over the **Run v** button | |
| 6 | Click the **Custom settings** button in the list | |
| 7 | Expand the **ADVANCED** section at once | |
| 8 | Click ***Add system parameter*** button in the ***System parameters*** section, while the developer tools still show pending requests of the form | The ***Select system parameter to override*** pop-up opens |
| 9 | Click the `CP_FSBROWSER_ENABLED` and `CP_CAP_KUBE_VERSION` rows in the list | <li> Both rows are marked as selected <li> The **OK** button shows `OK (2)` |
| 10 | Wait until the developer tools show no pending requests, without closing the pop-up | <li> Both rows are still marked as selected <li> The **OK** button still shows `OK (2)` |
| 11 | Click the **OK** button | Both `CP_FSBROWSER_ENABLED` and `CP_CAP_KUBE_VERSION` appear in the ***System parameters*** section, with their default values |

**After**:
- In the developer tools, turn the network throttling off
