# Audit run sharing event

Test verifies that run sharing event is logged.

**Prerequisites**:
- Admin user
- Non-admin user
- Test tool with endpoint

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the Prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the tool from the Prerequisites | |
| 4 | Launch tool with *Default settings* | |
| 5 | At the **Runs** page, click the just-launched run | |
| 6 | Wait until the **SSH** hyperlink appears | |
| 7 | Click on ***Not shared (click to configure)*** link | |
| 8 | In appeared pop-up click on ***Add user*** icon | |
| 9 | In appeared pop-up specify the name of non-admin user from the Prerequisites, click **OK** button | |
| 10 | Click **OK** button | |
| 11 | Open the **Settings** page | |
| 12 | Open the **SYSTEM MANAGEMENT** tab. Select the **LOGS** tab | |
| 13 | Click ***Show advanced*** button | |
| 14 | Click **Type** field and select `audit` value from drop-down list | Record <br> `Run #<run_id> shared with user <non-admin_user> with access type ENDPOINT.` , where `<run_id>` is Id of run launched at step 4, is shown in the top of logs records |
| 15 | At the **Runs** page, click the run launched at step 4 | |
| 16 | Click on ***Not shared (click to configure)*** link | |
| 17 | Near the non-admin user name set the ***Enable SSH connection*** checkbox. Click **OK** button | |
| 18 | Repeat steps 11-14 | Record <br> `Run #<run_id> shared with user <non-admin_user> with access type SSH.` , where `<run_id>` is Id of run launched at step 4, is shown in the top of logs records |

**After:**
- Stop run launched at step 4
