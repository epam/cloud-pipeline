# Validation of edit inactive notifications

Test verifies editing an inactive notification's title and body.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1217](EPMCMBIBPC-1217.md) case |  |
| 2 | Click the system-settings button (gear icon in the left panel) |  |
| 3 | Click the **System events** tab |  |
| 4 | Click the edit icon opposite any notification |  |
| 5 | Change the **Title** and **Body** values |  |
| 6 | Click **SAVE** | A new value of the notification title, entered at step 5, appears in the table |
| 7 | Click the **+** button in front of the notification selected at step 4 | A new value of the notification body, entered at step 5, appears in the table |
