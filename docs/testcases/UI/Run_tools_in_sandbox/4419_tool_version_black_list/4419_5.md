# User with ROLE_TOOL_ADMIN can manage the tool version black list

Test verifies that a non-admin user with the `ROLE_TOOL_ADMIN` role can add and remove tool versions from the blacklist in the same way as an admin user.

**Prerequisites**:
- Admin user
- Non-admin user (`user1`) with `ROLE_TOOL_ADMIN` role
- Test tool with at least 2 versions

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin `user1` with `ROLE_TOOL_ADMIN` role from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Open the **Versions** tab | List of tool versions is displayed. ***Configure access*** button is shown opposite each version |
| 5 | Click ***Configure access*** button opposite `latest` version | A content menu opens that contains *Add to black list* and *Add to white list* options |
| 6 | Click *Add to black list* option | <li> ***Configure access*** button is replaced by ***Black-listed*** red button <li> Exclamation mark appears on the **Run** button |
| 7 | Click ***Black-listed*** button | A content menu opens that contains *Remove from black list* and *Add to white list* options |
| 8 | Click *Remove from black list* button | <li> *Remove from black list* button is replaced by *Add to black list* button <li> Exclamation mark disappears from the **Run** button |
