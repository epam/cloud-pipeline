# ROLE_USER_ADMIN: import user

Test verifies that user with role `ROLE_USER_ADMIN` can import users.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.

**Preparations**:
1. Create `import.csv` file that contains
```
UserName,Groups,billing-center,import_attr1
TEST_USER2_4146,TEST_GROUP_4146,,import_attr1_val1
```

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Click **Import users** button | |
| 6 | Select `import.csv` file created at step 1 of the Preparations and click **Open** button | |
| 7 | In the ***Import settings*** pop up check **Create users** and **Create groups** checkboxes | |
| 8 | Click **Import** button | ***Import logs*** pop up appears that contains records <li> _`INFO User 'TEST_USER2_4146' successfully created.`_ <li> _`INFO Role 'ROLE_TEST_GROUP_4146' successfully created.`_ <li> _`INFO Role 'ROLE_TEST_GROUP_4146' successfully assigned to user 'TEST_USER2_4146'.`_|
| 9 | Close ***Import logs*** pop up | |
| 10 | Enter into the search field the user name specified in the `import.csv` file, press the **Enter** key | The record with the name specified in the `import.csv` file appears in the users list |
| 11 | Open **Groups** tab | |
| 12 | Enter into the search field the group name specified in the `import.csv` file, press the **Enter** key | The record with the group name specified in the `import.csv` file appears in the groupss list |

**After:**
- Remove `TEST_USER2_4146` and `TEST_GROUP_4146` created in test.
