# Downloads window: the Status filter's select-all box and "Reset to defaults"

Test verifies that:
- the **Status** column's filter lists a single select-all box above the per-status checkboxes, separated from them by a line
- that box's label names what the next click will do - **Select all** while any status is unticked, **Unselect all** only once every status is ticked
- unticking any single status turns the label back to **Select all**
- **Reset to defaults** restores the default selection - every status except `CANCELLED` and `EXPIRED`

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an object storage (or an NFS storage whose share is mounted as NFS), holding at least one file

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. Select several files via checkboxes, click the selection button (**"N item selected"**), choose **Download archive**, then click **OK** without changing the offered name
4. Open the **Downloads** window: click the grid-icon button at the top right of the storage view and choose **Show downloads**
5. Click **Cancel** on the row of the task queued at step 3, and wait until its status becomes `CANCELLED`
6. Repeat step 3 for the other file, so there is also one task that is *not* cancelled

| Steps | Actions | Expected results |
|:-----:| --- | --- |
|   1   | Click the filter icon on the **Status** column's header | <li> The filter dropdown opens <li> A single checkbox sits at the top, labelled **Select all**, shown in a half-ticked (indeterminate) state <li> Below the line there is one checkbox per status: `PENDING`, `RUNNING`, `CANCEL_REQUESTED`, `STOPPING`, `SUCCESS`, `FAILED`, `CANCELLED`, `EXPIRED` - all ticked except `CANCELLED` and `EXPIRED` <li> At the bottom there are two links, **OK** and **Reset to defaults** |
|   2   | Click the **Select all** checkbox | <li> Every status checkbox below the line becomes ticked <li> The top checkbox is now fully ticked and its label changes to **Unselect all** |
|   3   | Click **OK** | <li> The dropdown closes and the table reloads <li> Both tasks are shown - the cancelled one from step 5 of Preparations as well as the one from step 6 <li> The **Status** column's filter icon is highlighted <li> A **Reset filters** button appears above the table |
|   4   | Click the filter icon on the **Status** column's header again | Every status checkbox below the line becomes ticked |
|   5   | Click the **Unselect all** checkbox | <li> Every status checkbox below the line becomes unticked <li> The top checkbox is unticked and not half-ticked, and its label changes back to **Select all** |
|   6   | Click **OK** | <li> The dropdown closes and the table reloads <li> Both tasks are shown - the cancelled one from step 5 of Preparations as well as the one from step 6 <li> The **Status** column's filter icon is highlighted <li> A **Reset filters** button appears above the table |
|   7   | Click the filter icon on the **Status** column's header again | No status is ticked - the empty selection was kept, not replaced by the default |
|   8   | Click the **Select all** checkbox again, then untick the `EXPIRED` checkbox alone | <li> Only `EXPIRED` is unticked; the other seven stay ticked <li> The top checkbox returns to the half-ticked state and its label reads **Select all** again |
|   9   | Click **Reset to defaults** | <li> The dropdown closes <li> The table reloads, showing the user's tasks of every status except `CANCELLED` and `EXPIRED` <li> The **Status** column's filter icon is not highlighted |
|  10   | Click the filter icon on the **Status** column's header again | <li> Every status is ticked except `CANCELLED` and `EXPIRED` - the default is back <li> The top checkbox is half-ticked and reads **Select all** |
