# Admin adds a tool version to the black list

Test verifies that an admin user can add a tool version to the black list via the **Configure access** button on the **Versions** tab.

**Prerequisites**:
- Admin user
- Test tool with at least 2 versions

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Open the **Versions** tab | <li> List of tool versions is displayed in the table. <li> ***Configure access*** button is shown opposite each Version |
| 5 | Click ***Configure access*** button opposite `latest` version | A content menu opens that contains *Add to black list* and *Add to white list* options |
| 6 | Click *Add to black list* option | <li> ***Configure access*** button is replaced by ***Black-listed*** red button <li> Exclamation mark appears on the **Run** button |
| 7 | Click ***Black-listed*** button | A content menu opens that contains *Remove from black list* and *Add to white list* options |
| 8 | Click anywhere to close the menu. Hover over the **Run** button | Tooltip `The latest version is on the black list. Try to find an older one.` appears |
