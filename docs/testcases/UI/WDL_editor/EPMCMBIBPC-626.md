# Check scatter Inputs menu

Test verifies the default fields shown in a scatter object's Inputs section.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-624](EPMCMBIBPC-624.md) case |  |
| 2 | Click **Inputs** collapsed header | In the **Inputs** section are displayed: <li> **Name**, **Type**, **Value** fields <li> the **Type** field has the value `ScatterItem` <li> the **Name** field is non-empty <li> the **Value** field is empty <li> the **Name** field is enabled <li> the **Type** and **Value** fields are disabled |
