# Validate of tool that working in sand box

Test verifies that a launched tool's endpoint opens a started application in a new tab.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-494](EPMCMBIBPC-494.md) case |  |
| 2 | In the **Runs** page click on the tool launched at the [EPMCMBIBPC-494](EPMCMBIBPC-494.md) case |  |
| 3 | Wait until the hyperlink in the header opposite the **Endpoint** label appears |  |
| 4 | Click the appeared hyperlink | A new tab with a started application from the tool appears |
