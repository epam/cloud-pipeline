# Delete the default version of a tool without the latest version

Test verifies that the deletion confirmation of the default version tells which version is used instead, if the tool has no **latest** version: none, while several versions are left, or the only version left.

**Prerequisites**:
- Admin user
- Test tool without the **latest** version, with three versions `<version1>`, `<version2>` and `<version3>`, pushed from three different images

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version1>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page and select the test tool from the prerequisites | |
| 2 | Click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | The `<version1>` version has the **default** label |
| 3 | Click the **Delete** button opposite the `<version1>` version | The confirmation contains the `You are going to delete the default version of the tool.` warning and the `Once it is deleted, the tool has no default version, and no latest version either.` message |
| 4 | Click **Delete** | <li> The `<version1>` version disappears from the list <li> No version has the **default** label |
| 5 | Click the **SETTINGS** tab | The `<tool> has no default version.` alert is shown, where `<tool>` is the test tool name |
| 6 | Click the **VERSIONS** tab. Click the "check" button (**Set as default**) opposite the `<version2>` version, and click **Yes** in the confirmation | The `<version2>` version has the **default** label |
| 7 | Click the **Delete** button opposite the `<version2>` version | The confirmation contains the `You are going to delete the default version of the tool.` warning and the `Once it is deleted, the tool has no default version, and the only version <version3> is used instead.` message |
| 8 | Click **Delete** | <li> The `<version2>` version disappears from the list <li> No version has the **default** label |

**After**:
- The test tool has the `<version3>` version only
