# "Capacity retries" field validation

Test verifies the validation rules of the ***Capacity retries*** field: it accepts an empty value, or a positive integer up to `999`, or up to the `cluster.nodeup.retry.count` preference value if that is higher.

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Perform [4608_2](4608_2.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | At the tool page, hover over the **Run v** button | |
| 4 | Click the **Custom settings** button in the list | |
| 5 | Expand the **Exec environment** section | |
| 6 | Input `0` into the ***Capacity retries*** field | Error `Please enter a valid positive integer number` is shown under the field |
| 7 | Clear the field and input `-1` | Error `Please enter a valid positive integer number` is shown under the field |
| 8 | Clear the field and input `1.5` | Error `Please enter a valid positive integer number` is shown under the field |
| 9 | Clear the field and input `abc` | Error `Please enter a valid positive integer number` is shown under the field |
| 10 | Clear the field and input ` 7` (with a leading space) | Error `Please enter a valid positive integer number` is shown under the field |
| 11 | Click the **Launch** button | Launch is blocked, the ***Capacity retries*** field is highlighted as invalid |
| 12 | Clear the field and input `1` | No error is shown |
| 13 | Clear the field and input `999` | No error is shown |
| 14 | Clear the field and input `1000` | Error `Maximum value is 999` is shown under the field |
| 15 | Clear the ***Capacity retries*** field, leaving it empty | No error is shown |
| 16 | In a new browser tab, open the **Settings** page, click the **PREFERENCES** tab, then the **Cluster** tab | |
| 17 | Save the `cluster.nodeup.retry.count` preference value, then set it to `1005`. Click **Save** button | |
| 18 | Switch back to the launch form tab and reload the page. Repeat steps 1-5 | ***Capacity retries*** field placeholder is `1005` |
| 19 | Input `1005` into the ***Capacity retries*** field | No error is shown |
| 20 | Clear the field and input `1006` | Error `Maximum value is 1005` is shown under the field |

**After**:
- Restore the `cluster.nodeup.retry.count` preference value saved at step 17
