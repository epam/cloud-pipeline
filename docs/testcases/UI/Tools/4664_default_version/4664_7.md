# A docker image without a tag is launched with the default version

Test verifies that a tool image specified without a version in `pipe run -di` is launched with the default version of the tool.

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least two other versions
- `<version>` is one of the test tool versions, which is not the **latest** one
- `pipe` CLI is installed and configured for the admin user
- `<API URL>` is the API address of the deployment, e.g. `https://<host>/pipeline/restapi`

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Run `pipe run -di <registry>/<group>/<tool> -it <instance type> -id 30 -cmd "sleep infinity" -y`, where `<registry>/<group>/<tool>` is the test tool image without a tag | The run is launched, its ID is printed |
| 2 | Open the **Runs** page and click the run launched at step 1 | ***Docker image*** is shown without a tag, as it was specified at step 1 |
| 3 | Open `<API URL>/run/<run id>` in the browser, where `<run id>` is the ID printed at step 1 | `actualDockerImage` field of the response is the test tool's docker image with the `<version>` tag |

**After**:
- Stop the run launched at step 1
- Remove the default version of the test tool, as described in [4664_3](4664_3.md) (steps 1-4)
