# Validation of change configuration

Test verifies linking a detach configuration to a pipeline configuration for the first time.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1114](EPMCMBIBPC-1114.md) case |  |
| 2 | Open the detach configuration from step 1 |  |
| 3 | Click on the field opposite the **Pipeline** label |  |
| 4 | Select the pipeline and version in the appeared pop-up window |  |
| 5 | Click **OK** button |  |
| 6 | Click **Yes** in the appeared pop-up window | The detach configuration's fields are filled with values equal to the parameters of the pipeline's configuration selected at step 4 |
