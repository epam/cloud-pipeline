# Run is NOT marked IDLE when GPU config is disabled and only CPU would be idle

Test verifies that when the GPU idle configuration is disabled in `system.idle.monitoring.config`, a run on a GPU instance with no GPU activity is not tagged with **IDLE_GPU** or the aggregate **IDLE** tag.

**Prerequisites**:
- Admin user
- Test tool available in the registry that can run on a GPU instance type
- GPU instance available in the cloud region

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the system preference `system.idle.monitoring.config` to:
   ```
   [
      {
         "type": "CPU",
         "enabled": true,
         "thresholdPercent": 60,
         "gracePeriodMinutes": 5,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      },
      {
         "type": "GPU",
         "enabled": false,
         "gracePeriodMinutes": 5,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      },
      {
         "type": "ABSOLUTE",
         "enabled": true,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      }
   ]
   ```

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Launch the tool on a GPU instance type with default settings | |
| 4 | At the **Runs** page, click the just-launched run | |
| 5 | Wait until the **SSH** hyperlink appears and the all idle detection periods (`gracePeriodMinutes` for `CPU` and `GPU`, `actionTimeoutMinutes` for `ABSOLUTE` from `system.idle.monitoring.config`) elapse | <li> ***IDLE_CPU*** tag is shown in the **Instance** section <li> ***IDLE_GPU*** and ***IDLE*** tags aren't shown in the **Instance** section |
| 6 | Open the **Runs** page | ***IDLE_GPU*** and ***IDLE*** tags aren't shown and ***IDLE_CPU*** tag is shown near the name of run launched at step 3|
| 7 | Open the **Dashboard** page | In the **Active runs** section ***IDLE_GPU*** and ***IDLE*** tags aren't shown and ***IDLE_CPU*** tag is shown for the run launched at step 3 |

**After**:
- Stop the run launched at step 3
- Restore the original values of `system.monitoring.idle.settings` and `system.resource.monitoring.period`.
