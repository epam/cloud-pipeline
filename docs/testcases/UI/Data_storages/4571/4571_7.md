# Extract archive from the storage's selection menu

Test verifies that an archive already in a storage is extracted from the selection menu, with no
pop-up in between: the **Extract archive** item sits below **Download**, queues the task
straight away, and is offered for a selection of **exactly one** archive - so that a bulk
extraction cannot be started by accident, since **Select page** takes a whole listing in one click.

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose
 share is mounted as NFS)

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. Upload two archive files (e.g. `one.zip`, `two.tar.gz`) and one ordinary file (e.g. `notes.txt`)
 into the storage, choosing **Upload** > **Upload**
4. Create a folder in the storage whose name ends in `.zip` (e.g. `folder.zip`)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Select `one.zip` alone using its checkbox, then click the selection button (shown as **"1 item selected"**) | An **Extract archive** item is listed, directly below **Download** |
| 2 | Click **Extract archive** | <li> A loading message reading `Starting archive extraction...` appears briefly <li> It is replaced by a message reading `Archive extraction has been queued. Follow its progress under "Show storage tasks".`, with **Show storage tasks** as a clickable link |
| 3 | Click the **Show storage tasks** link inside that message | <li> The message closes and the **Storage tasks** window opens <li> One new row is listed, with **Extract archive** in its **Type** column and `one.zip` as its name <li> Its **Actions** offer **Cancel** while it is pending or running, and never **Download** |
| 4 | Close the window, select `one.zip` and `two.tar.gz` together, and click the selection button | No **Extract archive** item is listed |
| 5 | Click **Select page** to select everything on the page, then click the selection button | No **Extract archive** item is listed |
| 6 | Select `two.tar.gz` alone and choose **Extract archive** | <li> A message confirms the extraction has been queued <li> The **Storage tasks** window lists a second **Extract archive** task, naming `two.tar.gz` - so two archives are extracted by queueing them one after the other |
| 7 | Close the window, select `notes.txt` alone, and click the selection button | No **Extract archive** item is listed |
| 8 | Select the `folder.zip` folder alone and click the selection button | No **Extract archive** item is listed |

**After**:
- Delete `one.zip`, `two.tar.gz`, `notes.txt`, the `folder.zip` folder, and the `one/` and `two/`
 folders from the storage
