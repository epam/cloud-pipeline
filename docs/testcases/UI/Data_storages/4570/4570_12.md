# Storage tasks window: the Owner filter takes a user picked from its suggestion list

Test verifies that:
- typing into the **Owner** column's filter field offers a list of matching users, and picking one applies that user's name
- the table then shows only that user's tasks, and the **Owner** column's filter icon is highlighted
- a name that was only typed, with nothing picked from the list, is **not** applied: the table keeps showing what the previous selection matched

**Prerequisites**:
- Admin user (or a user with the **ROLE_STORAGE_ADMIN** role)
- Non-admin user, without the **ROLE_STORAGE_ADMIN** role
- An object storage (or an NFS storage whose share is mounted as NFS) both users can access, holding at least two files

**Preparations**:
1. Login as the non-admin user from the Prerequisites
2. Open the storage from the Prerequisites, select a file via its checkbox, click the selection button, choose **Download archive**, then click **OK** without changing the offered name
3. Logout, then login as the admin user from the Prerequisites
4. Open the same storage, select the other file, and queue an archive the same way
5. Open the **Storage tasks** window: click the grid-icon button at the top right of the storage view and choose **Show storage tasks**

| Steps | Actions | Expected results |
|:---:|---|---|
| 1 | Click the filter icon on the **Owner** column's header | <li> The filter dropdown opens with an input field holding the admin user's own user name <li> Below it there are two links, **OK** and **Reset to defaults** |
| 2 | Delete the user name from the field, then type the first few characters of the non-admin user's name | A list of matching users appears under the field |
| 3 | Type non-admin user's name and click somewhere on filter dropdown without picking anyone from the list | The typed name is dropped from the field, which goes back to empty state |
| 4 | Type nonexisting user name | The message `Select a user from the list, or empty the field to show every user's tasks.` appears under the field |
| 5 | Click **OK** button | The dropdown stays open |
| 6 | Type the first few characters of the non-admin user's name again, pick that user from the list, then click **OK** | <li> The dropdown closes and the table reloads <li> Only the non-admin user's tasks include queued at step 2 of Preparations, is shown, with that user's name in the **Owner** column <li> The **Owner** column's filter icon is highlighted <li> A **Reset filters** button appears above the table |
| 7 | Click the filter icon on the **Owner** column's header, then click **Reset to defaults** | <li> The dropdown closes and the table reloads <li> Only the admin user's own task is shown again <li> The **Owner** column's filter icon is no longer highlighted, and the **Reset filters** button disappears |
