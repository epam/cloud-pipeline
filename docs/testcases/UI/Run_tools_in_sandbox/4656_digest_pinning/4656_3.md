# Pause and resume of a run pinned to the docker image digest keep the run's changes

Test verifies that a run launched with the `launch.docker.image.pin.digest` system preference enabled
- can be paused and resumed
- is resumed from the state saved by the pause, not from the image of its digest: a file created before the pause is still present after the resume
- keeps its ***Docker image digest*** after the resume

**Prerequisites**:
- Admin user
- Test tool available in the registry

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Launch** tab
5. Find the `launch.docker.image.pin.digest` preference
6. Save the preference value, then set *Enabled* checkbox for `launch.docker.image.pin.digest` preference if needed
7. Click **Save** button if needed

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | At the tool page, hover over the **Run v** button | |
| 4 | Click the **Custom settings** button in the list | |
| 5 | Expand the **ADVANCED** section | |
| 6 | In the **Price type** dropdown list select **On-demand** | |
| 7 | Click the **Launch** button | |
| 8 | In an appeared pop-up window click **Launch** button | |
| 9 | At the **Runs** page, click the just-launched run | |
| 10 | Click the **Instance** item | ***Docker image digest*** field is shown with a value `sha256:<64 hexadecimal characters>` |
| 11 | Save the ***Docker image digest*** value | |
| 12 | Wait until the **SSH** hyperlink appears in the right upper corner, then click it | |
| 13 | In the opened tab run the command: `echo "pinned" > /root/digest_test.txt` | |
| 14 | Close the SSH tab, switch back to the run logs page | |
| 15 | Click the **PAUSE** hyperlink in the right upper corner | |
| 16 | Click the **PAUSE** button in the appeared pop-up window | The run state changes, the label **PAUSING** appears |
| 17 | Wait until the **RESUME** hyperlink appears in the right upper corner | The run state is **Paused** |
| 18 | Click the **RESUME** hyperlink | |
| 19 | Click the **RESUME** button in the appeared pop-up window | The run state changes, the label **RESUMING** appears |
| 20 | Wait until the **PAUSE** and **SSH** hyperlinks appear in the right upper corner | The run state is **Running** |
| 21 | Click the **SSH** hyperlink | |
| 22 | In the opened tab run the command: `cat /root/digest_test.txt` | The text `pinned` is output |
| 23 | Close the SSH tab, switch back to the run logs page | |
| 24 | Reload the page. Click the **Instance** item | ***Docker image digest*** field is shown with the value saved at step 11 |

**After**:
- Stop the run launched at step 8
- Restore the `launch.docker.image.pin.digest` preference value saved at step 6 of the preparations
