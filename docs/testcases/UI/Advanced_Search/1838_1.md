# Advanced Search results: Default Table view for different entities

Test verifies default Advanced Search results Table view for each entity type.

**Prerequisites**:

- admin user

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as admin user from the prerequisites | |
| 2 | Click on **Search** icon at the left menu bar | Advanced Search page opens:<ul><li>List of all search results corresponding search by "`*`" is shown on Search results page.</li><li>Each result is presented by the "row" in the list with next info: ***Name*** and ***Owner*** (if exist) |
| 3 | Click **Table** button to switch page to table view | <li>All results are presented by the single table, additional info is placed in columns</li><li>By default table has ***Name, Description, Changed, Size, Species, Magnification, Tissue, Processing type, Pre-processing steps, Library type, Assembly, Research Area, Platform, Sequencing Date, Machine ID, Sample ID, Sample Name, File Type, Spatial Type, NGS data analysis phases, Post-alignment steps, Owner, Path, Cloud path, Mount path, Started, Finished*** columns |
| 4 | Click the entity-types filter button (funnel icon), then select **Folders** in the appeared dropdown list, and check table columns. | The table has ***Name, Tissue, Processing type, Pre-processing steps, Assembly, Post-alignment steps, Owner*** columns by default |
| 5 | Open the entity-types filter dropdown again, deselect **Folders** and select **Pipelines** instead, then repeat step 4's check. | The table has ***Name, Description, Assembly, Sequencing Date, Machine ID, File Type, Processing type, Pre-processing steps, Post-alignment steps, Owner*** columns by default |
| 6 | Repeat step 5 for **Runs**. | The table has ***Name, Processing type, Pre-processing steps, Post-alignment steps, Owner, Started, Finished*** columns by default |
| 7 | Repeat step 5 for **Tools**. | The table has ***Name, Description, File Type, Processing type, Pre-processing steps, Post-alignment steps, Owner, Path*** columns by default |
| 8 | Repeat step 5 for **Data**. | The table has ***Name, Changed, Size, Species, Magnification, Tissue, Pre-processing steps, Library type, Assembly, Research Area, Platform, Sequencing Date, Machine ID, Sample ID, Sample Name, File Type, Spatial Type, NGS data analysis phases, Processing type, Post-alignment steps, Owner, Cloud path, Mount path*** columns by default |
| 9 | Repeat step 5 for **Issues**. | The table has ***Name, Description, Processing type, Pre-processing steps, Post-alignment steps, Owner*** columns by default |
| 10 | Open the entity-types filter dropdown and select **Runs**. | The table has ***Name, Description, Processing type, Pre-processing steps, Post-alignment steps, Owner, Started, Finished*** columns by default |
