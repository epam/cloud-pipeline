# Personal tool groups/tools: permission restrictions for all groups/roles 

Test verifies that restrictions on permissions for personal tool groups for all group/roles can be specified using preference.

**Prerequisites**:
- admin user
- non-admin user (`user1`)
- Perform [3230_1](3230_1.md)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Click the **PREFERENCES** tab | |
| 3 | Click the **User Interface** tab and find the `ui.personal.tools.permissions.restrictions` preference | |
| 4 | Add to the `ui.personal.tools.permissions.restrictions` preference json <br> `{` <br> `"role": "ALL",` <br> `"disable": "WRITE,EXECUTE"` <br> `}` | |
| 5 | Click **Save** button | | 
| 6 | Logout and login as the non-admin `user1` from the prerequisites | |
| 7 | Open the  the **Tools** page. | |
| 8 | Select *Personal* group from list of *All groups* |  |
| 9 | Click ***Settings*** button (gear-icon). In an appeared list select *Group* -> *Edit* | |
| 10 | Click the *Permissions* tab | |
| 11 | Click the **Add group** button. Input the `ROLE_CONFIGURATION_MANAGER` role name. Click the **OK** button | |
| 12 | Click the appeared role at the *Groups and users* section | In the Permissions tab <li> *WRITE, EXECUTE* checkboxes are ticked as **DENY** and disabled. <li> *READ* permission empty in the both columns and active|
| 13 | Close *Edit group* popup | |
| 14 | Open test Tool added at step 3 from the preparations | |
| 15 | Hover over gear-icon. In an appeared list select *Permissions* option | |
| 16 | Repeat steps 11-13 | |

**After:**
- Restore the value of the `ui.personal.tools.permissions.restrictions` preference to the initial value.
