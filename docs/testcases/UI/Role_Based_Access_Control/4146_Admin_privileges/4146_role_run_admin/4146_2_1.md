# ROLE_RUN_ADMIN: stop and rerun runs

Test verifies that user with role `ROLE_RUN_ADMIN` 
- can see all runs
- can stop and rerun runs of another users.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_RUN_ADMIN` role

**Preparations**:
1. Login as the admin user from the prerequisites.
2. Select the test tool and launch a tool with default settings and `On-demand` price type (`run1`).

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Runs** page. Click *View other available active runs* link if needed | <li> All runs include the run launched at step 2 of the Preparations are shown in the ***Active runs*** tab <li> *Pause*, *Stop*, *Log* buttons is shown in the `run1` row |
| 3 | Click **Stop** button in the row opposite to the `run1` | |
| 4 | Click **Stop** button in an appeared pop-up | |
| 5 | Select ***Completed runs*** tab | <li> `run1` with *Stopped* icon is displaying on the ***Completed runs*** tab <li> *Rerun*, *Log* buttons are shown in the `run1`  row |
| 6 | Click ***Log*** button in the row opposite to the `run1` | Run log page opens |
| 7 | Click ***Rerun*** button | *Launch* page opens |
| 8 | Click **Launch** button | |
| 9 | In an appeared pop-up click **Launch** button | ***Active runs*** tab opens and contains reruned run (`run2`) |
