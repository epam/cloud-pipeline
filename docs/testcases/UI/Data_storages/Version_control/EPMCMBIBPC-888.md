# Restore specified file version validation

Test verifies that restoring an earlier uploaded file version brings back that version's content.

**Prerequisites**:
- Perform [EPMCMBIBPC-820](EPMCMBIBPC-820.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on the **Restore** button opposite the early uploaded file version |  |
| 2 | Uncheck the **Show files versions** checkbox | The file restored at step 1 is displayed, its size equal to the size of the file version restored at step 1 |
