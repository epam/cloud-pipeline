# "Download archive" name pop-up: defaults and validation

Test verifies that:
- for a single selected folder, the field is pre-filled with that folder's own name plus `.zip`
- for a selection of several items, the field is pre-filled with a name built from the current date and time
- a name is not required to already end in `.zip` - the extension is appended automatically, and never doubled when it is already there
- a name with a character other than a letter, digit, space, underscore, hyphen or period is rejected with an error message once confirmed
- **Cancel** closes the pop-up and queues nothing

**Prerequisites**:
- An AWS S3 object storage with a folder named, for example, `report`, and at least one other file, exists

| Steps | Actions | Expected results |
|:---:|---| --- |
| 1 | Open library | |
| 2 | Click on the storage in the library-tree | |
| 3 | Click on the checkbox near the `report` folder name | |
| 4 | Click the **1 item selected** button, then click **Download archive** | The **Download archive** pop-up opens, with the **Archive name** field pre-filled with `report.zip` |
| 5 | Click **Cancel** | The pop-up closes |
| 6 | Click on the checkbox near one other file | |
| 7 | Click the **2 items selected** button, then click **Download archive** | The **Download archive** pop-up opens, with the **Archive name** field pre-filled with a name of the form `archive-<date> <time>`, e.g. `archive-2026-10-21 13-13-02` |
| 8 | Clear the **Archive name** field and type `my archive` (no extension), then click **OK** | The pop-up closes. A task named `my archive.zip` appears in the **Downloads** window |
| 9 | Repeat step 7 | |
| 10 | Clear the **Archive name** field and type `my archive.zip` (already ending in `.zip`), then click **OK** | The pop-up closes. A task named `my archive.zip` (not `my archive.zip.zip`) appears in the **Downloads** window |
| 11 | Repeat step 7 | |
| 12 | Clear the **Archive name** field and type `bad*name?`, then click **OK** | The pop-up stays open and an error message is shown. No task is queued |
| 13 | Click **Cancel** | The pop-up closes |
