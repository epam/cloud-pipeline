# Price type validation

Test verifies the fields shown when expanding the **Advanced** section on the Configuration tab.

**Prerequisites**:
- Perform the [EPMCMBIBPC-795](EPMCMBIBPC-795.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on **Advanced** collapsed header | <li> **Price type**, **Timeout (min)**, **Limit mounts**, **Cmd template** fields, the **Start idle** checkbox and question-mark icons near them appear <li> the **Add system parameter** button appears <li> the default price type value is selected as the price type |
