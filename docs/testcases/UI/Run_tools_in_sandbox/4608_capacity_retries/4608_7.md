# "Capacity retries" field in the Tool settings

Test verifies that
- a value set for ***Capacity retries*** in a Tool's settings becomes that Tool's default and is sent to the run as `CP_NODEUP_RETRY_COUNT`
- clearing the field removes `CP_NODEUP_RETRY_COUNT` from the Tool's configuration

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Perform [4608_2](4608_2.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **SETTINGS** tab | |
| 4 | Expand the **EXECUTION ENVIRONMENT** section | ***Capacity retries*** field is empty, with placeholder `N` |
| 5 | Input `6` into the ***Capacity retries*** field | |
| 6 | Click **SAVE** button | |
| 7 | Reload the page. Repeat steps 3-4 | ***Capacity retries*** field value is `6` (not a placeholder) |
| 8 | At the tool page, hover over the **Run v** button | |
| 9 | Click the **Custom settings** button in the list | |
| 10 | Expand the **Exec environment** section | ***Capacity retries*** field is pre-filled with `6` |
| 11 | Click the **Launch** button, without changing the ***Capacity retries*** field | |
| 12 | In an appeared pop-up window click **Launch** button | |
| 13 | At the **Runs** page, click the just-launched run. Expand the **Parameters** section | `CP_NODEUP_RETRY_COUNT: 6` is shown |
| 14 | Open the **Tools** page, select the test tool from the prerequisites | |
| 15 | Click the **SETTINGS** tab | |
| 16 | Expand the **EXECUTION ENVIRONMENT** section | |
| 17 | Clear the ***Capacity retries*** field | |
| 18 | Click **SAVE** button | |
| 19 | Reload the page. Repeat steps 15-16 | ***Capacity retries*** field is empty, with placeholder `N` |
| 20 | At the tool page, hover over the **Run v** button | |
| 21 | Click the **Custom settings** button in the list | |
| 22 | Expand the **Exec environment** section | ***Capacity retries*** field is empty, with placeholder `N`, confirming `CP_NODEUP_RETRY_COUNT` is no longer stored for the tool |

**After**:
- Stop the run launched at steps 11-12
- Restore the `ui.launch.allow.nodeup.count` preference value saved at step 8 of [4608_2](4608_2.md) case
