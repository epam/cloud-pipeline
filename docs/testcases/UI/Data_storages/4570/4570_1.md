# [Negative] Validate the Archive name field in the Download archive pop-up

Test verifies that:
- an empty **Archive name** shows the message `Archive name is required.` under the field and keeps **OK** disabled
- a name with an illegal character shows the message `Only letters, digits, spaces, dot, dash and underscore are allowed.` under the field and keeps **OK** disabled
- a valid name clears the message and re-enables **OK**

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose share is mounted as NFS)

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. Upload or create at least one file

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Select the file from Preparations via its checkbox | |
| 2 | Click the selection button (**"1 item selected"**) and choose **Download archive** | The **Download archive** pop-up opens. The **Archive name** field is pre-filled with a default name and shows no message. **OK** is enabled |
| 3 | Clear the **Archive name** field completely | The message `Archive name is required.` appears under the field. **OK** becomes disabled |
| 4 | Type `a@b` into the **Archive name** field | The message `Archive name is required.` disappears and the message `Only letters, digits, spaces, dot, dash and underscore are allowed.` appears under the field instead. **OK** stays disabled |
| 5 | Clear the field and type a valid name, e.g. `my archive-1.2026` | No message is shown under the field. **OK** becomes enabled |
| 6 | Click **Cancel** | The pop-up closes. No archive-download task is queued |
