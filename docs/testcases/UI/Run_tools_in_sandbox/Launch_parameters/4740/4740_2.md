# "Add system parameter" dialog is cleared when it is opened again

Test verifies that
- the ***Add system parameter*** dialog starts empty each time it is opened: no parameter is selected, and the search field is empty, on the launch form and in the Tool settings

**Prerequisites**:
- Admin user
- Test tool
- The `CP_FSBROWSER_ENABLED` parameter is defined in the **`launch.system.parameters`** preference
- The test tool's settings do not define the `CP_FSBROWSER_ENABLED` parameter

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | At the tool page, hover over the **Run v** button | |
| 5 | Click the **Custom settings** button in the list | |
| 6 | Expand the **ADVANCED** section | |
| 7 | Click ***Add system parameter*** button in the ***System parameters*** section | The ***Select system parameter to override*** pop-up opens. The **OK** button is disabled |
| 8 | Input `CP_FSBROWSER` into the search field | Only the parameters that contain `CP_FSBROWSER` are shown in the list |
| 9 | Click the `CP_FSBROWSER_ENABLED` row in the list | <li> The row is marked as selected <li> The **OK** button shows `OK (1)` |
| 10 | Click the **Cancel** button | The pop-up closes. `CP_FSBROWSER_ENABLED` is not added to the ***System parameters*** section |
| 11 | Click ***Add system parameter*** button in the ***System parameters*** section | <li> The search field is empty <li> All the system parameters are shown in the list <li> No row is marked as selected <li> The **OK** button is disabled and shows `OK` without a count |
| 12 | Click the `CP_FSBROWSER_ENABLED` row in the list and click the **OK** button | `CP_FSBROWSER_ENABLED` appears in the ***System parameters*** section |
| 13 | Click ***Add system parameter*** button in the ***System parameters*** section | <li> `CP_FSBROWSER_ENABLED` is not shown in the list <li> No row is marked as selected <li> The **OK** button is disabled |
| 14 | Click the **Cancel** button | |
| 15 | Open the **Tools** page | |
| 16 | Select the test tool from the prerequisites | |
| 17 | Click the **SETTINGS** tab | |
| 18 | Expand the **EXECUTION ENVIRONMENT** section | |
| 19 | Click ***Add system parameters*** button in the ***System parameters*** section | The ***Select system parameter to override*** pop-up opens. The **OK** button is disabled |
| 20 | Repeat steps 8-11, clicking ***Add system parameters*** at step 11 | The expected results are the same |
| 21 | Click the **Cancel** button | The tool settings are not changed |
