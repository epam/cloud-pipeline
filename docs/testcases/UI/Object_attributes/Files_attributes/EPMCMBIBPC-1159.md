# Validation of attributes for file in the bucket

Test verifies the attributes panel shown for an uploaded file.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Library** page |  |
| 2 | Hover over **+ Create v** |  |
| 3 | In the list that appears, select **Storages** -> click **Create new object storage** |  |
| 4 | Specify a valid storage path |  |
| 5 | Click **Create** |  |
| 6 | Open the created storage |  |
| 7 | Click **Upload** |  |
| 8 | In the pop-up that appears, select a file, confirm the upload |  |
| 9 | Click on the uploaded file | The panel appears on the right side, containing: <li>the **+ Add**, **Remove all**, **Enlarge** buttons <li>a text area with the file content (file preview) <li>an **Owner** value containing the current user name |
