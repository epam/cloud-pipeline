# "Capacity retries" field is available for a Pipeline, a Detached configuration, a Launch profile and a Rerun

Test verifies that the ***Capacity retries*** field, and the value set in it, are available
- in a pipeline's **CONFIGURATION** tab
- in a Detached configuration
- in a user's Launch profile (**Settings** -> **My Profile** -> **LAUNCH PROFILES**)
- on the ***Launch*** form opened via the **Rerun** hyperlink of a previously launched run

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Perform [4608_2](4608_2.md) and [4608_4](4608_4.md) cases

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create a pipeline (`test_pipeline1`) and select the test tool as its docker image
3. Create a Detached configuration (`test_configuration1`) and select the test tool as its docker image

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Library** page | |
| 2 | Open the `test_pipeline1` pipeline created at step 2 of the preparations | |
| 3 | Open the **CONFIGURATION** tab | |
| 4 | Expand the **Exec environment** section | ***Capacity retries*** field is shown, empty, with placeholder `N` |
| 5 | Input `3` into the ***Capacity retries*** field | |
| 6 | Click **Save** button | |
| 7 | Reload the page. Repeat steps 3-4 | ***Capacity retries*** field value is `3` |
| 8 | Click the **RUN** button, then **Launch** button on the pop-up | |
| 9 | At the **Runs** page, click the just-launched run. Expand the **Parameters** section | `CP_NODEUP_RETRY_COUNT: 3` is shown |
| 10 | Open the **Library** page | |
| 11 | Open the `test_configuration1` Detached configuration created at step 3 of the preparations | |
| 12 | Expand the **Exec environment** section | ***Capacity retries*** field is shown, empty, with placeholder `N` |
| 13 | Input `4` into the ***Capacity retries*** field | |
| 14 | Click **Save** button | |
| 15 | Reload the page. Repeat steps 11-12 | ***Capacity retries*** field value is `4` |
| 16 | Click the **RUN** button, then **Launch** button on the pop-up | |
| 17 | At the **Runs** page, click the just-launched run. Expand the **Parameters** section | `CP_NODEUP_RETRY_COUNT: 4` is shown |
| 18 | Open the **Settings** page | |
| 19 | Open the **My Profile** tab | |
| 20 | Click the **LAUNCH PROFILES** tab | |
| 21 | Click **Add profile** button | |
| 22 | Input `test_profile1` into the ***Profile name*** field | |
| 23 | Select the test tool's docker image for the profile. Expand the **Exec environment** section | ***Capacity retries*** field is shown, empty, with placeholder `N` |
| 24 | Input `5` into the ***Capacity retries*** field | |
| 25 | Click **Save** button | |
| 26 | Select another profile (or click **Add profile**), then select the `test_profile1` profile again | ***Capacity retries*** field value is `5` |
| 27 | Open the **Runs** page. Open **Completed runs** tab | |
| 28 | Click the run launched at steps 7-8 of the [4608_4](4608_4.md) case (launched with `CP_NODEUP_RETRY_COUNT` set to `7`) | |
| 29 | Click the **Rerun** hyperlink | ***Launch*** form opens with the ***Capacity retries*** field value `7` |

**After**:
- Stop the runs launched at steps 8 and 16
- Remove `test_pipeline1` pipeline, `test_configuration1` Detached configuration and `test_profile1` Launch profile
