# ROLE_PIPELINE_ADMIN: create new pipeline

Test verifies that user with role `ROLE_PIPELINE_ADMIN` can create new pipeline if has permissions on parent.

**Prerequisites**:
- admin user
- non-admin user with `ROLE_PIPELINE_ADMIN` role

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create folder (`folder1`)
3. Give all permissions to non-admin user from the prerequisites

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open **Library** | |
| 3 | Open folder `folder1` created at step 2 of the preparations | |
| 4 | Hover over *+ Create* button | Drop-down menu opens and contains *Pipeline* item |
| 5 | Click on "Pipeline" item | |
| 6 | In an appeared pop-up window specify a valid pipeline name. Click **CREATE** button | Created pipeline appears in the list |
