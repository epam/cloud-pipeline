# Create project folder

Test verifies creating a project folder with a "type: project" attribute.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Library** page |  |
| 2 | Hover over **+ Create v** |  |
| 3 | In the drop-down list that appears, select **Folder** and click it |  |
| 4 | Enter a folder name and click **OK** |  |
| 5 | Click on the created folder |  |
| 6 | Click the button for customizing the display of additional panels (in the upper-right corner) |  |
| 7 | Click **Attributes** in the list that appears |  |
| 8 | Click **+ Add** |  |
| 9 | Enter `type` in the **Key** field that appears |  |
| 10 | Enter `project` in the **Value** field that appears |  |
| 11 | Click **Add** | The folder is created |
