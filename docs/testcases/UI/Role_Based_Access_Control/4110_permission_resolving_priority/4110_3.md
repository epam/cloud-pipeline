# [Negative] Deny permission has priority over Allow permission within the same SID type

Test verifies that, when a user belongs to two groups with conflicting permissions on the same object,
a **Deny** permission granted to one group takes priority over an **Allow** permission granted to the
other group.

**Prerequisites**:
- admin user
- non-admin user (`user1`)
- two user groups (`test_group_4110_3a`, `test_group_4110_3b`), both with `user1` added as a member

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Library** page
3. Hover over **+ Create v**, click **Folder**. Specify a valid folder name (`folder_4110_3`), click **OK**
4. Open `folder_4110_3`, click the gear icon in the upper-right corner, click **Edit folder**
5. In the pop-up that appears, click the **Permissions** tab
6. Click the **Add group** button. Enter `test_group_4110_3a` from the prerequisites, click **OK**
7. In the list, click on `test_group_4110_3a`. Set the checkboxes in the **Allow** column opposite **Read** and **Write**
8. Click the **Add group** button. Enter `test_group_4110_3b` from the prerequisites, click **OK**
9. In the list, click on `test_group_4110_3b`. Set the checkboxes in the **Deny** column opposite **Read** and **Write**
10. Close the pop-up

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Logout and login as `user1` from the prerequisites | |
| 2 | Open the **Library** page | `folder_4110_3` is not displayed in the tree |
