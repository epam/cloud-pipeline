# [Manual] Read all and Refresh buttons work correctly in the Notifications section

Test verifies that the **Read all** button in the **Notifications** section marks all unread notifications as read, and that the **Refresh** button updates the list and the unread counter.

**Prerequisites**:
- Admin user
- Non-admin user (user1) with at least 2 unread push notifications

| Steps | Actions | Expected results |
|:---:|------|---|
| 1 | Login as user1 from the prerequisites | |
| 2 | Click the **Notifications** icon in the main menu | The **Notifications** section opens showing the unread notifications list |
| 3 | Note the number of unread notifications displayed | |
| 4 | Click the **Read all** button | All notifications in the unread list are marked as read. The unread notifications list becomes empty. The counter near the **Notifications** icon in the main menu resets to zero |
| 5 | Switch to the **Read** notifications list | All previously unread notifications are now present in the **Read** list |
| 6 | Trigger a new system event to generate a new push notification for user1 | |
| 7 | Without navigating away, click the **Refresh** button in the **Notifications** section | The new notification appears in the unread list. The unread counter near the **Notifications** icon updates accordingly |

**After**:
- No cleanup required.
