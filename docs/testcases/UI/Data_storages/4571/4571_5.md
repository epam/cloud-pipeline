# [Negative] A selection with no archive uploads immediately, with no confirmation pop-up

Test verifies that on a storage where the upload confirmation pop-up is offered, picking a batch of
files that holds no archive uploads right away, exactly as before this pop-up existed - the pop-up
never shows the **Cancel**/**Upload and extract**/**Upload** choice for such a batch.

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose
  share is mounted as NFS)

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. On the local machine, have ready two ordinary files, neither with an archive extension (e.g.
   `file1.txt`, `file2.png`)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click the **Upload** button, select both files from Preparations together in the OS file dialog and confirm | A pop-up titled **Uploading files...** opens straight away, with a progress row per file. At no point are **Cancel**, **Upload and extract** or **Upload** buttons shown together - the pop-up never pauses for a choice |
| 2 | Wait for the upload to finish | The pop-up closes on its own |
| 3 | Look at the storage listing | Both `file1.txt` and `file2.png` are present |

**After**:
- Delete `file1.txt` and `file2.png` from the storage
