# CP_NODEUP_RETRY_COUNT name is reserved when `ui.launch.allow.nodeup.count` is on

Test verifies that with the ***Capacity retries*** control on, `CP_NODEUP_RETRY_COUNT`
- is excluded from the ***Add system parameter*** dialog
- can't be used as a name for a manually-added parameter, in any case, both on the launch form and in the Tool settings

**Prerequisites**:
- Admin user
- Test tool available in the registry
- Perform [4608_2](4608_2.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | At the tool page, hover over the **Run v** button | |
| 4 | Click the **Custom settings** button in the list | |
| 5 | Expand the **ADVANCED** section | |
| 6 | Click ***Add system parameter*** button in the ***System parameters*** section | |
| 7 | Input `CP_NODEUP_RETRY_COUNT` into the search field | List of found parameters is empty |
| 8 | Click **Cancel** button | |
| 9 | Click ***Add parameter*** button in the ***Parameters*** section | |
| 10 | Input `CP_NODEUP_RETRY_COUNT` into the parameter name field | Error message `Name is reserved for system parameter` is shown under the field |
| 11 | Clear the parameter name field and input `cp_nodeup_retry_count` | Error message `Name is reserved for system parameter` is shown under the field |
| 12 | Open the **Tools** page | |
| 13 | Select the test tool from the prerequisites | |
| 14 | Click the **SETTINGS** tab | |
| 15 | Expand the **EXECUTION ENVIRONMENT** section | |
| 16 | Click ***Add system parameter*** button in the ***System parameters*** section | |
| 17 | Input `CP_NODEUP_RETRY_COUNT` into the search field | List of found parameters is empty |
| 18 | Click **Cancel** button | |
| 19 | Click ***Add parameter*** button in the ***Custom parameters*** section | |
| 20 | Input `CP_NODEUP_RETRY_COUNT` into the parameter name field | Error message `Parameter name is reserved` is shown under the field |
| 21 | Clear the parameter name field and input `cp_nodeup_retry_count` | Error message `Parameter name is reserved` is shown under the field |

**After**:
- Discard unsaved changes on the Tool **SETTINGS** tab
