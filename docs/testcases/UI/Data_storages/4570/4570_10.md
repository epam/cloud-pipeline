# Downloads window: unselecting every status applies no status filter at all

Test verifies that:
- unticking every status in the **Status** column's filter and confirming does **not** silently restore the default selection
- the table then applies no status filter, so it shows tasks of every status - `CANCELLED` and `EXPIRED` included
- the **Status** column's filter icon stays highlighted and the **Reset filters** button is offered, so the default is always reachable again
- **Reset filters** and the filter's own **Reset to defaults** both bring the default selection back

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose share is mounted as NFS), holding at least two files

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. Select a file via its checkbox, click the selection button (**"1 item selected"**), choose **Download archive**, then click **OK** without changing the offered name
4. Open the **Downloads** window: click the grid-icon button at the top right of the storage view and choose **Show downloads**
5. Click **Cancel** on the row of the task queued at step 3, and wait until its status becomes `CANCELLED`
6. Repeat step 3 for the other file, so there is also one task that is *not* cancelled

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Look at the table | Only the task queued at step 6 of Preparations is shown - the cancelled one is hidden by the default filter |
| 2 | Click the filter icon on the **Status** column's header | The filter dropdown opens, with every status ticked except `CANCELLED` and `EXPIRED` |
| 3 | Click the select-all checkbox at the top twice - once to tick every status, once to untick them all | No status checkbox is ticked, and the top checkbox reads **Select all** |
| 4 | Click **OK** | <li> The dropdown closes and the table reloads <li> Both tasks are shown - the cancelled one from step 5 of Preparations as well as the one from step 6 <li> The **Status** column's filter icon is highlighted <li> A **Reset filters** button appears above the table |
| 5 | Click the filter icon on the **Status** column's header again | No status is ticked - the empty selection was kept, not replaced by the default |
| 6 | Click **Reset to defaults** | <li> The dropdown closes and the table reloads <li> Only the non-cancelled task is shown again <li> The **Status** column's filter icon is no longer highlighted, and the **Reset filters** button disappears |
| 7 | Repeat steps 2-4 to empty the selection again, then click the **Reset filters** button above the table | <li> The table reloads and shows only the non-cancelled task <li> The **Status** column's filter icon is no longer highlighted, and the **Reset filters** button disappears |

**After**:
- Cancel the remaining task queued in Preparations from the **Downloads** window, or let it finish and discard the downloaded archive
