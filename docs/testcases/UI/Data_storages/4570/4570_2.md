# "Download archive" name pop-up: defaults and validation

Test verifies that:
- for a single selected file, the **Archive name** field is pre-filled with that file's own name plus `.zip`, with its own extension kept intact
- for a single selected folder, the field is pre-filled with that folder's own name plus `.zip`
- for a selection of several items, the field is pre-filled with a name built from the current date and time
- a name is not required to already end in `.zip` - the extension is appended automatically, and never doubled when it is already there
- a name with a character other than a letter, digit, space, underscore, hyphen or period is rejected with an error message once confirmed
- **Cancel** closes the pop-up and queues nothing

**Prerequisites**:
- An AWS S3 object storage with a file named, for example, `report.csv`, a folder named, for example, `report`, and at least one other file, exists

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Click on the checkbox near the `report.csv` file name |  |
| 4 | Click the **1 item selected** button, then click **Download archive** | The **Download archive** pop-up opens, with the **Archive name** field pre-filled with `report.csv.zip` |
| 5 | Click **Cancel** | The pop-up closes. No task appears if the **Downloads** window is opened afterwards |
| 6 | Click on the checkbox near the `report.csv` file name to unselect it, then click on the checkbox near the `report` folder name | |
| 7 | Click the **1 item selected** button, then click **Download archive** | The **Download archive** pop-up opens, with the **Archive name** field pre-filled with `report.zip` |
| 8 | Click **Cancel** | The pop-up closes |
| 9 | Click on the checkboxes near the `report` folder and one other file | |
| 10 | Click the **2 items selected** button, then click **Download archive** | The **Download archive** pop-up opens, with the **Archive name** field pre-filled with a name of the form `archive-<date> <time>`, e.g. `archive-2026-10-21 13-13-02` |
| 11 | Clear the **Archive name** field and type `my archive` (no extension), then click **OK** | The pop-up closes. A task named `my archive.zip` appears in the **Downloads** window |
| 12 | Repeat steps 9-10 | |
| 13 | Clear the **Archive name** field and type `my archive.zip` (already ending in `.zip`), then click **OK** | The pop-up closes. A task named `my archive.zip` (not `my archive.zip.zip`) appears in the **Downloads** window |
| 14 | Repeat steps 9-10 | |
| 15 | Clear the **Archive name** field and type `bad*name?`, then click **OK** | The pop-up closes right away. An error notification then appears, since the server rejects the name. No task is queued |
