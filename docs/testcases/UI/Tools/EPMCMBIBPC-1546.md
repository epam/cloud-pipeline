# Add tool description and change settings

Test verifies that a tool's full description and its **Disk (Gb)** execution setting can be edited and saved.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open **Tools** page |  |
| 2 | Select **Default** registry |  |
| 3 | Select a group |  |
| 4 | Click a tool |  |
| 5 | Click **EDIT** button in the **Full description** section |  |
| 6 | Add some text and click **SAVE** button |  |
| 7 | Click **SETTINGS** tab |  |
| 8 | Expand **EXECUTION ENVIRONMENT** section if it's minimized |  |
| 9 | Input a natural number in the **Disk (Gb)** field |  |
| 10 | Click **SAVE** button |  |
| 11 | Click **DESCRIPTION** tab | The description entered at step 6 is displayed |
