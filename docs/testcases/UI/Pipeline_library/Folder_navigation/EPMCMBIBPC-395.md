# Selecting pipeline version

Test verifies that clicking a pipeline version in the library-tree opens its page and highlights it.

**Prerequisites**:
- Perform the [EPMCMBIBPC-394](EPMCMBIBPC-394.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on the pipeline version in the library-tree | <li> the pipeline page is displayed on the right panel, containing **CODE**, **CONFIGURATION**, **DOCUMENTS**, **HISTORY**, **STORAGE RULES** tabs <li> the selected pipeline version is highlighted blue in the library-tree |
