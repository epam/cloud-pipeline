# Blacklisted tool version is visible but cannot be launched by a regular user

Test verifies that 
- a blacklisted tool version remains visible to a regular user on the **Versions** tab, but the user cannot launch it
- can't add or remove tool versions from the blacklist.

**Prerequisites**:
- Admin user
- Non-admin user (`user1`) 
- Perform [4419_1](4419_1.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | *Description* tab of tool page opens that contains `The latest version is on the black list. Try to find an older one.` message |
| 4 | Open the **Versions** tab | <li> The blacklisted `latest` version is visible in the versions list <li> **Run** button opposite `latest` version is disabled <li> ***Configure access*** button isn't shown opposite any version|
| 5 | Hover over the **Run** button | Tooltip `The latest version is on the black list. Try to find an older one.` appears |
