# ROLE_PIPELINE_ADMIN: managing permissions of existing pipeline

Test verifies that user with role `ROLE_PIPELINE_ADMIN` can fully manage existing pipeline.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_PIPELINE_ADMIN` role and Read/Write permissions to at least of 1 user (`user2`).
- non-admin user (`user3`)
- perform [4146_1_1](4146_1_1.md) case

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open **Library** page | 
| 3 | Open `pipeline1` |  |
| 4 | Click on *Gear-icon* in the upper right corner of the page | |
| 5 | Click on the *Permissions* tab | |
| 6 | Click on the *Owner* name | |
| 7 | Input `user2` name and select it in the drop-down list | |
| 8 | Click **Apply** button. Close *Edit pipeline info* pop-up | `user2` name is shown in the owner field near the pipeline name|
| 9 | Click on *Gear-icon* in the upper right corner of the page | |
| 10 | Click on the *Permissions* tab | |
| 11 | Click the *Add user* button. | |
| 12 | Input the non-admin `user3` name from the prerequisites. Click the **OK** button | |
| 13 | Allow ***Read*** and ***Write*** permissions to the non-admin user from the prerequisites. Click **Apply** button | <li> **Apply** button is disabled. <li> Added permissions are checked for `user3` |
| 14 | Close the *Edit pipeline info* pop-up | |
