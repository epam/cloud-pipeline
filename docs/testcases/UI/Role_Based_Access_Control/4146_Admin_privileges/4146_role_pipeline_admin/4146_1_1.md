# ROLE_PIPELINE_ADMIN: editing existing pipeline

Test verifies that user with role `ROLE_PIPELINE_ADMIN` can fully manage existing pipeline.

**Prerequisites**:
- admin user
- non-admin user with `ROLE_PIPELINE_ADMIN` role

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create pipeline (`pipeline1`)
3. In the `pipeline1` ***Attributes*** section add attribute `key1`/`value1`

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open **Library** page | 
| 3 | Click the "**All pipelines**" button | The list of all existing pipelines appears and contains the rows for the pipelines created at step 2 of the preparations. |
| 4 | Open `pipeline1` | <li> List contains pipeline draft version <li> *RUN* and *RELEASE* buttons are shown opposite the pipeline version |
| 5 | Open pipeline draft version. Click on *Gear-icon* in the upper right corner of the page | |
| 6 | In an appeared window specify a new valid value in *Name* field. Click **SAVE** button. | The pipeline name is equal to the inputted |
| 7 | Click on **CONFIGURATION** tab. Click on *Exec environment* header to expand the section. Change the value of *Disk (Gb)* field. Click **Save** button |  |
| 8 | Click on **CODE** tab. Click on `config.json` file | Value _`"instance_disk " : <value specified at step 7>`_ is displayed in the default configuration section |
| 9 | Close `config.json` file |  |
| 10 | Click on **STORAGE RULES** tab. Click on *Add new rule* button. Specify value into *File mask* field. Click **Create** button | In the table new record appears |
| 11 | Return to list of pipeline version |  |
| 12 | Click *RELEASE* button opposite the draft pipeline version | |
| 13 | In an appeared pop-up window input version name. Click *RELEASE* button | <li> Name of the pipeline version is equal to the inputted <li> *RELEASE* button opposite the pipeline version doesn't display |
