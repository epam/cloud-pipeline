# Price type validation

Test verifies the fields shown when expanding the **Advanced** section on a detached configuration.

**Preparations**:
1. Complete the [EPMCMBIBPC-1091](EPMCMBIBPC-1091.md) case
2. Open the created detached configuration

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Expand the **Advanced** collapsed header | <li> **Price type**, **Timeout (min)**, **Cmd template** fields, the **Start idle** checkbox and question-mark icons near them appear <li> the default price type is selected in the **Price type** combobox |
