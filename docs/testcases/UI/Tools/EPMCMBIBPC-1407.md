# Enable tool validation

Test verifies that a previously deleted tool can be re-enabled by name and reappears in the tools list.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1404](EPMCMBIBPC-1404.md) case |  |
| 2 | Open **Tools** page |  |
| 3 | Select **Default** registry |  |
| 4 | Select the group used at step 1 |  |
| 5 | Click the gear icon |  |
| 6 | Click **+ Enable tool** in the appeared list |  |
| 7 | Input the name of the tool removed at step 1 in the appeared pop-up |  |
| 8 | Click **ENABLE** button | The tool removed at step 1 is displayed in the tools list |
