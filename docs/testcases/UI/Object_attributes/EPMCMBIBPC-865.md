# Check attributes for sub-folder

Test verifies that a subfolder's own attributes are not shown when navigating to its parent.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Library** page |  |
| 2 | Hover over **+ Create v** |  |
| 3 | Click **Folder** in the list that appears |  |
| 4 | Specify a valid folder name |  |
| 5 | Click **OK** |  |
| 6 | Open the created folder |  |
| 7 | Repeat steps 2-6 |  |
| 8 | Click the button for customizing the display of additional panels (in the upper-right corner) |  |
| 9 | Click **Attributes** in the list that appears |  |
| 10 | Click **+ Add** |  |
| 11 | Enter a value into the **Key** field |  |
| 12 | Enter a value into the **Value** field |  |
| 13 | Click **Add** |  |
| 14 | Click **..** to navigate to the parent folder | The attributes added at step 13 are not displayed |
