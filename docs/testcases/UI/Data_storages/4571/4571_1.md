# Picking an archive together with other files pauses the upload behind a confirmation pop-up

Test verifies that:
- picking a batch of files that includes at least one archive, on a storage where this mode is
  offered, opens an **Upload files** pop-up before anything is uploaded
- the pop-up lists one row per picked file, each showing the file's name only - no icon marks the
  archive's row apart from the others
- the pop-up offers three buttons: **Cancel**, **Upload and extract** and **Upload**
- no progress bar is shown while the pop-up is in this state - nothing has started uploading yet

**Prerequisites**:
- A user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose
  share is mounted as NFS)

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. On the local machine, have ready: two ordinary files (e.g. `file1.txt`, `file2.txt`) and one
   archive file (e.g. `archive1.zip`)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click the **Upload** button |  |
| 2 | In the OS file dialog, select all three files from Preparations together and confirm | The **Upload files** pop-up opens. No files have been uploaded yet |
| 3 | Look at the pop-up | <li> There is one row per selected file: `file1.txt`, `file2.txt`, `archive1.zip`, each showing the file's name only - no size is shown <li> No row carries an icon or other marker singling out `archive1.zip` as an archive <li> No progress bar or percentage is shown on any row <li> Three buttons are shown at the bottom, left to right: **Cancel**, **Upload and extract**, **Upload** (highlighted as the primary action) |
| 4 | Click **Cancel** | The pop-up closes. None of the three files were uploaded |

**After**:
- None - nothing was uploaded
