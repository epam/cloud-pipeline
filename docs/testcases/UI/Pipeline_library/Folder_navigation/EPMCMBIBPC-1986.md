# [MANUAL] Clone folder with detach configuration

Test verifies cloning a folder that contains a detached configuration, into a new folder at the same level.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open **Library** page |  |
| 2 | Hover over **+ Create v** button -> click **Folder** item in the appeared dropdown list |  |
| 3 | Specify a valid folder name in the appeared pop-up, click **OK** button |  |
| 4 | Open the just-created folder |  |
| 5 | Hover over **+ Create v** button -> click **Configuration** item in the appeared dropdown list |  |
| 6 | Specify a valid configuration name in the appeared pop-up, click **CREATE** button |  |
| 7 | Hover over the gear icon in the right upper corner -> click **Clone** item in the appeared dropdown list |  |
| 8 | Specify a valid new name in the appeared pop-up |  |
| 9 | Click **Clone into {folder_name}** button | A cloned folder is displayed that contains a detach configuration with the name equal to the one specified at step 6; the cloned folder is at the same level as the original folder created at step 3 |
