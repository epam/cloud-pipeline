# Folder editing

Test verifies renaming a folder.

**Prerequisites**:
- A storage with a folder exists

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Click on the edit icon opposite the folder name |  |
| 4 | Specify a new name for the folder in the appeared pop-up window |  |
| 5 | Click **OK** button | The folder's name is changed to the one specified at step 4 |
