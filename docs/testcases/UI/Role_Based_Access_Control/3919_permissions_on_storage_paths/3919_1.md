# Access denied for user without permition to any storage's entity

Test verifies that for storages created with option _Fine-grained permissions_ non-admin user with `READ/WRITE` permissions to storage but without permissions to any file/folder couldn't see storage content

**Prerequisites**:
- Admin user
- User group (`user_group1`)
- Non-admin user (`user1`) is a member of this user group `user_group1`

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as admin user from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Create the object storage `storage1` with option _Fine-grained permissions_ | |
| 4 | Open the created storage `storage1` | |
| 5 | Give `READ/WRITE` permissions to the non-admin user from the prerequisites | |
| 6 | Logout and login as non-admin user from the prerequisites | |
| 7 | Open the **Library** page | |
| 8 | Open `storage1` | Error message `Error retrieving data storage items: Access is denied` is shown on the storage page |
