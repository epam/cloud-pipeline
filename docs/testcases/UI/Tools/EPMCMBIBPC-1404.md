# Delete tool validation

Test verifies that deleting a tool removes it from the tools list.

**Prerequisites**:
- Login as administrator or tool owner

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open **Tools** page |  |
| 2 | Select **Default** registry |  |
| 3 | Select a group |  |
| 4 | Click a tool |  |
| 5 | Click the gear icon |  |
| 6 | Click **Delete tool** in the appeared list |  |
| 7 | Click **OK** button in the appeared pop-up | <li> the page of the group selected at step 3 appears <li> the removed tool is not displayed |
