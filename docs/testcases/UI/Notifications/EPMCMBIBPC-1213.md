# Validation of displaying of several active notification

Test verifies that several active notifications all appear together.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1212](EPMCMBIBPC-1212.md) case |  |
| 2 | Click the system-settings button (gear icon in the left panel) |  |
| 3 | Click the **System events** tab |  |
| 4 | Set the **Active** checkbox opposite all notifications added at step 1 |  |
| 5 | Click **Refresh** |  |
| 6 | Wait until the notifications appear | 3 notifications appear: <li>the title texts are equal to the corresponding ones entered in the [EPMCMBIBPC-1212](EPMCMBIBPC-1212.md) case <li>the body texts are equal to the corresponding ones entered in the [EPMCMBIBPC-1212](EPMCMBIBPC-1212.md) case <li>the severity values are equal to the corresponding ones specified in the [EPMCMBIBPC-1212](EPMCMBIBPC-1212.md) case |

**After**:
- Click the close icons for all notifications
