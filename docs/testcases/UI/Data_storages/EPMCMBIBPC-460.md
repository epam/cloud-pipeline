# Validation of delete folder with content

Test verifies that deleting a folder removes it together with all of its content.

**Prerequisites**:
- A storage with a folder that contains files and subfolders exists

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Click on the delete icon opposite the folder name |  |
| 4 | Click **OK** button in the appeared pop-up window | The folder doesn't display in the storage. The storage is empty |
