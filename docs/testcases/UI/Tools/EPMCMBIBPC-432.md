# Check of description adding at tool enabling

Test verifies editing and saving both the short and full description of a tool.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open **Tools** page |  |
| 2 | Select **Default** registry |  |
| 3 | Select a group |  |
| 4 | Click a tool |  |
| 5 | Click **EDIT** button in the **Short description** section | In the **Short description** section: <li> **EDIT** button is not displayed <li> **CANCEL**, **SAVE** buttons appear |
| 6 | Input some text |  |
| 7 | Click **SAVE** button | In the **Short description** section: <li> **EDIT** button appears <li> **CANCEL**, **SAVE** buttons are not displayed <li> the text entered at step 6 is displayed |
| 8 | Click **EDIT** button in the **Full description** section | In the **Full description** section: <li> **EDIT** button is not displayed <li> **CANCEL**, **SAVE** buttons appear |
| 9 | Input some text |  |
| 10 | Click **SAVE** button | In the **Full description** section: <li> **EDIT** button appears <li> **CANCEL**, **SAVE** buttons are not displayed <li> the text entered at step 9 is displayed |
