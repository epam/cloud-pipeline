# Delete several folders

Test verifies deleting several selected folders at once.

**Prerequisites**:
- A storage with more than one folder exists

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Click on the checkbox near the first folder name |  |
| 4 | Click on the checkbox near the second folder name |  |
| 5 | Click the appeared **Remove all selected** button |  |
| 6 | Click **OK** button in the appeared pop-up window | The folders selected at steps 3, 4 are removed and don't display in the storage |
