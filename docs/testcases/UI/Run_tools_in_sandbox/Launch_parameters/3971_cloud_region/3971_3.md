# Mount rules: check Mount Storages located in the certain region via pipe CLI

Test verifies that storages 
- are mounted only to the instances located in the same cloud region with the storage if option `Same region` is selected for *Object storages* and *File storages* in the Cloud region *Mount rules*
- aren't mounted to the instances independently of instance regions if option `None` is selected for *Object storages* and *File storages* in the Cloud region *Mount rules*.

**Prerequisites**:
- admin user
- Perform [3971_1](3971_1.md)

**Preparations**
1. Login as admin user from the prerequisites
2. Open the **Settings** page >> **CLOUD REGIONS** tab
3. Select `region1` on the left panel >> In the **Mount rules:** section select option `Same region` for *Object storages* and *File storages*. Click **Save** button.
4. Select `region2` on the left panel >> In the **Mount rules:** section select option `None` for *Object storages* and *File storages*. Click **Save** button.
