# IDLE_GPU tag is shown with timestamp for a GPU run with no GPU activity

Test verifies that 
- a run launched on a GPU instance with no GPU activity is tagged with **IDLE_GPU** and the tag displays a timestamp tooltip on the **Runs** page, **Run log** page, and **Dashboard**.
- **IDLE** tag isn't shown until the both tags **IDLE_CPU** and **IDLE_GPU** appear.

**Prerequisites**:
- Admin user
- Test tool available in the registry that can run on a GPU instance type
- GPU instance available in the cloud region

**Preparations**:
1. Login as the admin user from the prerequisites
2. Save the `system.idle.monitoring.config` system preference value.
3. Set `system.idle.monitoring.config` system preference value to:

```
[
 {
 "type": "CPU",
  "enabled": true,
  "thresholdPercent": 60,
  "gracePeriodMinutes": 15,
  "actionTimeoutMinutes": 10,
 `"action": "NOTIFY"
 },
 {
 "type": "GPU",
  "enabled": true,
  "gracePeriodMinutes": 4,
  "actionTimeoutMinutes": 10,
  "action": "NOTIFY"
 },
 {
  "type": "ABSOLUTE",
  "enabled": true,
  "actionTimeoutMinutes": 15,
  "action": "NOTIFY"
 }
]
```

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Launch the tool on a GPU instance type with default settings | |
| 4 | At the **Runs** page, click the just-launched run | |
| 5 | Wait until the **SSH** hyperlink appears and the idle detection period (`gracePeriodMinutes` for `GPU` from `system.idle.monitoring.config`) elapses | <li> ***IDLE_GPU*** tag appears in the **Instance** section <li> ***IDLE_CPU*** and ***IDLE*** aren't shown |
| 6 | Hover over the ***IDLE_GPU*** tag on the run log page | Tooltip appears that contains a timestamp with corresponding value |
| 7 | Click on the ***IDLE_GPU*** tag | The **Monitor** of the node resource utilization opens |
| 8 | Open the **Runs** page | ***IDLE_GPU*** tag is shown near the just-launched run name |
| 9 | Hover over the ***IDLE_GPU*** tag | Tooltip appears that contains a timestamp with value about 1 minute |
| 10 | Open the **Dashboard** page | In the **Active runs** section ***IDLE_GPU*** tag is shown for the run launched at step 3 |
| 11 | Hover over the ***IDLE_GPU*** tag on the Dashboard | Tooltip appears that contains a timestamp with corresponding value |
| 12 | Wait until the idle detection period (`gracePeriodMinutes` for `CPU` from `system.idle.monitoring.config`) elapses | ***IDLE_CPU*** and ***IDLE*** tags appear simultaneously |
