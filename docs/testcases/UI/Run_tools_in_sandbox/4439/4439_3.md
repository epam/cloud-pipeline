# Custom endpoint with displayOnCompletion=false is hidden after run completion

Test verifies that a custom endpoint with `displayOnCompletion` set to `false` is visible during an active run but is hidden once the run reaches a terminal state (e.g., `SUCCESS` or `FAILURE`).

**Prerequisites**:
- admin user
- test tool or pipeline that completes on its own (or can be stopped) available in the registry

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Click the **Run** button | Run launch form opens |
| 5 | Expand the **Parameters** section. Click **Add system parameter** | |
| 6 | Enter key `EXTERNAL_URLS` and value `[{"url": "https://example.com", "name": "Temp Link", "displayOnCompletion": false}]` | |
| 7 | Click **Launch** | Run is launched |
| 8 | Wait until the run reaches `RUNNING` state (SSH link appears) | |
| 9 | Click on the run to open the run log page | |
| 10 | Locate the **Endpoints** section | A link **Temp Link** pointing to `https://example.com` is displayed in the **Endpoints** section |
| 11 | Return to the **Runs** page. Stop the run | Run transitions to `STOPPED` state |
| 12 | Click on the stopped run to open the run log page | |
| 13 | Locate the **Endpoints** section | The **Temp Link** custom endpoint is **not** displayed in the **Endpoints** section |
