# A version without own settings is launched with the settings of the default version

Test verifies that
- the **Settings** tab of a tool shows and saves the settings of its default version
- a version, which has no own settings, is launched from the GUI with the settings of the default version, and not of the **latest** one
- a version, which has own settings, is launched with them

This is the counterpart of [EPMCMBIBPC-2720](../EPMCMBIBPC-2720.md), which checks the same hierarchy while no default version is set.

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least two other versions, without a default version set, and without settings of any version
- `<version>` and `<other>` are two test tool versions, which are not the **latest** one

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page and select the test tool from the prerequisites | |
| 2 | Click the **VERSIONS** tab, click the **latest** version, click its **SETTINGS** tab | |
| 3 | Specify valid values for **Instance type**, **Disk (Gb)**, **Cmd template**, and click **SAVE** | |
| 4 | Return to the test tool page and click the **SETTINGS** tab | <li> Alert `Execution environment settings will be applied to the default version <version>.` is shown <li> **Instance type**, **Disk (Gb)**, **Cmd template** fields of the **EXECUTION ENVIRONMENT** section are empty |
| 5 | Specify valid values for **Instance type**, **Disk (Gb)**, **Cmd template**, distinct from the ones specified at step 3, and click **SAVE** | |
| 6 | Click the **VERSIONS** tab, click the `<version>` version, click its **SETTINGS** tab | **Instance type**, **Disk (Gb)**, **Cmd template** are the ones specified at step 5 |
| 7 | Return to the test tool page, click the **VERSIONS** tab | |
| 8 | At the row of the `<other>` version, hover over the **v** button next to the **Run** button, click **Custom settings** in the appeared list | |
| 9 | Expand the **Exec environment** and **Advanced** sections | The launch page contains: <li> `Launch <tool_name> <other>` <li> **Node type**, **Disk (Gb)**, **Cmd template** equal to the ones specified at step 5 |
| 10 | Return to the test tool page, click the **VERSIONS** tab. At the row of the **latest** version, hover over the **v** button next to the **Run** button, click **Custom settings** in the appeared list | |
| 11 | Repeat step 9 | The launch page contains: <li> `Launch <tool_name> latest` <li> **Node type**, **Disk (Gb)**, **Cmd template** equal to the ones specified at step 3 |
| 12 | Return to the test tool page. Hover over the **v** button next to the **Run** button in the right upper corner, click **Custom settings** in the appeared list | |
| 13 | Repeat step 9 | The launch page contains: <li> `Launch <tool_name> <version>` <li> **Node type**, **Disk (Gb)**, **Cmd template** equal to the ones specified at step 5 |

**After**:
- Remove the default version of the test tool, as described in [4664_3](4664_3.md) (steps 1-4)
- Clear the settings saved at steps 3 and 5
