# "Show optional parameters" checkbox overrides for a single pipeline

Test verifies that an `optional-parameters-filter` override:
- by a pipeline id hides the **Show optional parameters** checkbox for that pipeline only
- by a pipeline name, in any letter case, changes the default value for that pipeline only

**Prerequisites**:
- Admin user
- Non-admin user `<user>` that is a member of the group `<user_group>`
- `<user>` and its roles have no `ui-launch-form` attribute
- 3 pipelines `<pipeline_1>`, `<pipeline_2>` and `<pipeline_3>` that `<user>` can run, each with a non-required parameter `<param>` in its `config.json`
- `<pipeline_1_id>` is the id of `<pipeline_1>`

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Miscellaneous** tab and find the `misc.groups.ui.preferences` preference
5. Save the current value of the preference
6. Set the preference value to the following, with the name of `<pipeline_2>` in upper case:
```
{
  "<user_group>": {
    "ui-launch-form": {
      "pipelines": {
        "optional-parameters-filter": {
          "default_value": true,
          "overrides": {
            "<pipeline_1_id>": false,
            "<PIPELINE_2>": {"default_value": false}
          }
        }
      }
    }
  }
}
```
7. Click **Save** button
8. Logout

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin user `<user>` from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Open the pipeline `<pipeline_1>` from the prerequisites | |
| 4 | Click **Run** button | <li> The launch form opens <li> The **Parameters** section header has no **Show optional parameters** checkbox <li> The parameter `<param>` is shown |
| 5 | Open the pipeline `<pipeline_2>` from the prerequisites and click **Run** button | <li> The **Show optional parameters** checkbox is shown and unchecked <li> The parameter `<param>` is hidden |
| 6 | Open the pipeline `<pipeline_3>` from the prerequisites and click **Run** button | <li> The **Show optional parameters** checkbox is shown and checked <li> The parameter `<param>` is shown |

**After**:
- Restore the saved value of the `misc.groups.ui.preferences` preference
