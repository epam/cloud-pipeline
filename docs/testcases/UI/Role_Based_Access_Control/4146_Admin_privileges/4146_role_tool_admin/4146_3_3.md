# ROLE_TOOL_ADMIN: edit Instance management items

Test verifies that user with role `ROLE_TOOL_ADMIN`  can specify some restrictions on allowed instance and price types, and jobs visibility for launching tool.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_TOOL_ADMIN` role.

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | | 
| 2 | Open **Tools** page | |
| 3 | Select test tool | |
| 4 | Hover over icon left to the gear icon in the right upper corner | |
| 5 | In an appeared list click on ***Instance management*** item | |
| 6 | In an appeared panel specify mask value into *Allowed tool instance types mask* (e.g. `m5.*`) | |
| 7 | Click on *Allowed price types* combobox, select the value in dropdown list (e.g. *On demand*) | |
| 8 | Click on *Jobs visibility* combobox, select the value in dropdown list (e.g. `Only owner`) | |
| 9 | Click **APPLY** button | Tool restrictions are saved without errors |

**After** 
- Clear *Allowed tool instance types mask*, *Allowed price types* and *Jobs visibility* fields
