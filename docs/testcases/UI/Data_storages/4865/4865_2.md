# [MANUAL] An item focused by keyboard is not hidden under the sticky rows

Test verifies that an item of a storage list focused by the keyboard is scrolled into view below the controls row and the column header.

**Prerequisites**:
- Admin user

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create the object storage
3. Upload into the storage more files than fit the storage panel (e.g. 40 files)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Make the browser window 1400 px wide or wider | |
| 3 | Open the **Library** page | |
| 4 | Open the storage created at step 2 of the Preparations | The column names of the column header (**Name**, **Size**, **Date changed**) are shown on one line |
| 5 | Scroll the list down to its middle | |
| 6 | Click the checkbox of the first row that is fully shown under the column header | The row is selected |
| 7 | Press **Shift+Tab** | <li> The focus moves to the last button of the previous row (**Delete**) <li> The list scrolls so that the focused button is shown below the column header, not under it |
| 8 | Press **Shift+Tab** several times more | Each focused item is shown below the column header |

**After**:
- Delete the storage created at step 2 of the Preparations
