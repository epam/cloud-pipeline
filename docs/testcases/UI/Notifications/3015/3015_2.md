# [Manual] Clicking a push notification opens it in a pop-up and marks it as read on close

Test verifies that clicking a push notification tile opens the full notification body in a pop-up, and that closing the pop-up marks the notification as read and decrements the unread counter near the Notifications icon.

**Prerequisites**:
- Admin user
- Non-admin user (user1) with at least one unread push notification already received

| Steps | Actions | Expected results |
|:---:|------|---|
| 1 | Login as user1 from the prerequisites | |
| 2 | Observe the **Notifications** icon in the main menu | A numeric counter showing the number of unread notifications is displayed next to the icon |
| 3 | Wait for or trigger a push notification tile to appear in the top-right corner | A push notification tile is visible in the top-right corner |
| 4 | Note the current unread counter value near the **Notifications** icon | |
| 5 | Click the push notification tile | The full notification content opens in a pop-up with the complete subject and body |
| 6 | Close the pop-up | The pop-up closes. The notification is marked as **read**. The unread counter near the **Notifications** icon decreases by 1 |

**After**:
- No cleanup required.
