# Custom endpoints are shown in all run log form views (Default, Nextflow, MLflow)

Test verifies that custom endpoints defined via the `EXTERNAL_URLS` tag appear in the **Endpoints** section across all run log form views: Default, Nextflow, and MLflow.

**Prerequisites**:
- admin user
- test Nextflow pipeline and test MLflow tool available, or the ability to observe the same run log in different view modes

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select a regular test tool | |
| 4 | Click the **Run** button | Run launch form opens |
| 5 | Click **Launch** | Run is launched |
| 6 | Add external url to the just-launched run as json `{"tags": {"EXTERNAL_URLS": "[{\"url\": \"https://example.com\", \"name\": \"Custom Endpoint\"}]"}}` using the `/pipeline/restapi/run/<runID>/tag?overwrite=true` API method | |
| 7 | Wait until the run reaches `RUNNING` state | |
| 8 | Click on the run to open the run log page (Default view) | **Custom Endpoint** link is displayed in the **Endpoints** section |
| 9 | Stop the run. Launch a **Nextflow** pipeline from the prerequisites, repeating step 6 with the same `EXTERNAL_URLS` value | |
| 10 | Wait until the Nextflow run reaches `RUNNING` state. Open the run log page | **Custom Endpoint** link is displayed in the **Endpoints** section of the Nextflow run log view |
| 11 | Stop the run. Launch an **MLflow** tool from the prerequisites, repeating step 6 with the same `EXTERNAL_URLS` value | |
| 12 | Wait until the MLflow run reaches `RUNNING` state. Open the run log page | **Custom Endpoint** link is displayed in the **Endpoints** section of the MLflow run log view |

**After**:
- Stop all runs launched during this test case.
