# Validation of delete active notification

Test verifies deleting an active notification.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1213](EPMCMBIBPC-1213.md) case |  |
| 2 | Click the system-settings button (gear icon in the left panel) |  |
| 3 | Click the **System events** tab |  |
| 4 | Click the delete icon opposite any notification |  |
| 5 | Click **OK** in the pop-up that appears | The removed notification is not displayed in the notifications table |
| 6 | Click **Refresh** | The removed notification is not displayed |
