# "Download"/"Download archive" selection items depend on what is selected

Test verifies that:
- a selection of a single file offers only **Download**
- a selection of a single folder offers only **Download archive**
- a selection of 2-3 files offers both **Download** and **Download archive**
- a selection of 4 or more files offers only **Download archive**
- adding a folder to any files selection does not count towards the 1-3 files limit of **Download**

**Prerequisites**:
- An object storage with at least 5 files and 1 folder at the same level exists

| Steps | Actions | Expected results |
| :---: |---| --- |
| 1 | Open **Library** page | |
| 2 | Click on the storage in the library-tree | |
| 3 | Check the checkbox near a single file name | |
| 4 | Click the **1 item selected** button | The dropdown contains a **Download** item and does not contain a **Download archive** item |
| 5 | Uncheck the checkbox near the file selected at step 3, then check the checkbox near a folder name | |
| 6 | Click the **1 item selected** button | The dropdown contains a **Download archive** item and does not contain a **Download** item |
| 7 | Uncheck the checkbox near the folder selected at step 5, then check the checkboxes near 2 file names | |
| 8 | Click the **2 items selected** button | The dropdown contains both a **Download** item and a **Download archive** item |
| 9 | Check the checkbox near a 3rd file name | |
| 10 | Click the **3 items selected** button | The dropdown contains both a **Download** item and a **Download archive** item |
| 11 | Check the checkbox near the folder (keeping the 3 files selected) | |
| 12 | Click the **4 items selected** button | The dropdown still contains both a **Download** item and a **Download archive** item - the folder does not count towards the 3-file limit |
| 13 | Uncheck the checkbox near the folder, then check the checkbox near a 4th file name | |
| 14 | Click the **4 items selected** button | The dropdown contains a **Download archive** item and does not contain a **Download** item |
