# Custom endpoints from EXTERNAL_URLS are shown in the Endpoints section

Test verifies that URLs defined in the `EXTERNAL_URLS` reserved run tag appear in the **Endpoints** section of the run log form alongside existing tool endpoints.

**Prerequisites**:
- admin user
- test tool available in the registry

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Click the **Run** button | Run launch form opens |
| 5 | Expand the **Parameters** section. Click **Add system parameter** | |
| 6 | Enter key `EXTERNAL_URLS` and value `[{"url": "https://example.com", "name": "My Custom Link"}]` | |
| 7 | Click **Launch** | Run is launched |
| 8 | Open the **Runs** page and wait until the run reaches `RUNNING` state (SSH link appears) | |
| 9 | Click on the run to open the run log page | |
| 10 | Locate the **Endpoints** section on the run log page | The **Endpoints** section contains a link with label **My Custom Link** pointing to `https://example.com`, displayed alongside any native tool endpoints |

**After**:
- Stop the run launched at step 7.
