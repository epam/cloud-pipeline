# [MANUAL] Sticky rows of a storage list are opaque in every theme

Test verifies that the controls row and the column header of a storage list hide the rows scrolled under them in the **Light**, **Dark** and **Dark dimmed** themes.

**Prerequisites**:
- Admin user

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create the object storage
3. Upload into the storage more files than fit the storage panel (e.g. 40 files)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **MY PROFILE** tab, then the **Appearance** subtab | |
| 4 | Save the current **Mode** and theme, then set **Mode** to **Single theme** | |
| 5 | Select the **Light** theme | The pages are shown in the **Light** theme |
| 6 | Open the storage created at step 2 of the Preparations | |
| 7 | Scroll the list down to its middle | <li> The rows scrolled under the controls row and the column header are not seen through them <li> The controls row has a top border, and the column header is separated from the rows under it |
| 8 | Repeat steps 2-3 | |
| 9 | Select the **Dark** theme | The pages are shown in the **Dark** theme |
| 10 | Repeat steps 6-7 | The expected results are the same as at step 7 |
| 11 | Repeat steps 2-3 | |
| 12 | Select the **Dark dimmed** theme | The pages are shown in the **Dark dimmed** theme |
| 13 | Repeat steps 6-7 | The expected results are the same as at step 7 |

**After**:
- Restore the **Mode** and the theme saved at step 4
- Delete the storage created at step 2 of the Preparations
