# Pipeline run form validation

**Prerequisites**:
- Perform the [EPMCMBIBPC-298](EPMCMBIBPC-298.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the pipeline created at the [EPMCMBIBPC-298](EPMCMBIBPC-298.md) case |  |
| 2 | Click **RUN** button in the upper right corner of the pipeline page | The pipeline launch page appears, containing: <li> the pipeline name <li> the **Launch** button <li> the header **Estimated price for hour** <li> the collapsed header **Exec environment** (minimized by default) <li> the collapsed header **Advanced** (minimized by default) <li> the collapsed header **Parameters** (expanded by default) <li> the **Add parameter** button |
