# [MANUAL] Create issue for tool

Test verifies creating an issue for a tool.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page |  |
| 2 | Select a registry and tool group |  |
| 3 | Click on any tool |  |
| 4 | Click the button in front of the gear icon in the upper-right corner |  |
| 5 | Click **Issues** in the list that appears | The **Issues** panel appears, containing: <li>the **New issue** button <li>the "No issues found" label |
| 6 | Click **New issue** |  |
| 7 | Specify valid values for the issue title and description, click **Create** | In the **Issues** panel, a new record for the issue appears, containing: <li>the issue title equal to the one specified at step 7 <li>the text "Opened {some time} ago by {USER_NAME}", where {USER_NAME} is the name of the user who created the issue |
| 8 | Repeat steps 1, 2 | In the row with the tool selected at step 3, the number "1" appears on the issues button |
