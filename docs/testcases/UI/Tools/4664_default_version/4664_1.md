# The latest version is used until a default version is set

Test verifies that
- while a default version is not set for a tool, no version has the **default** label, though the **latest** version is used
- the "Set as default" button is shown for every version, the **latest** one included
- the **Run** button at the top of the tool page launches the **latest** version

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least two other versions, without a default version set

**Preparations**:
1. Login as the admin user from the prerequisites

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **VERSIONS** tab | No version has the **default** label |
| 4 | Hover over the "check" button opposite the **latest** version | Tooltip `Set as default` appears |
| 5 | Look at the buttons opposite the other versions | There is a "check" button opposite every version |
| 6 | Click the **Run** button at the top of the tool page | |
| 7 | In an appeared pop-up window click **Launch** button | |
| 8 | At the **Runs** page, click the just-launched run | |
| 9 | Click the **Instance** item | ***Docker image*** field is shown with the test tool's docker image and the `latest` tag |

**After**:
- Stop the run launched at step 7
