# User receives notification when credit balance falls below the configured threshold

Test verifies that a user receives a notification when their Platform Usage Credits balance drops below the configured notification threshold.

**Prerequisites**:
- admin user
- non-admin user (user1) with a valid email address configured
- Platform Usage Credits feature enabled

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page, navigate to **Platform Usage Credits**
3. Set the notification threshold to `500` credits
4. Set user1's credit balance to `600` credits

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Manually deduct `200` credits from user1's balance (bringing it to `400`, below the threshold of `500`) | The credit adjustment is saved. user1's balance is now `400` |
| 3 | Open the **Events** section for user1 | A credit deduction event is recorded for user1 |
| 4 | Check user1's notifications (in-app notification panel or email) | user1 has received a notification indicating that their credit balance has dropped below the threshold (`500`), showing the current balance (`400`) |
| 5 | Verify the notification message contains relevant details | The notification includes the current balance, the threshold value, and a message advising the user to review their resource usage |

**After**:
- Restore user1's credit balance to the default value.
- Restore the notification threshold to its original value.
