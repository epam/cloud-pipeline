# Check PAUSE_OR_STOP action for a on-demand GPU run with no GPU activity

Test verifies that on-demand run is paused when action is `PAUSE_OR_STOP` for the GPU idle configuration in `system.idle.monitoring.config`.

**Prerequisites**:
- Admin user
- Test tool available in the registry that can run on a GPU instance type
- GPU instance available in the cloud region

**Preparations**:
1. Login as the admin user from the prerequisites
2. Save the `system.idle.monitoring.config` system preference value.
3. Set the system preference `system.idle.monitoring.config` to:

   ```
   [
      {
         "type": "CPU",
         "enabled": true,
         "thresholdPercent": 60,
         "gracePeriodMinutes": 5,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      },
      {
         "type": "GPU",
         "enabled": false,
         "gracePeriodMinutes": 5,
         "actionTimeoutMinutes": 10,
         "action": "PAUSE_OR_STOP"
      },
      {
         "type": "ABSOLUTE",
         "enabled": true,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      }
   ]
   ```

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Launch the tool on a GPU instance type and `On-demand` price type | |
| 4 | At the **Runs** page, click the just-launched run | |
| 5 | Wait until ***IDLE_GPU***, ***IDLE_CPU*** and ***IDLE*** tags appear in the **Instance** section | |
| 6 | Wait until action delay period (`actionTimeoutMinutes` for `GPU` from `system.idle.monitoring.config`) elapses | The pausing process is started for run. Run state is changed to `PAUSED` in a reasonable time. |
| 7 | Open the **Notifications** page | Notifications list opens that contains `Job #<run_ID> was PAUSED as it was Idle for a long time` notification, where `<run_ID>` is id of run launched at step 3| 

**After**:
- Stop the run launched at step 3
- Restore the original values of `system.idle.monitoring.config`.
