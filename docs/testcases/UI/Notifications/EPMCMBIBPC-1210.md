# Validation of expand notifications

Test verifies expanding and collapsing a notification's body row in the System events table.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1206](EPMCMBIBPC-1206.md) case |  |
| 2 | Click the system-settings button (gear icon in the left panel) |  |
| 3 | Click the **System events** tab |  |
| 4 | Click the **+** button opposite the notification added at step 1 | A new row with the notification body entered at step 4 of the [EPMCMBIBPC-1206](EPMCMBIBPC-1206.md) case appears |
| 5 | Click the **-** button opposite the notification added at step 1 | The row with the notification body disappears |
