# Forcible terminate instances if the job is stuck in umount

Test verifies that a run stuck in its cleanup is stopped after the period that its `CP_TERMINATE_RUN_ON_CLEANUP_TIMEOUT_MIN` parameter sets, and not before.

**Prerequisites**:
- Admin user
- Non-admin user
- Test tool
- The `launch.run.emergency.termination.action` preference is `STOP` (default: `DISABLED`, the platform then never stops a stuck run). The platform checks the runs every `system.resource.monitoring.period` milliseconds (default: `60000`)
- The `launch.run.emergency.termination.delay.min` preference, the period for a run without the parameter, is more than `1` (default: `30`)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool | |
| 4 | At the tool page, hover over the "**Run v**" button | |
| 5 | Click the "**Custom settings**" button in the list | |
| 6 | Expand the **Advanced** section | |
| 7 | Input `echo "#!/usr/bin/env bash" > /usr/local/sbin/umount && echo "sleep infinity" >> /usr/local/sbin/umount && chmod +x /usr/local/sbin/umount` command into the ***Cmd template*** field | |
| 8 | Launch tool | |
| 9 | At the **Runs** page, click the just-launched run | |
| 10 | Open run's ***Console*** task | |
| 11 | Wait until `Unmounting all storage mounts` appears in the log | The `umount` that the command replaced never ends: the run is stuck in its cleanup |
| 12 | Wait for 1 minute | Run isn't stopped automatically |
| 13 | Repeat steps 2-7 | |
| 14 | Click the **Add parameter** button. Input `CP_TERMINATE_RUN_ON_CLEANUP_TIMEOUT_MIN` into the name field of the added parameter, and `2` into its value field | |
| 15 | Repeat steps 8-11 | |
| 16 | Wait until the ***CleanupEnvironment*** task appears | |
| 17 | Click the ***CleanupEnvironment*** task | `Marking run as finished.` is shown in the log |
| 18 | Open the API method `/pipeline/restapi/run/<run ID>` of the run launched at step 15 in a new browser tab | The `tags` of the run have `WORK_FINISHED` |
| 19 | Wait for 3 minutes: the period specified at step 14, and one check of the platform | The run launched at step 15 has the **Stopped** status |

**After:**
- Stop the run launched at step 8
