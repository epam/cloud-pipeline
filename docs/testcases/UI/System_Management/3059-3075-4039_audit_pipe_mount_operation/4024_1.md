# Audit mount events

Test verifies that mount events are logged with the following format `MOUNT <mount bucket>`.

**Prerequisites**:
- Admin user
- Non-admin user
- perform [3059_1](3059_1.md) case

| Steps | Actions | Expected results |
| :---: |---|---|
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open the **Tools** page. Select the test tool | |
| 3 | At the tool page, hover over the **Run v** button | |
| 4 | Select the ***Custom settings*** option in the list | |
| 5 | Expand ***Exec environment*** section | |
| 6 | Expand ***Advanced*** section | |
| 7 | Click on the text field in the **Limit mounts** section | |
| 8 | In an appeared ***Select data storages to limit mounts*** pop-up click the **Clear selection** button. | |
| 9 | Input `storage1` name into the *Search* field. Select `storage1`. Click the **OK** button | |
| 10 | Launch run | |
| 11 | At the **Runs** page, click the just-launched run | |
| 12 | Wait until the ***MountDataStorages*** task is completed | |
| 13 | Logout and login as the admin user from the prerequisites | |
| 14 | Open the **Settings** page | |
| 15 | Open the **SYSTEM MANAGEMENT** tab. Select the **LOGS** tab | |
| 16 | Click ***Show advanced*** button | |
| 17 | Click **Type** field and select `audit` value from drop-down list | Record <br> `[run_id #<run_id>] MOUNT storage1` , where `<run_id>` is Id of run launched at step 10, is shown in the top of logs records |
| 18 | Login as the non-admin user from the prerequisites | |
| 19 | At the **Runs** page, click the run launched at step 10 | |
| 20 | Wait until the **SSH** hyperlink appears. Click the **SSH** hyperlink | |
| 21 | In the opened tab, enter and perform the `pipe storage mount -b storage1 mountdir` command | |
| 22 | Repeat steps 13-17 | Record <br> `[run_id #<run_id>] MOUNT storage1` , where `<run_id>` is Id of run launched at step 10, is shown in the top of logs records | 

**After:**
- Stop run launched at step 10 
- Delete storages created at step 2 in the Preparations of [3059_1](3059_1.md) case
