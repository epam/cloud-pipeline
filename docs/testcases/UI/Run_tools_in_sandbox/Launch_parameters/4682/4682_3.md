# "Show optional parameters" checkbox overrides for a single tool

Test verifies that, where the `tools` section of the launch form setting hides the **Show optional parameters** checkbox, an `optional-parameters-filter` override:
- by a tool id shows the checkbox for that tool only, with its own default value
- by a tool `registry/group/tool` name shows the checkbox for that tool only, unchecked

**Prerequisites**:
- Admin user
- Non-admin user `<user>` that is a member of the group `<user_group>`
- `<user>` and its roles have no `ui-launch-form` attribute
- 3 tools `<tool_1>`, `<tool_2>` and `<tool_3>` that `<user>` can run, each with a non-required parameter `<param>` in its settings
- `<tool_1_id>` is the id of `<tool_1>`
- `<registry>/<tool_group>/<tool_2>` is the full name of `<tool_2>`, without a version

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Miscellaneous** tab and find the `misc.groups.ui.preferences` preference
5. Save the current value of the preference
6. Set the preference value to:
```
{
  "<user_group>": {
    "ui-launch-form": {
      "tools": {
        "optional-parameters-filter": {
          "enabled": false,
          "overrides": {
            "<tool_1_id>": {"default_value": true, "enabled": true},
            "<registry>/<tool_group>/<tool_2>": true
          }
        }
      }
    }
  }
}
```
7. Click **Save** button
8. Logout

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin user `<user>` from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the tool `<tool_1>` from the prerequisites | |
| 4 | Hover over the **v** button near the **Run** button, click **Custom settings** | <li> The launch form opens <li> The **Parameters** section header has the **Show optional parameters** checkbox, and it is checked <li> The parameter `<param>` is shown |
| 5 | Open the **Tools** page, select the tool `<tool_2>` from the prerequisites | |
| 6 | Hover over the **v** button near the **Run** button, click **Custom settings** | <li> The **Show optional parameters** checkbox is shown and unchecked <li> The parameter `<param>` is hidden |
| 7 | Open the **Tools** page, select the tool `<tool_3>` from the prerequisites | |
| 8 | Hover over the **v** button near the **Run** button, click **Custom settings** | <li> The **Parameters** section header has no **Show optional parameters** checkbox <li> The parameter `<param>` is shown |

**After**:
- Restore the saved value of the `misc.groups.ui.preferences` preference
