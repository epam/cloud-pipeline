# ROLE_STORAGE_ADMIN: storage creation

Test verifies that User with `ROLE_STORAGE_ADMIN` shall be able create storages in folders with granted WRITE access

**Prerequisites**:
- Admin user
- Non-admin user
- Perform [3389_1](3389_1.md) case

**Preparations**
1. Login as admin user from the prerequisites
2. Create the folder `folder1`. Give `READ` permission to `folder1` to the non-admin user from the prerequisites
3. Create the folder `folder2`. Give `WRITE` permission to `folder2` to the non-admin user from the prerequisites

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as non-admin user from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Open the `folder1` | **+ Create** button isn't visible | 
| 4 | Open the **Library** page | |
| 5 | Open the `folder2` | **+ Create** button is visible |
| 6 | Click **+ Create** button | Drop-down menu contains *Storages* item  |
| 7 | Select *Storages* item >> "Create new object storage" | |
| 8 | In pop-up window input valid value (`storage2`) into the field *Storage path* | |
| 9 | Click **Create** button | Created Storage is shown in the `folder2` entities list |
