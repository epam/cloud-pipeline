# The default version in the version pickers

Test verifies that the version pickers of the launch form and of the versioned storage launch select the default version of a tool and mark it as **default**.

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least two other versions
- `<version>` is one of the test tool versions, which is not the **latest** one
- Test versioned storage

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the arrow near the **Run** button at the top of the page and select **Custom settings** | The launch form opens |
| 4 | Click the **Docker image** field in the **Exec environment** section | **Select docker image** pop-up opens |
| 5 | Click any other tool of the group, then click the test tool | The version picker opposite the test tool shows `<version> (default)` |
| 6 | Open the version picker | The `<version> (default)` item is shown, other versions are shown without the label |
| 7 | Click **Cancel** | |
| 8 | Open the **Library** page and select the test versioned storage | |
| 9 | Click the **Run** button | The versioned storage launch pop-up opens |
| 10 | Click the test tool | The version picker shows `<version> (default)` |

**After**:
- Remove the default version of the test tool, as described in [4664_3](4664_3.md) (steps 1-4)
