# A default version removed outside the platform

Test verifies that, when the default version is removed from the Docker registry outside of Cloud Pipeline,
- the **VERSIONS** tab warns that the default version does not exist, and no version has the **default** label
- `pipe run` of the tool image without a tag stops, since the missing default version is checked
- a user without the **WRITE** permission for the tool, and a "symlink" of the tool, show the warning without the **Unset** button
- the **Unset** button of the warning unsets the missing default version

**Prerequisites**:
- Admin user
- Test tool with the **latest** version
- `<version>` is a version of the test tool, pushed for this test from an image of its own, which no other version of the test tool is pushed from (e.g. committed from a run of the test tool, as in [4664_4](4664_4.md) (preparation 2)): the registry deletes every version of an image together
- `<version>` can be deleted directly in the Docker registry (e.g. with the registry API: `DELETE /v2/<group>/<tool>/manifests/<digest>`)
- `pipe` CLI is installed and configured for the admin user
- Non-admin user, who has the **READ** and **EXECUTE** permissions for the test tool, but not the **WRITE** one
- A "symlink" of the test tool in another tool group (see [10.8. Symlinks between tools](../../../../md/manual/10_Manage_Tools/10.8._Symlinks_between_tools.md))

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Delete the `<version>` version directly in the Docker registry, outside of Cloud Pipeline | |
| 2 | Open the **Tools** page, select the test tool from the prerequisites, click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | <li> The `<version>` version isn't shown <li> No version has the **default** label <li> The `The default version <version> does not exist.` warning with the **Unset** button is shown above the list of versions |
| 3 | Run `pipe run -di <registry>/<group>/<tool> -it <instance type> -id 30 -cmd "sleep infinity" -y`, where `<registry>/<group>/<tool>` is the test tool image without a tag | `pipe` prints `Docker image <registry>/<group>/<tool> has no tag "<version>"` with the list of the available tags, and exits without launching a run |
| 4 | Open the "symlink" of the test tool and click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | The `The default version <version> does not exist.` warning is shown without the **Unset** button |
| 5 | Logout and login as the non-admin user from the prerequisites | |
| 6 | Open the **Tools** page, select the test tool, click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | The `The default version <version> does not exist.` warning is shown without the **Unset** button |
| 7 | Logout and login as the admin user. Open the test tool and click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | The `The default version <version> does not exist.` warning is shown with the **Unset** button |
| 8 | Click the **Unset** button of the warning. In the `Are you sure you want to unset version '<version>' as default?` confirmation, click **Yes** | <li> The warning disappears <li> No version has the **default** label |
