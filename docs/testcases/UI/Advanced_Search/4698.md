# Scrolling of search results with files with long paths

Test verifies that scrolling through the Advanced Search results shows each file with a path longer than 512 bytes exactly once, both down and back up the list.

**Prerequisites**:
- admin user
- `pipe` CLI configured for the admin user

**Preparations**:

1. Login as admin user from the prerequisites.
2. Open the **Library** page and create a new object storage `storage2` (AWS S3, GCS or Azure Blob).
3. Prepare a local folder `advanced_search_files` with 300 files `advanced_search_file_001.txt` ... `advanced_search_file_300.txt`.
4. Upload the folder content into `storage2`, under three nested folders `<long_folder>`, where `<long_folder>` is a folder name of 200 `a` characters:
   `pipe storage cp advanced_search_files s3://storage2/<long_folder>/<long_folder>/<long_folder>/ -r`
   (use `gs://` or `az://` for the other providers). The full path of each file is longer than 512 bytes.
5. Wait for the next indexing cycle of the storage files.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on **Search** icon at the left menu bar | Advanced Search page opens |
| 2 | Enter `advanced_search_file` into the search field, click **Search** button | The search results list contains files `advanced_search_file_*.txt` |
| 3 | Click the button with the filter icon near the **Search** button | The drop-down list contains the **Data** item with the count `(300)` |
| 4 | Close the drop-down list. In the **Sort by** panel, click the close icon on the **Name** button | <li>The **Name** sorting is removed <li>The first item of the search results list is `advanced_search_file_300.txt` |
| 5 | Scroll the search results list down to its end, until no more results are loaded | <li>The file numbers in the list only go down while scrolling <li>The last item of the list is `advanced_search_file_001.txt` <li>No file is shown in the list twice |
| 6 | Scroll the search results list back up to its top | <li>The first item of the list is `advanced_search_file_300.txt` <li>No file is shown in the list twice |

**After**:
- Delete `storage2`
