Test verifies that user with role `ROLE_PIPELINE_ADMIN` can fully manage existing pipeline.

**Prerequisites**:
- admin user
- non-admin user with `ROLE_PIPELINE_ADMIN` role
- perform [4146_1_1](4146_1_1.md) case

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin user from the prerequisites | |
| 2 | Open **Library** page | 
| 3 | Open `pipeline1` |  |
| 4 | Open **Attributes** panel | |
| 5 | Click **+Add** button. | |
| 6 | Click into the **Key** field and input `Key1` value | |
| 7 | Click into the **Value** field and input `Value1` value. | |
| 8 | Click **Add** button. | Record appears that contains: <li> in the first row, the value inputted at step 6, with the *Delete* icon near the value <li> in the second row, the value inputted at step 7|
