# Admin can create a credit reward rule for spot instance usage

Test verifies that an admin can create a Platform Usage Credits rule that adds credits to a user's balance when a run is launched on a spot instance.

**Prerequisites**:
- admin user
- Platform Usage Credits feature enabled

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Settings** page. Navigate to the **Platform Usage Credits** section | The **Platform Usage Credits** section is displayed with a list of configured rules |
| 3 | Click **Add rule** | A rule creation form opens |
| 4 | Set the rule name to `Spot Usage Reward` | |
| 5 | Set the rule type to **Reward** | |
| 6 | Set the credit amount to `200` | |
| 7 | Set the condition to **Run uses spot instance** | |
| 8 | Click **Save** | The new rule `Spot Usage Reward` appears in the rules list with type **Reward**, amount `200`, and the spot instance condition |
| 9 | Refresh the page and reopen the **Platform Usage Credits** section | The `Spot Usage Reward` rule is still present with all configured values preserved |

**After**:
- Delete the rule created during this test if it is not needed for further tests.
