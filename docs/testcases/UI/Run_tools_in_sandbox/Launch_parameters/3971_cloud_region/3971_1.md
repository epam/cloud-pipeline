# Mount rules: Mount All Storages independently instance cloud region

Test verifies that storages from all regions are mounted to the instances independently of storages and instance regions if option `All` is selected for *Object storages* and *File storages* in the Cloud region *Mount rules*.

**Prerequisites**:
- admin user

**Preparations**
1. Login as admin user from the prerequisites
2. Create object storage `storage1` in Cloud region `region1`
3. Create object storage `storage2` in Cloud region `region2`
4. Create FS data storage `nfs_storage1` in Cloud region `region1`

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Open the **Settings** page | |
| 2 | Click the **CLOUD REGIONS** tab | |
| 3 | Select `region1` on the left panel | |
| 4 | In the **Mount rules:** section select <li> option `All` for ***Object storages*** <li> option `All` for ***File storages*** |  |
| 5 | Click **Save** button | |
| 6 | Open the **Tools** page. Select the test tool | |
| 7 | At the tool page, hover over the **Run v** button | |
| 8 | Select the ***Custom settings*** option in the list | |
| 9 | Expand ***Exec environment*** section |  |
| 10 | Select `region1` for **Cloud Region** | |
| 11 | Expand ***Advanced*** section |  |
| 12 | Click on the text field in the **Limit mounts** section | |
| 13 | In an appeared ***Select data storages to limit mounts*** pop-up click the **Clear selection** button. Select `storage1`, `nfs_storage1`. Click **OK** button | |
| 14 | Launch tool | |
| 15 | Open the just launched pipeline | |
| 16 | Wait until *MountDataStorages* task appears | |
| 17 | Click on *MountDataStorages* task at the left panel | *MountDataStorages* task log is displaying that contains the following text: <li> `Only 2 storages will be mounted` <li> `Found 2 available storage(s). Checking mount options.` <li> 2 records: `-->{storage_name} mounted to /cloud-data/{storage_name}`, <br> where `{storage_name}` is `storage1`, `nfs_storage1` name |
| 18 | Repeat steps 6-17 with `region2` selected for **Cloud Region** at step 10 | The same result |

**After:**
- Stop the run launched at step 14
