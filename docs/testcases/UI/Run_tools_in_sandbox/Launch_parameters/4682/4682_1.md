# "Show optional parameters" checkbox is checked by default on the pipeline launch form

Test verifies that:
- the `default_value` of the `optional-parameters-filter` launch form setting checks the **Show optional parameters** checkbox when the pipeline launch form opens
- the user can uncheck it
- the **Show optional parameters** checkbox isn't shown for user that not member of group from preference 

**Prerequisites**:
- Admin user
- Non-admin user `<user1>` that is a member of the group `<user_group>`
- Non-admin user `<user2>` that isn't a member of the group `<user_group>`
- `<user1>`, `<user2>` and their roles have no `ui-launch-form` attribute 
- Pipeline `<pipeline>` with a non-required parameter `<param>` that `<user1>` and `<user2>` can run 

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Miscellaneous** tab and find the `misc.groups.ui.preferences` preference
5. Save the current value of the preference
6. Set the preference value to:
```
{
  "<user_group>": {
  "ui-launch-form": {
  "pipelines": {"optional-parameters-filter": {"default_value": true}}
  }
 }
}
```
7. Click **Save** button
8. Logout

| Steps | Actions | Expected results |
|:---:|---|---|
| 1 | Login as the non-admin user `<user1>` from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Open the pipeline `<pipeline>` from the prerequisites | |
| 4 | Click **Run** button | <li> The launch form opens <li> The **Parameters** section header has the **Show optional parameters** checkbox, and it is checked <li> The parameter `<param>` is shown |
| 5 | Uncheck the **Show optional parameters** checkbox | The parameter `<param>` is hidden |
| 6 | Logout and login as the non-admin user `<user2>` from the prerequisites | |
| 7 | Repeat steps 2-4 | <li> The launch form opens <li> The **Parameters** section header doesn't have the **Show optional parameters** checkbox <li> The parameter `<param>` is shown |

**After**:
- Restore the saved value of the `misc.groups.ui.preferences` preference
