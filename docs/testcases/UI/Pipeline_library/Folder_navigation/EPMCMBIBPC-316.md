# Delete folder that have subitem

Test verifies deleting a folder that contains a subfolder, using the **Delete sub-items** option.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Hover over **+ Create v** button, click **Folder** in the appeared list |  |
| 3 | Input a valid folder name in the appeared window, click **OK** button |  |
| 4 | Click on the created folder |  |
| 5 | Repeat steps 2-3 |  |
| 6 | Click the `..` button |  |
| 7 | Click the delete icon opposite the folder name created at step 3 | A pop-up window appears containing the **Delete sub-items** checkbox and **Cancel**, **OK** buttons |
| 8 | Set the **Delete sub-items** checkbox in the appeared pop-up window |  |
| 9 | Click **OK** button | The folder created at step 3 doesn't display |
| 10 | Input into the **Search** field on the left panel the name of the folder created at step 3 | Search results are empty |
