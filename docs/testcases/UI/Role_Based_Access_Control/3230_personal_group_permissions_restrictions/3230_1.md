# Personal tool groups/tools: permission restrictions for group

Test verifies that restrictions on permissions for personal tool groups for roles can be specified using preference.

**Prerequisites**:
- admin user
- non-admin user (`user1`)
- test user group (`test_group`)

**Preparations**:
1. Login as the non-admin user `user1` from the prerequisites.
2. Create *Personal tool group* if needed
3. Add tool to the *Personal tool group*

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Click the **PREFERENCES** tab | |
| 3 | Click the **User Interface** tab and find the `ui.personal.tools.permissions.restrictions` preference | |
| 4 | Add to the `ui.personal.tools.permissions.restrictions` preference json <br> `{` <br> `"role": "<test_group>",` <br> `"disable": "WRITE,EXECUTE"` <br> `}`, <br> where `<test_group>` - test user group from the prerequisites | |
| 5 | Set *eye-icon* near the preference if they are disabled | |
| 6 | Click **Save** button. | | 
| 7 | Logout and login as the non-admin `user1` from the prerequisites | |
| 8 | Open the  the **Tools** page. | |
| 9 | Select *Personal* group from list of *All groups* |  |
| 10 | Click ***Settings*** button (gear-icon). In an appeared list select *Group* -> *Edit* | |
| 11 | Click the *Permissions* tab | |
| 12 | Click the **Add group** button. Input the test user group name from the prerequisites. Click the **OK** button | |
| 13 | Click the appeared group at the *Groups and users* section | In the Permissions tab <li> *WRITE, EXECUTE* checkboxes are ticked as **DENY** and disabled. <li> *READ* permission empty in the both columns and active|
| 14 | Close *Edit group* popup | |
| 15 | Open test Tool added at step 3 from the preparations | |
| 16 | Hover over gear-icon. In an appeared list select *Permissions* option | |
| 17 | Repeat steps 12-14 | |
