# Validation of add second configuration

Test verifies adding a second sub-configuration to a detach configuration.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1114](EPMCMBIBPC-1114.md) case |  |
| 2 | Open the detach configuration from step 1 |  |
| 3 | Click on **+ ADD** button |  |
| 4 | Specify a valid configuration name |  |
| 5 | Click **CREATE** button | <li> the tab with the just-created configuration is active <li> the field values are the same as in the configuration created at the [EPMCMBIBPC-1114](EPMCMBIBPC-1114.md) case <li> **Remove**, **Set as default** buttons are displayed |
