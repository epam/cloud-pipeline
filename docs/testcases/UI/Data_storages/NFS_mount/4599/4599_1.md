# Exclude NFS storage from file indexing by metadata attribute

Test verifies that:
- Files of an NFS storage can be excluded from the search indexing by adding the `Billing status` = `Exclude` attribute to the storage
- Files indexed before the attribute was added remain searchable
- The storage itself stays searchable by its name even when its files are excluded

**Prerequisites**:
- admin user
- NFS storage `nfs_storage1` registered on the platform

**Preparations**:

1. Login as admin user from the prerequisites.
2. Open **Library** page.
3. Open `nfs_storage1`.
4. Upload file `file1` into `nfs_storage1`.
5. Wait for the next NFS indexing cycle.
6. Click on **Search** icon at the left menu bar and make sure `file1` is found among the search results.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open `nfs_storage1` and click **Show attributes** button in the right upper corner | |
| 2 | Click **+ Add** button | |
| 3 | Select `Billing status` in the **_Key_** field and `Exclude` in the **_Value_** field | |
| 4 | Click **Add** button | The attribute is added to `nfs_storage1` |
| 5 | Upload a new file `file2` into `nfs_storage1` | |
| 6 | Wait for the next NFS indexing cycle | |
| 7 | Click on **Search** icon at the left menu bar and search for `file2` | `file2` isn't found among the search results |
| 8 | Search for `file1` | `file1` uploaded at the Preparations is still found among the search results |
| 9 | Search for `nfs_storage1` | `nfs_storage1` is found among the search results - the storage itself stays searchable even though its files are excluded |
