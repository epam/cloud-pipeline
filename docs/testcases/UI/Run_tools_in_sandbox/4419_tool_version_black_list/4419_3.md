# Pipeline with blacklisted tool version can't be launched by a regular user

Test verifies that a pipeline with blacklisted tool version can't be launched by a regular user.

**Prerequisites**:
- Admin user
- Non-admin user (`user1`) 
- Perform [4419_1](4419_1.md) case

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create pipeline (`test_pipeline1`). 
3. Select test tool `latest` version from case [4419_1](4419_1.md) prerequisites as `test_pipeline1` docker image. 
4. Give all permissions to `test_pipeline1` to `user1`.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Open the pipeline created at step 2 of the preparations | |
| 4 | Click the **RUN** button | |
| 5 | Launch the run. Click **Launch** button on the *Launch* pop up. | Error message `Tool execution is not allowed by a Security Policy 'Tool version is blacklisted and cannot be executed.'` appears |
