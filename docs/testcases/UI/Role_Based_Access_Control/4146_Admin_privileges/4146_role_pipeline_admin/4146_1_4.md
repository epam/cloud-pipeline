# ROLE_PIPELINE_ADMIN: managing runs of existing pipeline

Test verifies that user with role `ROLE_PIPELINE_ADMIN` can see runs connected with pipelines.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_PIPELINE_ADMIN` role
- perform [4146_1_1](4146_1_1.md) case

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select test tool. Launch a selected tool with custom settings (`run1`) | |
| 4 | Open **Library** page | 
| 5 | Open `pipeline1`. Launch pipeline (`run2`). Set `On-demand` price type if needed |  |
| 6 | Logout and login as the non-admin `user1` from the prerequisites | |
| 7 | Open  the **Runs** page. Click *View other available active runs* link if needed | <li> `run1` isn't shown in the list of active runs <li> `run2` is shown in the list of active runs |
| 8 | Click the `run2` | Log run page opens: <li> *PAUSE*, *STOP*, *SSH*, *BROWSE* buttons aren't shown <li> *Share with:* link isn't shown |
| 9 | Open the "**Cluster state**" page | Nodes list <li> contains the row for the `run2` <li> doesn't contain the row for the `run1` |

**After:**
- Stop the runs launched at steps 3, 5
