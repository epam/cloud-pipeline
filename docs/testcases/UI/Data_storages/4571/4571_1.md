# Picking an archive together with other files pauses the upload behind a confirmation pop-up

Test verifies that picking a batch of files that includes at least one archive, on a storage where this mode is offered, opens an **Upload files** pop-up before anything is uploaded.

**Prerequisites**:
- A non-admin user with **READ** and **WRITE** permissions on an S3 object storage (or an NFS storage whose share is mounted as NFS)

**Preparations**:
1. Login as the user from the Prerequisites
2. Open the storage from the Prerequisites
3. On the local machine, have ready: two ordinary files (e.g. `file1.txt`, `file2.txt`) and one archive file (e.g. `archive1.zip`)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click the **Upload** button |  |
| 2 | In the OS file dialog, select two ordinary files from Preparations together and confirm | The **Upload files** pop-up opens. Files are uploaded immediately |
| 3 | Wait until the ordinary **Uploading files...** progress pop-up closes | |
| 4 | Click the **Upload** button |  |
| 5 | In the OS file dialog, select all three files from Preparations together and confirm | The Upload files pop-up opens: <li> No files have been uploaded yet <li> There is one row per selected file: `file1.txt`, `file2.txt`, `archive1.zip`, each showing the file's name only <li> Each row carries a cross on its right, which drops that file from the list <li> Three buttons are shown at the bottom: **Cancel**, **Upload and extract**, **Upload** |
| 6 | Click **Cancel** | The pop-up closes. None of the three files were uploaded |

**After:**
- Delete `file1.txt` and `file2.txt` from the storage
