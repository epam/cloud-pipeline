# Check attributes for pipeline in folder

Test verifies that a pipeline's own attributes are not shown when navigating to its containing folder.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-866](EPMCMBIBPC-866.md) case |  |
| 2 | Navigate to the folder created at step 5 of the EPMCMBIBPC-866 case |  |
| 3 | Click the button for customizing the display of additional panels (in the upper-right corner) |  |
| 4 | Click **Attributes** in the list that appears | The pipeline attributes are not displayed |
