# Wetty

## Requirements

- [Node.js](https://nodejs.org/) **v20**
- npm (comes with Node.js)

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

## Running application

```bash
npm run build # builds UI (dist directory)
node app.cjs --port XXXX # starts server
```

## Development

```bash
npm run dev-server # starts local server
npm run dev # starts UI (dev mode)
```
