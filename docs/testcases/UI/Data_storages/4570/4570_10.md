# Generate URL creates URLs only for the files that can be downloaded

Test verifies that:
- **Generate URL** is offered for a selection of files and folders
- an info icon next to it says how many items get a URL
- the pop-up lists URLs only for the selected files

**Prerequisites**:
- Admin user

**Preparations**:
1. Login as the admin user from the prerequisites
2. Create an object storage `storage1`
3. Open `storage1` and create a folder `folder1` and two files `testfile1.txt` and `testfile2.txt` in the root of `storage1`

| Steps | Actions | Expected results |
| :---: |---| --- |
| 1 | Open `storage1` from the library-tree | `folder1`, `testfile1.txt` and `testfile2.txt` are listed, each with a checkbox |
| 2 | Check the checkboxes next to `testfile1.txt` and `testfile2.txt`, then click the **2 items selected** button | The dropdown contains a **Generate URL** item with no info icon next to it |
| 3 | Close the dropdown. Check the checkbox next to the `folder1` name | The **3 items selected** button appears |
| 4 | Click the **3 items selected** button | The dropdown contains a **Generate URL** item with an info icon next to it |
| 5 | Hover over the info icon | A tooltip appears: `URLs are generated only for downloadable files (2 of 3).` |
| 6 | Click the **Generate URL** item | The `Download file url` pop-up opens. Its text area has two links: one for `testfile1.txt` and one for `testfile2.txt` |
| 7 | Click the **OK** button | The pop-up closes |

**After**: delete `storage1`
