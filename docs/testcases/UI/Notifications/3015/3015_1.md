# [Manual] Push notification appears in the top-right corner when a system event fires

Test verifies that when a system event triggers an email notification, the corresponding push notification is displayed in the top-right corner of the Cloud Pipeline GUI for the recipient user, and an unread counter appears near the Notifications icon in the main menu.

**Prerequisites**:
- Admin user
- Non-admin user (user1) configured as a recipient for at least one enabled email notification template (e.g. `LONG_RUNNING` or `IDLE_RUN`)
- Test tool available in the registry

| Steps | Actions | Expected results |
|:---:|------|---|
| 1 | Login as user1 from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Launch the tool with default settings | |
| 5 | Keep the Cloud Pipeline GUI open in the browser and wait until the configured notification event is triggered (e.g. the run reaches the idle/long-running threshold) | A push notification tile appears in the **top-right corner** of the GUI over the current page |
| 6 | Inspect the push notification tile | The tile displays the notification subject and a brief body matching the corresponding email notification |
| 7 | Inspect the **Notifications** icon in the main menu | A numeric counter of unread messages appears next to the **Notifications** icon |

**After**:
- Stop the run launched at step 4.
