# ROLE_USER_ADMIN: impersonate admin user

Test verifies that user with role `ROLE_USER_ADMIN` can't impersonate admin user.

**Prerequisites**:
- non-admin user (`user1`) with `ROLE_USER_ADMIN` role.
- admin user

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open the **Settings** page | |
| 3 | Click the **USER MANAGEMENT** tab |  |
| 4 | Click the **Users** tab |  |
| 5 | Find the admin user from the prerequisites. Click *Edit* icon opposite the  admin user  name. |  |
| 6 | In an appeared pop-up click on the **Impersonate** button | <li> Error message `Access denied` appears <li> User edit pop-up remains open |
