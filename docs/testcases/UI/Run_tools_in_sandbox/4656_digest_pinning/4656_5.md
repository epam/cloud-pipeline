# A run launched before the digest pinning is enabled keeps working with the tag

Test verifies that a run launched while the `launch.docker.image.pin.digest` system preference is disabled, after the preference is enabled
- still has no ***Docker image digest***
- can be committed, paused and resumed, and keeps its changes after the resume

**Prerequisites**:
- Admin user
- Test tool available in the registry

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Launch** tab
5. Find the `launch.docker.image.pin.digest` preference
6. Save the preference value, then uncheck *Enabled* checkbox for `launch.docker.image.pin.digest` preference if needed
7. Click **Save** button if needed
