# Authentication in platform

Test verifies logging in to the platform and opening the Library page.

**Prerequisites**:
- A valid user registered in the platform

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the internet browser (Chrome/Firefox/Edge/Internet Explorer 11) |  |
| 2 | In a new tab, specify the platform address, press **Enter** |  |
| 3 | Log in to the platform as the user from the prerequisites | The main Dashboard appears |
| 4 | Click the **Library** item in the main menu on the left side of the page to open the library of objects | The **Library** page opens |
