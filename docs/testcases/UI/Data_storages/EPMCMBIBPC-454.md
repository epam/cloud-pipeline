# Create subfolder in bucket

Test verifies creating a subfolder inside a folder.

**Prerequisites**:
- The storage created in [EPMCMBIBPC-448](EPMCMBIBPC-448.md) is selected

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Hover the mouse pointer over the **+ Create v** button, select **Folder** item |  |
| 2 | Input a valid value into the **Name** field in the pop-up window |  |
| 3 | Click **OK** button |  |
| 4 | Select the created folder |  |
| 5 | Hover the mouse pointer over the **+ Create v** button, select **Folder** item |  |
| 6 | Input a valid value for the subfolder name in the pop-up window |  |
| 7 | Click **OK** button | The folder with the name from step 2 contains a subfolder with the name from step 6 |
