# File upload validation

Test verifies uploading a single file to the root of the storage.

**Prerequisites**:
- The storage created in [EPMCMBIBPC-448](EPMCMBIBPC-448.md) is selected

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click **Upload** button |  |
| 2 | Select a file and confirm the upload in the pop-up window | <li> a pop-up window `Uploading files...` with a progress bar and the uploading file's name appears <li> the file selected at step 2 appears in the root directory of the storage |
