# Configuration create pop-up focus validation

Test verifies that the create-configuration pop-up opens with focus on the name field and that pressing Enter creates the configuration.

**Prerequisites**:
- At least one library folder

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the folder |  |
| 2 | Hover over the **+ Create** button located above the file and folder list |  |
| 3 | Click on **Configuration** | The **Create configuration** pop-up appears with focus on the **Configuration name** field (cursor is already there, field edges are highlighted blue) |
| 4 | Start entering a configuration name |  |
| 5 | Press **Enter** key when finished | A new configuration with the corresponding name appears in the directory |
