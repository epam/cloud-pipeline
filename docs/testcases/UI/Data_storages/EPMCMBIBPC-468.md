# File editing

Test verifies renaming a file.

**Prerequisites**:
- A storage with a file exists

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Click on the storage in the library-tree |  |
| 3 | Click on the edit icon opposite the file name |  |
| 4 | Specify a new name for the file in the appeared pop-up window |  |
| 5 | Click **OK** button | The file's name is changed to the one specified at step 4 |
