# Validation of select one of several pipeline configurations

Test verifies that a detached configuration correctly reflects the specific pipeline configuration selected for it.

**Prerequisites**:
- The existing pipeline with several configurations

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-1091](EPMCMBIBPC-1091.md) case |  |
| 2 | Click on the created configuration |  |
| 3 | Click on the field opposite the **Pipeline** label |  |
| 4 | Select the pipeline from the prerequisites in the appeared pop-up window |  |
| 5 | Click on the pipeline version |  |
| 6 | Click on the dropdown list opposite the pipeline version name |  |
| 7 | In the appeared list select a configuration |  |
| 8 | Click **OK** button |  |
| 9 | Click **Yes** in the appeared pop-up window | The same parameters as in the selected pipeline configuration are displayed in the detach configuration opened at step 2 |
