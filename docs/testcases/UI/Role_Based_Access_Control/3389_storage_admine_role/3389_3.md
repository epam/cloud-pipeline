# ROLE_STORAGE_ADMIN: operations with storage tags

Test verifies that User with role STORAGE_ADMIN shall be able view/edit/delete storage and file tags

**Prerequisites**:
- Admin user
- Non-admin user
- Perform [3389_1](3389_1.md) case

**Preparations**
1. Login as admin user from the prerequisites
2. Create the object storage `storage3`.
6. Open `storage3` and
    - in the _Attributes_ section add 2 attributes `key1/value1`, `key2/value2`
    - create file `testfile.txt`.
    - in the `testfile.txt` file _Attributes_ section add 2 attributes `key1/value1`, `key2/value2`

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as non-admin user from the prerequisites | |
| 2 | Open the **Library** page | |
| 3 | Open `storage3` | |
| 4 | Click ***Show attributes*** button | Attributes `key1` and `key2` are visible and editable |
| 5 | In the **Attributes** section click ***Remove*** button for `key2` attribute. Confirm deletion |  |
| 6 | Change `key1` and `value1` values for attribute `key1` to `key1_new`/`value1_new` | |
| 7 | Add attribute `key3` with `value3` | Attributes `key1_new`/`value1_new` and `key3/value3` are shown in the **Attributes** section |
| 8 | Click on the `testfile.txt` file | |
| 9 | Repeat steps 5-7 for `testfile.txt` file attributes | |
