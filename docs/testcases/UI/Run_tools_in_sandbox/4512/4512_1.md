# IDLE_CPU and IDLE tags are shown for non-GPU run when CPU utilization is below than threshold

Test verifies that a run with CPU utilization below than configured CPU idle threshold is tagged with ***IDLE_CPU*** and ***IDLE*** and the tags display a timestamp tooltips on the **Runs** page, **Rrun log** page, and **Dashboard** page.

**Prerequisites**:
- Admin user
- Test tool available in the registry

**Preparations**:
1. Login as the admin user from the prerequisites
2. Save the `system.idle.monitoring.config` system preference value.
3. Set `system.idle.monitoring.config` system preference value to:

```
[
 {
 "type": "CPU",
  "enabled": true,
  "thresholdPercent": 60,
  "gracePeriodMinutes": 3,
  "actionTimeoutMinutes": 6,
 `"action": "NOTIFY"
 },
 {
 "type": "GPU",
  "enabled": true,
  "gracePeriodMinutes": 4,
  "actionTimeoutMinutes": 10,
  "action": "NOTIFY"
 },
 {
  "type": "ABSOLUTE",
  "enabled": true,
  "actionTimeoutMinutes": 15,
  "action": "NOTIFY"
 }
]
```
4. Check that `system.run.tag.date.suffix` preference has value `_date`

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Launch the tool with non-GPU instance | |
| 4 | At the **Runs** page, click the just-launched run | |
| 5 | Wait until the **SSH** hyperlink appears and the idle detection period (`gracePeriodMinutes` for `CPU` from `system.idle.monitoring.config`) elapses | ***IDLE_CPU*** and ***IDLE*** tags are shown in the **Instance** section |
| 6 | Hover over the ***IDLE_CPU*** tag on the run log page | Tooltip appears that contains a timestamp with corresponding value |
| 7 | Hover over the ***IDLE*** tag on the run log page | Tooltip appears that contains a timestamp with corresponding value |
| 8 | Click on the ***IDLE_CPU*** tag | The **Monitor** of the node resource utilization opens |
| 9 | Click RunID tag | Run log page opens |
| 10 | Click on the ***IDLE*** tag | The **Monitor** of the node resource utilization opens |
| 11 | Open the **Runs** page | |
| 12 |  ***IDLE_CPU*** and ***IDLE*** tags are shown near the just-launched run name |
| 13 | Hover over the ***IDLE_CPU*** tag | Tooltip appears that contains a timestamp with value about 1 minute |
| 14 | Hover over the ***IDLE*** tag | Tooltip appears that contains a timestamp with value about 1 minute |
| 15 | Open the **Dashboard** page | In the **Active runs** section ***IDLE_CPU*** and ***IDLE*** tags are shown for the run launched at step 3 |
| 16 | Hover over the ***IDLE_CPU*** tag on the Dashboard | Tooltip appears that contains a timestamp with corresponding value |
| 17 | Hover over the ***IDLE*** tag on the Dashboard | Tooltip appears that contains a timestamp with corresponding value |

**After**:
- Stop the run launched at step 3
- Restore the original values of `system.idle.monitoring.config`.
