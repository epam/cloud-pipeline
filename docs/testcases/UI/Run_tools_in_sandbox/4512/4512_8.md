# Run is NOT marked IDLE when CPU config is disabled

Test verifies that when the CPU idle configuration is disabled in `system.idle.monitoring.config`, a run with low CPU usage is not tagged with **IDLE_CPU** or the aggregate **IDLE** tag.

**Prerequisites**:
- Admin user
- Test tool available in the registry

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the system preference `system.idle.monitoring.config` to:
   ```
   [
      {
         "type": "CPU",
         "enabled": false,
         "thresholdPercent": 60,
         "gracePeriodMinutes": 5,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      },
      {
         "type": "GPU",
         "enabled": true,
         "gracePeriodMinutes": 4,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      },
      {
         "type": "ABSOLUTE",
         "enabled": true,
         "actionTimeoutMinutes": 10,
         "action": "NOTIFY"
      }
   ]
   ```

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Launch the tool on a non-GPU instance type with default settings | |
| 4 | At the **Runs** page, click the just-launched run | |
| 5 | Wait until the **SSH** hyperlink appears and the idle detection periods (`gracePeriodMinutes` for `CPU` and `actionTimeoutMinutes` for `ABSOLUTE` from `system.idle.monitoring.config`) elapse | ***IDLE_CPU*** and ***IDLE*** tags aren't shown in the **Instance** section |
| 6 | Open the **Runs** page | ***IDLE_CPU*** and ***IDLE*** tags aren't shown ***IDLE_GPU*** tag is shown near the name of run launched at step 3|
| 7 | Open the **Dashboard** page | In the **Active runs** section neither ***IDLE_CPU*** nor ***IDLE*** tags are shown for the run |

**After**:
- Stop the run launched at step 3
- Restore the original values of `system.idle.monitoring.config`.
