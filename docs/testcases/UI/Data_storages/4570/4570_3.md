# Queue, track and download an archive

Test verifies that:
- queueing an archive shows a notification naming the **Show downloads** menu item, and the task appears in the **Downloads** window right away, in a pending/active state
- the **Downloads** window is opened from the presentation dropdown's **Show downloads** item, and shows the archive name, its item count (with the archived paths on hover), the storage, size, status and created/finished dates
- once a task finishes while the **Downloads** window is closed, a notification appears saying the archive is ready, with a **Download it** link, and it stays on screen until clicked
- a task that finishes while the **Downloads** window stays open shows its outcome on its own row instead, with no separate notification
- clicking **Download** on a finished task's own row in the **Downloads** window fetches the archive

**Prerequisites**:
- An AWS S3 object storage with at least 4 files exists

| Steps | Actions | Expected results |
|:---:|---|---|
| 1 | Open library | |
| 2 | Click on the storage in the library-tree | |
| 3 | Click on the checkboxes near 2 file names | |
| 4 | Click the **2 items selected** button, then click **Download archive** | The **Download archive** pop-up opens |
| 5 | Click **OK** | <li> The pop-up closes <li> A notification appears reading `Archive download has been queued. Follow its progress under "Show downloads".` |
| 6 | Wait until the task completes | A notification appears reading `Archive "<name>" is ready. Download it now.`, with **Download it** as a link; it does not disappear on its own |
| 7 | Click the **Download it** link | The archive is fetched via the browser, and the notification is dismissed |
| 8 | Repeat steps 3-5 | |
| 9 | Click the button with the grid icon at the top right of the storage view, then click **Show downloads** in the appeared dropdown | The **Downloads** window opens and shows a row for the task queued at step 5, with: <li> the archive name with its `.zip` extension, followed by `(2 items)` <li> the storage from step 2 <li> a colour-coded status with a spinner, in a pending or active state <li> a **Created** date/time |
| 10 | Hover the archive name | A popover lists the 2 files archived |
| 11 | Wait until the task completes | <li> The row's status changes to a `SUCCESS` <li> The row shows the archive's size and a **Finished** date/time <li> A **Download** button/link appears on the row <li> no separate notification for it appears|
| 12 | Click **Download** on the finished task's row | The archive is fetched via the browser |
| 13 | Close the **Downloads** window |
