# Validation of file name editing

Test verifies renaming a file on an NFS mount.

**Prerequisites**:
- Perform [EPMCMBIBPC-2276](EPMCMBIBPC-2276.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on the edit icon opposite the file name created in the [EPMCMBIBPC-2276](EPMCMBIBPC-2276.md) case |  |
| 2 | Input a new name for the file in the appeared pop-up window |  |
| 3 | Click **OK** button | The file is successfully renamed |
