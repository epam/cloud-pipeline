# Mount rules: Mount None Storages located in cloud region

Test verifies that storages aren't mounted to the instances independently of instance regions if option `None` is selected for *Object storages* and *File storages* in the Cloud region *Mount rules*.

**Prerequisites**:
- admin user
- Perform [3971_1](3971_1.md)

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Open the **Settings** page | |
| 2 | Click the **CLOUD REGIONS** tab | |
| 3 | Select `region1` on the left panel | |
| 4 | In the **Mount rules:** section select <li> option `None` for ***Object storages*** <li> option `None` for ***File storages*** |  |
| 5 | Click **Save** button | |
| 6 | Open the **Tools** page. Select the test tool | |
| 7 | At the tool page, hover over the **Run v** button | |
| 8 | Select the ***Custom settings*** option in the list | |
| 9 | Expand ***Exec environment*** section |  |
| 10 | Select `region1` for **Cloud Region** | |
| 11 | Expand ***Advanced*** section |  |
| 12 | Click on the text field in the **Limit mounts** section | |
| 13 | In an appeared ***Select data storages to limit mounts*** pop-up click the **Clear selection** button. Select `storage1`, `storage2`, `nfs_storage1`. Click **OK** button | |
| 14 | Launch tool | |
| 15 | Open the just launched pipeline | |
| 16 | Wait until *MountDataStorages* task appears | |
| 17 | Click on *MountDataStorages* task at the left panel | *MountDataStorages* task log is displaying that contains the following text: <li> `Only 3 storages will be mounted` <li> `Found 3 available storage(s). Checking mount options.` <li> 1 record: `-->{storage_name} mounted to /cloud-data/{storage_name}`, <br> where `{storage_name}` is `storage2` name |
| 18 | Repeat steps 6-17 with `region2` selected for **Cloud Region** at step 10 | The same result |

**After:**
- Stop the run launched at step 14
