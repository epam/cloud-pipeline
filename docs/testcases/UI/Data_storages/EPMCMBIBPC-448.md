# Validate bucket creating

Test verifies creating a bucket and the initial layout of its page.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open library |  |
| 2 | Hover the mouse pointer over the **+ Create v** button |  |
| 3 | Select **Storages** > **Create new object storage** |  |
| 4 | Input a valid value into the **Storage path** field in the pop-up window (e.g. `epmcmbi-test`) |  |
| 5 | Click **Create** button | A new storage (bucket) appears in the library-tree, with the name equal to the value entered at step 4 |
| 6 | Click on the created storage in the left panel (library-tree) | The page appears on the right panel, containing: <li> the title with the storage name <li> **Refresh** button <li> **Edit** button <li> storage description <li> path to the storage <li> **+ Create folder** button <li> **Upload** button <li> **Select page** button <li> the storage's folders list |
