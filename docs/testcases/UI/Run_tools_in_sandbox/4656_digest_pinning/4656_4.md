# Commit of a run pinned to the docker image digest

Test verifies that a run launched with the `launch.docker.image.pin.digest` system preference enabled
- can be committed to a new tool version
- and that a run launched from that new version is pinned to the new version's digest

**Prerequisites**:
- Admin user
- Test tool available in the registry
- If the tool scanning is enabled, the `security.tools.policy.deny.not.scanned` system preference is disabled, so that a version which is not scanned yet can be launched

**Preparations**:
1. Login as the admin user from the prerequisites
2. Open the **Settings** page
3. Click the **PREFERENCES** tab
4. Click the **Launch** tab
5. Find the `launch.docker.image.pin.digest` preference
6. Save the preference value, then set *Enabled* checkbox for `launch.docker.image.pin.digest` preference if needed
7. Click **Save** button if needed

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page | |
| 2 | Select the test tool from the prerequisites | |
| 3 | Click the **Run** button | |
| 4 | In an appeared pop-up window click **Launch** button | |
| 5 | At the **Runs** page, click the just-launched run | |
| 6 | Click the **Instance** item | ***Docker image digest*** field is shown with a value `sha256:<64 hexadecimal characters>` |
| 7 | Save the ***Docker image digest*** value | |
| 8 | Wait until the **COMMIT** hyperlink appears in the right upper corner, then click it | A pop-up with the header `Commit pipeline run` appears |
| 9 | In the **Docker image** field, select the test tool's registry and tools group, and make sure the tool name is the test tool's name | |
| 10 | Replace the value of the **Version** field with `digest-test-commit` | |
| 11 | Click **COMMIT** button | The **COMMITTING...** label appears |
| 12 | Wait until the commit finishes | The label `COMMIT SUCCEEDED` with the commit date appears |
| 13 | Open the **Tools** page | |
| 14 | Select the test tool from the prerequisites | |
| 15 | Click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | The `digest-test-commit` version is shown, with a ***Digest*** value that differs from the value saved at step 7 |
| 16 | Save the ***Digest*** value of the `digest-test-commit` version | |
| 17 | Hover over the **Run v** button of the `digest-test-commit` version, click **Default settings** | |
| 18 | In an appeared pop-up window click **Launch** button | |
| 19 | At the **Runs** page, click the just-launched run | |
| 20 | Click the **Instance** item | <li> ***Docker image*** field ends with `:digest-test-commit` <li> ***Docker image digest*** field is shown with the value saved at step 16 |

**After**:
- Stop the runs launched at steps 4 and 18
- Delete the `digest-test-commit` version of the test tool
- Restore the `launch.docker.image.pin.digest` preference value saved at step 6 of the preparations
