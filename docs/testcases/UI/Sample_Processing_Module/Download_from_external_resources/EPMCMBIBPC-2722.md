# [MANUAL] Prepare for downloading

Test verifies uploading a metadata file and opening its samples panel, as a shared setup step for the download-from-external-resources cases.

**Prerequisites**:
- Login as admin

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Library** page |  |
| 2 | Hover over the **+ Create v** button -> click **Folder** in the list that appears |  |
| 3 | In the pop-up that appears, specify a valid folder name, click **OK** |  |
| 4 | Open the just-created folder |  |
| 5 | Hover over the **+ Create v** button -> click **Storages** in the list that appears |  |
| 6 | In the pop-up that appears, specify a valid storage name, click **Create** |  |
| 7 | Open the just-created storage |  |
| 8 | Repeat steps 2-3 |  |
| 9 | Open the folder created at step 3 |  |
| 10 | Click the **Upload metadata** button in the upper-right corner |  |
| 11 | In the pop-up that appears, select a file (see the attachment to the case), confirm the upload | A **Metadata** object appears in the folder created at step 3 |
| 12 | Wait 10 seconds |  |
| 13 | Click on the **Metadata** object |  |
| 14 | Click on the **Sample [4]** object | <li>The panel with metadata samples appears with the **DELETE**, **CLEAR SELECTION**, **RUN** buttons disabled and the **TRANSFER TO THE CLOUD** button enabled <li>A table with the **ID**, **Location**, **Name** columns and 4 rows is displayed |
