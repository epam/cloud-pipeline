# Admin can create a credit deduction rule for idle runs

Test verifies that an admin can create a Platform Usage Credits rule that deducts credits from a user's balance when a run remains idle beyond a configured time threshold.

**Prerequisites**:
- admin user
- Platform Usage Credits feature enabled

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Settings** page. Navigate to the **Platform Usage Credits** section | The **Platform Usage Credits** section is displayed with a list of configured rules |
| 3 | Click **Add rule** | A rule creation form opens |
| 4 | Set the rule name to `Idle Run Penalty` | |
| 5 | Set the rule type to **Deduction** | |
| 6 | Set the credit amount to `100` | |
| 7 | Set the condition to **Run is idle for** `48` **hours** | |
| 8 | Click **Save** | The new rule `Idle Run Penalty` appears in the rules list with type **Deduction**, amount `100`, and the configured idle condition |
| 9 | Refresh the page and reopen the **Platform Usage Credits** section | The `Idle Run Penalty` rule is still present in the rules list with all configured values preserved |
