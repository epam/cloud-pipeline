# ROLE_RUN_ADMIN: Cluster state tab and terminating node

Test verifies that user with role `ROLE_RUN_ADMIN` 
- can see all nodes
- can terminate nodes for runs of another users.

**Prerequisites**:
- admin user
- non-admin user (`user1`) with `ROLE_RUN_ADMIN` role
- Perform [4146_2_1](4146_2_1.md) case

| Steps | Actions | Expected results |
| :---: |--- | --- |
| 1 | Login as the non-admin `user1` from the prerequisites | |
| 2 | Open **Runs** page | |
| 3 | Click on **STOP** hyperlink opposite the `run2` launched at step 9 of [4146_2_1](4146_2_1.md) case | |
| 4 | Open **Cluster state** page | <li> All nodes include the node for the `run2` are shown in the **Cluster state** tab <li> ***Terminate*** buttons are shown in the each non-master node rows include `run2` row |
| 5 | Click ***Terminate*** button opposite the node for the `run2` | |
| 6 | Click **OK** button in an appeared pop-up | Node for the `run2` isn't displayed at the table at ***Cluster state*** page |
