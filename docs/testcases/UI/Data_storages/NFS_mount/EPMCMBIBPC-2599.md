# Validation of folder name editing

Test verifies renaming a folder on an NFS mount.

**Prerequisites**:
- Perform [EPMCMBIBPC-2276](EPMCMBIBPC-2276.md)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Click on the edit icon opposite the folder name created in the [EPMCMBIBPC-2276](EPMCMBIBPC-2276.md) case |  |
| 2 | Input a new name for the folder in the appeared pop-up window |  |
| 3 | Click **OK** button | The folder is successfully renamed |
