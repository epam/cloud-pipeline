# The security messages name the default version

Test verifies that the messages about the security state of a tool version (the black list here) call the default version set for a tool **default**, and no longer call the **latest** version so, once another version is the default one.

**Prerequisites**:
- Admin user
- Test tool with the **latest** version and at least one other version, without a default version set, and with no version on the black list
- `<version>` is one of the test tool versions, which is not the **latest** one
- The tool scanning is enabled for the registry of the test tool (the `security.tools.scan.enabled` system preference is enabled, and the registry has the ***Require security scanning*** option set): the ***Configure access*** button and the security messages are shown only then

**Preparations**:
1. Login as the admin user from the prerequisites
2. Set the `<version>` version as the default one of the test tool, as described in [4664_2](4664_2.md) (steps 1-4)

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Open the **Tools** page and select the test tool from the prerequisites | |
| 2 | Click the **VERSIONS** tab. If the **VIEW UNSCANNED VERSIONS** button is shown, click it | |
| 3 | Click ***Configure access*** button opposite the `<version>` version, click *Add to black list* option | ***Configure access*** button is replaced by ***Black-listed*** red button opposite the `<version>` version |
| 4 | Hover over the **Run** button opposite the `<version>` version | Tooltip `The default version is on the black list. Try to find another one.` appears |
| 5 | Click the **DESCRIPTION** tab | The tab contains the `The default version is on the black list. Try to find another one.` message |
| 6 | Click the **VERSIONS** tab. Click ***Black-listed*** button opposite the `<version>` version, click *Remove from black list* option | |
| 7 | Click ***Configure access*** button opposite the **latest** version, click *Add to black list* option | |
| 8 | Hover over the **Run** button opposite the **latest** version | Tooltip `The version is on the black list. Try to find another one.` appears |
| 9 | Click the **DESCRIPTION** tab | The tab contains no message about the black list |

**After**:
- Remove the **latest** version from the black list
- Remove the default version of the test tool, as described in [4664_3](4664_3.md) (steps 1-4)
