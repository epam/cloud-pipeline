# Check attributes for tool

Test verifies that a tool's own attributes are not shown for a different tool.

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Perform the [EPMCMBIBPC-914](EPMCMBIBPC-914.md) case |  |
| 2 | Navigate to another tool not used in the EPMCMBIBPC-914 case |  |
| 3 | Click the button for customizing the display of additional panels (in the upper-right corner) |  |
| 4 | Click **Attributes** in the list that appears | The attributes added in the EPMCMBIBPC-914 case are not displayed |
