# EXTERNAL_URLS tag is not displayed in run tags

Test verifies that the reserved `EXTERNAL_URLS` run tag is excluded from the run tag badge and tag list displays.

**Prerequisites**:
- admin user
- test tool available in the registry

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Tools** page | |
| 3 | Select the test tool from the prerequisites | |
| 4 | Click the **Run** button | Run launch form opens |
| 5 | Click **Launch** | Run is launched and appears on the **Runs** page |
| 6 | Add external url to the just-launched run as json `{"tags": {"EXTERNAL_URLS": "[{\"url\": \"https://example.com\", \"name\": \"Custom Link\"}]"}}` using the `/pipeline/restapi/run/<runID>/tag?overwrite=true` API method | |
| 7 | On the **Runs** page, inspect the tag badges displayed next to the just-launched run | `EXTERNAL_URLS` tag badge is **not** shown among the run tags |
| 8 | Click on the just-launched run to open the run log page | |
| 9 | Inspect the **Instance** section and any tag list displayed on the run log page | `EXTERNAL_URLS` tag is **not** shown in any tag list or badge on the run log page |

**After**:
- Stop the run launched at step 5.
