# Notifications for idle states

Test verifies that user receive a corresponding notifications when run tagged by ***IDLE***, ***IDLE_CPU*** and ***IDLE_GPU*** tags.

**Prerequisites**:
- Admin user
- Perform [4512_2](4512_2.md) case

| Steps | Actions | Expected results |
| :---: | --- | --- |
| 1 | Login as the admin user from the prerequisites | |
| 2 | Open the **Notifications** page | Notifications list opens that contains: <br> `Job #<run_ID> is CPU Idle for a long time` <br> `Job #<run_ID> is GPU Idle for a long time` <br> `Job #<run_ID> is completely Idle for a long time` <br> notifications, where `<run_ID>` is id of run launched at step 3 of [4512_2](4512_2.md) case |
| 3 | Open `Job #<run_ID> is CPU Idle for a long time` notification | Notification opens that contains `extend idle period request` link |
| 4 | Click `extend idle period request` link | XML with result of prolong operation opens |
| 5 | Back to the **Notification** page. Open **Runs** page. | ***IDLE***, ***IDLE_CPU*** and ***IDLE_GPU*** tags aren't shown near the name of run launched at step 3 of [4512_2](4512_2.md) case |
| 6 | Wait until ***IDLE***, ***IDLE_CPU*** and ***IDLE_GPU*** tags appear near the name of run launched at step 3 of [4512_2](4512_2.md) case | |
| 7 | Open the **Notifications** page | | 
| 8 | Repeat steps 3-7 for `Job #<run_ID> is GPU Idle for a long time` and `Job #<run_ID> is completely Idle for a long time` notifications | |
